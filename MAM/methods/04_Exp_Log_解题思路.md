## 工具箱

- 定义：y = logₐx ⇔ aʸ = x。**大量题目的第一步是在对数式和指数式之间转换**（key 常有 1 分给「converts to index form / uses the inverse relationship」）。
- 对数律：log(mn) = log m + log n；log(m/n) = log m − log n；log mᵏ = k log m；logₐa = 1；logₐ1 = 0；换底 logₐb = log_c b / log_c a。
- 常数也能写成对数：4 = 4 ln e = ln e⁴；2 = log₁₀100；9 = log₁₀10⁹。这是 2025F-Q7(a)、2020F-Q6(c)、2024A-Q15(c)、2019A-Q17(b)(iii) 的关键一步。
- 微积分：(ln f)′ = f′/f；∫f′/f dx = ln|f| + c（考试中一般 f(x) > 0，key 常写 ln f(x) + c）；(eᵏˣ)′ = keᵏˣ。

## 阅卷组提醒

- 解 2 ln x = …：ln x 要求 x > 0，**负根必须舍去**（2025F-Q7 key 明确要求只给一个解）。
- 对数刻度的「几倍」问题：读数之差不是答案，差值还要化成 10 的幂（2016A-Q12 的 key 有 1 分给 "subtracts Richter magnitudes"，再化成指数式）。2023 报告要求加强对数刻度的解读与读数（见 2023F-Q4(c)：在 y = log₁₀x 的图上读数）。
- 题目要求用图像时，要在图上画出读数过程（2024A-Q15(a)：You must show clearly how you have used the graph）。
- 应用题带单位。问 rate of change 就给带符号的值（如 2018A-Q9(c) 的答案是 −0.164 mg/L/h）；问 rate of decrease 才写成正数并说明 decreasing（2024A-Q8(c) key：「converts to a rate of decrease」）。

## 题型 1：用给定字母表示对数（CF）

**识别**：「Let p = ln 2, q = ln 3, r = ln 5. Express ln 6.25 in terms of …」「log₁₀2 = x, log₁₀7 = y」。

**思路**：把真数分解成给定底数的乘积、商、幂：6.25 = 25/4 = 5²/2² ⇒ 2r − 2p；17.5 = 7 × 10 / 4 ⇒ y + 1 − 2x；14 = 2 × 7。
**换底类（2025F-Q7(b)）**：m = log₃6，n = log₆5，求 log₃10。先 log₃10 = log₃2 + log₃5；再 log₃2 = log₃6 − 1 = m − 1，log₃5 = log₃6 · log₆5 = mn ⇒ **log₃10 = m − 1 + mn**。
**e^{p+q} 类**：e^{ln2 + ln3} = e^{ln 6} = 6（指数律加互逆关系）。

**得分点**：✓ 分解真数 ✓ 用对的对数律 ✓ 最终表达式。

**真题**：2017F-Q7、2023F-Q2(a)(b)、2024F-Q5(a)(b)、2025F-Q7(b)。

## 题型 2：解指数 / 对数方程（CF 精确值）

**思路**
- 同类项合并：4e²ˣ = 81 − 5e²ˣ ⇒ 9e²ˣ = 81 ⇒ e²ˣ = 9 ⇒ x = ln 3。
- eˣ 的二次型：设 u = eˣ，因式分解，并舍去 u ≤ 0 的根（2020F-Q7(a)：eˣ(eˣ − 4) = 0 ⇒ 只有 x = ln 4）。
- 对数方程：先把所有项合成单个对数（log₂(x+y) + 2 = log₂(x − 2y) ⇒ log₂[4(x+y)] = log₂(x − 2y)），再去掉对数，最后**检查定义域**。

**真题**：2017F-Q3、2016F-Q1(b)、2020F-Q7(a)、2024F-Q5(c)、2025F-Q7(a)。

## 题型 3：对数函数图像与变换

**识别**：「sketch y = ln(x − 2) + 1」「determine the equation of g」「explain why p = 5」「find m, q」。

**思路**
1. y = m logₐ(x − p) + q：竖直渐近线 x = p；必过 (p + 1, q)；a > 1 时 m > 0 为增。
2. 作图三要素（key 各 1 分）：**渐近线**（画出并标方程，习惯用虚线）、**一个特殊点**（如 (3, 1)）、**正确形状**（含近渐近线的行为）。
3. 由图像定参数：先由渐近线定 p，再代两个点解 m、q（2021A-Q15）。
4. 变换的识别：ln(4x) = ln x + ln 4 → 向上平移 ln 4；ln√x = ½ln x → 竖直伸缩 ½；ln x + 4 = ln(e⁴x) → 水平伸缩，比例 1/e⁴（2020F-Q6）。
5. log₂(1/(x−1)) = −log₂(x − 1)：先关于 x 轴翻转，再右移 1（2022F-Q4(c)）。

**用图像解方程或估值**：例如 √7 ⇒ log₂√7 = ½log₂7 ≈ ½ × 2.8 = 1.4 ⇒ 读 x ≈ 2.6（2022F-Q4(a)(ii)）。

**真题**：2018A-Q8、2019F-Q4、2020F-Q6、2021A-Q15、2022F-Q4、2024F-Q5(d)。

## 题型 4：指数增长/衰减模型 ★ CA 高频

**识别**：P = P₀eᵏᵗ、C = 4e^{−0.05t}、T = T₀ − 175e^{−0.07t}、half-life、「in danger if below …」。

**标准流程**
1. **初值**：t = 0 代入（带单位）。
2. **求 k**：用半衰期 ½ = e^{k·100.5}，或者用两个数据点。按要求保留有效数字。
3. **到达某值的时刻**：令模型等于目标值，用 ln 解；按语境换算成具体时刻，**并按题意取整**。例：2018A-Q9(d) 中 4e^{−0.05t} = 2.5 ⇒ t = ln 1.6 / 0.05 ≈ 9.40 h ⇒ 9 am + 9 h 24 min = **6:24 pm**（latest 要向下取，key 注明 6:25 已太晚）。超出定义域的根要写明舍去（2025A-Q9(b)）。
4. **变化率**：dP/dt = kP，代入时刻；符号的写法见上面的提醒。
5. **分段模型**：后一段模型的初值 = 前一段末的值（2017A-Q16(c)、2023A-Q6(e)）。
6. **长期行为**：t → ∞ 时 e^{−kt} → 0，所以 T → T₀，变化率 → 0（2020A-Q15(e) 三个点：变化率 → 0、温度趋于常数、常数等于 T₀）。

**得分点**：✓ 列方程 ✓ 解出 ✓ 按要求取整或换算时间 ✓ 求导 ✓ 代值。

**真题**：2016A-Q9、2016S-A10、2017A-Q16、2018A-Q9、2020A-Q15、2022A-Q14、2023A-Q6、2024A-Q8、2025A-Q9(b)。

## 题型 5：对数刻度（分贝、里氏、站点排名、矩震级）

**识别**：L = 10 log(I/I₀)、M = log₁₀(A/A₀)、R = 2 log₁₀(S/S₀)，问「how many times larger / more intense」。

**思路（比值题）**
1. 一般式 L = k·log₁₀(I/I₀)。两个读数分别化成指数式：I₁ = I₀·10^{L₁/k}，I₂ = I₀·10^{L₂/k}。
2. 相除，I₀ 约掉：I₂/I₁ = 10^{(L₂−L₁)/k}。**k 因题而异**：分贝 L = 10 log ⇒ 90 dB 对 60 dB 为 10³ = 1000 倍；声压 D = 20 log（2016S-A13）⇒ 差 30 dB 为 10^{1.5} ≈ 31.6 倍；里氏 k = 1（2016A-Q12）⇒ 10^{2.1} ≈ 126 倍；站点排名 R = 2 log（2023F-Q4）。
3. 求参考值 I₀ 或 S₀：代入一组 (L, I)，化成指数式解出。

**线性化（log 对 t 是直线）**：log₁₀P = At + B ⇒ P = 10^B·(10^A)ᵗ；斜率 A 反映增长快慢（2019A-Q17(c) 比较两种温度下的增长率要引用斜率或底数）。

**得分点**：✓ 化成指数式 ✓ 写比值并约分 ✓ 结论（「… times」）。

**真题**：2016A-Q12、2016S-A13、2018A-Q18、2019A-Q17、2022A-Q14(c)–(e)、2023F-Q4、2024A-Q15、2025A-Q17。

## 题型 6：对数模型 + 求导 + 下结论

**识别**：s = 40.6 ln(0.15D)、A(t) = b log₄(t+1) + c、P(x) = 20 ln(x+a)/(x+5)。

**思路**
- 由已知点定参数：A(0) = 21 ⇒ c = 21；A(1) = 53 ⇒ b·log₄2 = 32 ⇒ b = 64。
- 求导解释：ds/dD = 40.6/D 随 D 增大而减小 ⇒ 同样减少 8 m，原本停车距离大的道路限速降得少（2025A-Q11(c)）。
- 判断能否达成目标：解 A(t) = 493，看 t 是否合理（2024A-Q17(c)），要带理由下结论。
- 按语境取整：数量向下取整（2024A-Q17(b)）；比较相邻整数（2020A-Q13 比较 74 和 75）。
- 「during which week」：x 是从开始算起的周数，1 < x < 2 属于**第 2 周**，不是第 1 周（2021A-Q16(d) 的 key 写「occurs in the second week」）。

**真题**：2018F-Q6、2020A-Q13、2021A-Q16、2024A-Q17、2025A-Q11。
