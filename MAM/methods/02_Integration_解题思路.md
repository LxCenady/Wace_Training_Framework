# MAM · 积分及其应用 — 题型与解题思路

> 依据：2016–2025 共 39 道含积分的真题 marking key + 考试报告。原题见 `topics/02_Integration.pdf`。积分以 Calculator-free 为主（作为主知识点时 CF 16 题、CA 7 题）。另引 2016 样卷 2 题（`2016S-F1`、`2016S-A20`，原卷见 `papers/2016Sample_*`）。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 先记住：阅卷组反复扣分的地方

- **FTC（微积分基本定理）多次被报告点名**（2016、2017、2018、2022、2025 报告）：认不出 FTC 的各种用法；2022 报告特别点名 FTC 与链式法则结合（上限是 g(x) 时要乘 g′(x)）。
- **面积 ≠ 积分**：x 轴下方的部分要取绝对值，或者分段相减（2018A-Q16(b) 4 分全在这里）。
- **积分号后面要写 dx**（2023 报告：notation 扣分；2025F-Q5 给了「uses correct notation including dx on all integrals」1 分）。
- **上下界由多个函数组成的面积**要拆成多个积分（2024 报告点名）。
- **不定积分要写 + c**（key 有时单独给 1 分）。
- **"Show that" 不能跳步**。

## 题型 1：基本不定积分与由 f′ 求 f

**识别**：「Determine ∫…dx」「If f′(x) = …, find f(x) given f(0) = −2」。

**思路**
1. 记牢反导数：∫eᵏˣdx = eᵏˣ/k；∫cos kx dx = sin kx / k；∫(ax+b)ⁿdx = (ax+b)ⁿ⁺¹/[a(n+1)]（n ≠ −1）；∫f′/f dx = ln|f| + c（考试中一般 f(x) > 0，key 常写 ln f(x) + c）。
4. **定积分求值**（CF 常见 3 分）：✓ 反导数 ✓ 代入上下限 ✓ 化简得精确值（2017F-Q6(a)、2021F-Q4(b)、2023F-Q1(b)、2023F-Q2(a)(iii)）。
2. **分子是分母导数的倍数**时：先把系数调出来，如 ∫(3x+1)/(3x²+2x+1)dx = ½∫(6x+2)/(…)dx = ½ln(…) + c。key 有一分专门给「modifies the integrand so the numerator is the derivative of the denominator」。
3. 由 f′ 求 f：积分并写 + c → 代入已知点求 c → 写出完整的 f(x)。答案涉及 ln 时，用对数律化简（如 ln 32 − ln 4 = ln 8）。

**得分点**：✓ 反导数正确 ✓ 带常数 c ✓ 代点求 c ✓ 写出最终表达式（并按要求化简）。

**真题**：2018F-Q3(c)(d)、2019F-Q1(c)、2021F-Q1(c)、2021F-Q4(a)、2022F-Q1(b)、2024F-Q1(b)、2020A-Q10(b)。

## 题型 2：「Hence」利用刚求的导数求积分 ★ CF 高频

**识别**：(a) 先求 d/dx(x ln x) 或 d/dx(2x sin 3x)（2017F-Q8）；(b)「Hence show that ∫ln x dx = x ln x − x + c」。

**固定三步**（key 通常按这三步给分：2017F-Q8、2022F-Q6 正好 3 分；2018F-Q7 拆成 4 分，2023F-Q2 合成 2 分）
1. **两边同时积分**：∫ d/dx(x ln x) dx = ∫(ln x + 1)dx。
2. **对左边用 FTC**：左边 = x ln x（反导数与导数抵消）。
3. **拆开右边并移项**：x ln x + c₁ = ∫ln x dx + x + c₂ ⇒ ∫ln x dx = x ln x − x + c（两个常数合并为 c）。

**易错**：直接写结论；忘了 + c；右边没有用线性性质拆开。

**真题**：2016F-Q2(b)、2017F-Q8(b)、2018F-Q7(b)、2022F-Q6(a)(ii)、2023F-Q2(c)(ii)。之后通常还有一小问用这个结果求期望、定积分或面积（2022F-Q6(b)(ii)、2023F-Q2(c)(iii)、2018F-Q7(c)）。

## 题型 3：定积分 = 有向面积（从图形读值）

**识别**：给出由线段、半圆或四分之一圆组成的图形，问 ∫₀¹² f(x)dx、∫(f(x) − 2)dx、∫f′(x)dx。

**思路**
1. 把区域拆成矩形、三角形、扇形，**x 轴上方为正，下方为负**。
2. ∫(f(x) − k)dx = ∫f dx − k·(区间长度)。
3. ∫ₐᵇ f′(x)dx = f(b) − f(a)（FTC，直接从图上读两个函数值）。
4. 求使 ∫₀^α f = 0 的 α：令上方正面积等于下方负面积，列方程。

**得分点**：✓ 分块面积 ✓ 带符号相加 ✓ 结果（精确值，含 π）。

**真题**：2016S-F1、2016F-Q7、2022F-Q2。

## 题型 4：FTC 与积分定义的函数 ★ 高频（2016–18、2021–23、2025 均出现），且多次被报告点名

**识别**：A(x) = ∫ₐˣ f(t)dt；d/dx ∫ₐ^{g(x)} f(t)dt；d/dt ∫ₜ³ f(x)dx；「Sketch A(x)」「Is F(2π) positive or negative?」。

**核心公式**
- d/dx ∫ₐˣ f(t)dt = f(x)（结果要写成 x 的函数）；
- d/dx ∫ₐ^{g(x)} f(t)dt = f(g(x))·g′(x)（2022A-Q15：D(t) = ∫₀^{πt}… ⇒ D′(t) = π·√(1+3cos²(πt))）；
- 下限是变量时先交换上下限：∫ₜ³ f = −∫₃ᵗ f，所以导数为 −f(t)（2022F-Q1(c)）；
- ∫ₐᵇ f′(x)dx = f(b) − f(a)（2018A-Q16(a)、2023F-Q2(a)(iii)、2016F-Q4(c)）。
- 线性性质 + 积分函数：∫₂⁴ (f + 2)dx = F(4) − F(2) + 4（2023F-Q5(b)）。

**画 A(x)（积分函数）的规则**
- A(a) = 0（下限处）；A 的零点要标出；
- f 由正变负的地方，A 取局部极大；f 由负变正的地方，A 取局部极小；
- f 的转折点对应 A 的拐点；
- A 的增减由 f 的正负决定；端点要标 A 的值。

**判断 F(x) 正负（2025F-Q2）**：F(x) 等于从 0 到 x 的有向面积，看图上正面积和负面积哪个大。理由要引用面积，不能只说结论。

**真题**：2016F-Q5、2016S-A20、2017A-Q15(a)、2018A-Q16、2021F-Q4(c)、2022A-Q15、2022F-Q1(c)、2023F-Q5(b)(c)、2025F-Q2。

## 题型 5：曲线下 / 曲线间的面积

**识别**：「Determine the (exact) area bounded by …」，或「Write an integral expression for the area」。

**思路**
1. **先求交点**作为积分上下限（交点本身常给 1 分）。
2. 判断谁在上方：面积 = ∫(上 − 下)dx。
3. 求曲线与 x 轴之间的面积而曲线跨过 x 轴时，或两条曲线的上下关系发生交换时，要**分段**（只求两曲线之间面积时，曲线跨过 x 轴本身不需要分段）。
4. 面积不方便对 x 积时，用「矩形 − 曲线下面积」，例如 y = eˣ、y = 2 与 y 轴围成的面积 = 2·ln 2 − ∫₀^{ln2} eˣ dx（2017F-Q5、2019F-Q5）。
5. 反函数的面积（2020A-Q11(e)）：先认出 eˣ 的反函数是 g(x) = ln x（单独 1 分）；再注意 ln 2 ≈ 0.69 < 1，区域在 x 轴**下方**，所以面积 = −∫_{ln2}^{1} ln x dx（或者写成 ∫_{ln2}^{1} −ln x dx）。
6. 「为什么两块面积相等」：两个函数被同一个平移移动，形状不变（2021F-Q5(b) 两点：同方向同距离平移、形状不变）。

**得分点**：✓ 交点/上下限 ✓ 正确的积分式（被积函数 + 上下限 + dx）✓ 反导数 ✓ 精确值。

**真题**：2016A-Q13(d)、2016F-Q6、2017F-Q5、2018F-Q7(c)、2019F-Q5、2020A-Q11(d)(e)、2021F-Q5、2025F-Q5。

## 题型 6：参数未知的定积分方程

**识别**：「If the area … is to equal 2, determine the exact value of k」「∫ₐᵇ 1/x dx = ln 3, find the relationship between a and b」。

**思路**：写出积分 → 用 FTC 算出含参表达式 → 令其等于给定值 → 解方程（常用对数律：ln b − ln a = ln 3 ⇒ b = 3a）。

**真题**：2017F-Q5(b)、2021F-Q7(a)(ii)、2020A-Q10(d)。

## 题型 7：黎曼和（矩形估计）

**识别**：图上画了矩形，「demonstrate and explain why L < ∫ < U」「best estimate」「state one way to improve」。

**思路**
1. 下和用每个小区间上的**较小**函数值（左端或右端，取决于函数增减），上和用**较大**值；分别写出算式。
2. **解释**：函数在区间上递增时，左端点矩形全部在曲线下方，是低估，右端点矩形是高估；**递减时正好相反**（如 2021F-Q7 的 1/x）。函数在区间上不单调时，不能简单按端点判断。这条解释单独占 1 分（2017 报告指出面积相关的解释类问题普遍薄弱）。
3. 最佳估计 = (L + U)/2（梯形）。
4. 改进方法：增加矩形个数（缩小宽度）；改用梯形；求出函数表达式后用积分算精确值（2017F-Q9 的 key 接受第一条和最后一条）。

**真题**：2017F-Q9、2021F-Q7(b)、2024F-Q6。

## 题型 8：语境中的积分应用（截面积、体积、总变化量）

**识别**：建筑或窗户截面、海沟、水坝、洗发水瓶；或「rate is … determine the total change」。

**思路**
1. 体积 = 截面积 × 厚度/长度。截面积用积分算；单位要统一（厘米和米）。
2. 求交点或边界（如 h(W) = 0 求宽度，D(x) = −2 求海沟边缘）。
3. 总变化量 = ∫ₐᵇ 变化率 dt。
4. 未知水位 h 时：把截面积写成 h 的函数（上限是 h 的表达式）→ **截面积 × 长度（宽度）= 体积** → 解 h（2024A-Q16(b)：宽 4 cm）。2023A-Q14(a) 是用同样方法推出 V(h) 的表达式。

**得分点（2023A-Q14(a)）**：✓ 上限用 h 表示 ✓ 正确积分式 ✓ 反导数 ✓ 代入上下限 ✓ 化简到目标式。

**真题**：2019A-Q15(c)、2020A-Q10(c)(d)、2022A-Q7、2023A-Q9、2023A-Q14、2024A-Q16。（2021A-Q9 同类语境，但整题不涉及积分。）
