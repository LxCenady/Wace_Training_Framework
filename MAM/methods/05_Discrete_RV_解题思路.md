# MAM · 离散随机变量与二项分布 — 题型与解题思路

> 依据：2016–2025 共 27 道离散随机变量真题 marking key + 考试报告（另引 2016 官方样卷 `2016S-F4`，原卷见 `papers/2016Sample_*`）。原题见 `topics/05_Discrete_RV.pdf`。文中数值例已用 Python 验算。

## 阅卷组提醒

- **认出二项分布并写出参数**：「State the distribution」通常名称 1 分、参数 1 分（偶尔合并为 1 分，如 2023A-Q13(b)），写成 X ~ Bin(5, 0.05)。2020 报告：很多人没认出 2020F-Q1 是二项分布，(c) 求均值、方差时算得过于复杂。
- **写出概率表达式**（如 P(X ≥ 4) = 1 − P(X ≤ 3)）多数题单独给 1 分，不要只写计算器结果。
- 中间概率至少保留 **4 位小数**（2020 报告：只保留 2 位会使后续答案不准）。概率很小时要保留足够的有效数字：2019A-Q18(c) 的答案约 0.00003，key 要求至少 5 位小数。
- **区分概率分布和累积分布**：P(X = x) 与 P(X ≤ x) 的表格不要混用（2023 报告）。
- 「Explain / justify / state assumptions」类问题要结合语境作答（2020 报告点名 9(c)、12(h)）。

## 题型 1：补全分布表 / 求未知概率

**思路**
1. 等可能情形：列出样本空间，如两颗四面骰的和用 4×4 表格（2016A-Q15）；不放回抽取用乘法法则或组合数。
2. 有未知数 a、b 时：**ΣP = 1**（1 分）和 **E(X) = Σx·P = μ**（1 分）联立解出（2019A-Q10）。
3. 由原始数据建分布表：频数 ÷ 总数（2018F-Q4）。
4. 已知累积分布 P(X ≤ x)：P(X = k) = P(X ≤ k) − P(X ≤ k−1)（2024F-Q3）。
5. 新变量（如未卖出蛋糕数 Y = max(0, 3 − X)，即 X ≤ 3 时 Y = 3 − X，X ≥ 3 时 Y = 0）：Y = 0 对应 X ≥ 3 ⇒ P(Y=0) = P(X=3) + P(X=4)（2020A-Q9(c)）。

**真题**：2016A-Q15、2018F-Q1(a)、2018F-Q4、2019A-Q10、2020A-Q9、2024F-Q3、2025A-Q8(a)。

## 题型 2：期望、方差与线性变换

**公式**：E(X) = Σx·p；Var(X) = Σx²p − [E(X)]²；E(aX + b) = aE(X) + b；Var(aX + b) = a²Var(X)；SD(aX + b) = |a|·SD(X)。

**常见陷阱**
- Var(25 − 2X) = 4Var(X)：系数是 (−2)² = 4，**常数 25 对方差没有影响**（key 原话：uses a positive factor of four）。
- 缩放到新的均值和标准差（2016A-Q17(c)）：**先用标准差定 a**（|a|·22 = 15 ⇒ a = 15/22，取 a > 0 以保持名次顺序），再用均值定 b（75a + b = 60 ⇒ b = 195/22）。key 第一分就是「determines change on standard deviation first」。
- 费用涨 20% 再加收 $1（2018A-Q12(f)）⇒ 新均值 = 1.2μ + 1，新标准差 = 1.2σ（加常数不影响标准差）。

**真题**：2016A-Q17、2017A-Q19(c)、2018A-Q12(d)–(f)、2019A-Q10(b)、2023F-Q3(d)、2025A-Q8(b)。

## 题型 3：游戏 / 筹款的期望收益 ★ 高频（近 10 年有 6 年考过：2017、2020、2021、2022、2024、2025）

**识别**：「expected profit/loss」「who is better off in the long term」「what should be charged」「is it a good idea for the organisers」。

**标准流程**
1. 定义收益变量（**站在谁的角度**：玩家还是主办方）。
2. 列出「每个结果的净收益 + 概率」表。
3. E(收益) = Σ值 × 概率。
4. 下结论：E < 0 表示玩家长期亏损；要说「on average / in the long run」。
5. 定价：令期望利润 = 目标（例如收费的 20%）解方程；「最低收费使期望利润不为负」= 期望赔付（2025A-Q8(c)：E(X) = 0.8，每个红球 $5 ⇒ 至少收 $4）。

**得分点（2017A-Q13，共 9 分）**：(a)–(c)：✓ 收益表顶行 ✓ 概率 ✓ 期望算式 ✓ 期望值 ✓ 新的期望赔付 ✓ 结论（谁更有利）✓ 解释期望的含义；(d)：✓ 列方程 ✓ 解出收费。

**真题**：2017A-Q13、2020A-Q9(b)、2021A-Q13(c)、2022A-Q9(c)–(f)、2024A-Q14(c)–(e)、2025A-Q8(c)。

## 题型 4：Bernoulli 与二项分布

**识别**：固定次数 n、每次只有两种结果、各次独立、成功概率 p 不变，问「number of …」。

**思路**
1. **写出 X ~ Bin(n, p)**，并说明 n 和 p 在语境中指什么。
2. P(X = k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ；CF 卷要能手算（2018F-Q1(e)：Bin(5, 0.8)，P(X=2) = 10 × 0.8² × 0.2³ = 32/625）。
3. E(X) = np，Var(X) = np(1−p)。**由均值和方差反求 n、p**（2024F-Q4(b)）：np = ½，np(1−p) = 5/12 ⇒ 1 − p = 5/6 ⇒ p = 1/6，n = 3 ⇒ P(W=1) = 3 × (1/6) × (5/6)² = 25/72。
4. 「至少 / 至多 / 超过」的边界要写准：more than three ⇒ X ≥ 4；system fails if fewer than 2 work ⇒ 坏掉 ≥ 4 个。
5. 情境变化要换参数：拆掉一个报警器后变成 Bin(4, 0.05)（2019A-Q18(d)）。

**假设题（2 分）**：首选这两条——各对象**相互独立**；各对象的成功/失败**概率相同且不变**（2019A-Q18(b)、2020A-Q12(h) 的 key 都只给这两类）。「只有两种结果」「n 固定」一般是题设，不宜当作假设来写。要结合语境写，例如「the failure of one alarm does not affect another」。2020A-Q12(h) 还要求讨论假设是否合理。
**为什么不是二项**（2024A-Q14(b)、2025A-Q8(d)）：试验次数不固定；不放回导致各次不独立、p 在变化。改进方法：放回抽取。

**真题**：2016S-F4、2018F-Q1、2019A-Q18、2020F-Q1、2021A-Q13、2022A-Q9、2025A-Q15。

## 题型 5：与正态分布结合（「n 件里至少 k 件……」）

**识别**：先用正态求单件满足条件的概率 p，再问 n 件中有几件满足。

**两步法**
1. 正态：p = P(X > 3.7)。保留足够的小数位。
2. 二项：Y ~ Bin(20, p)，求 P(Y ≥ 10)。**key 要求写出「binomial」和参数**，通常名称 1 分、参数 1 分（2017A-Q19(b)、2018A-Q12(b)、2023A-Q12(b)）。

**真题**：2017A-Q19(b)、2018A-Q12(b)、2019A-Q11(b)、2021A-Q8(d)、2023A-Q12(b)；2023A-Q13(b) 同理，但单件概率来自均匀分布。

## 题型 6：路径 / 组合计数类（robot、Lucky 7）

**思路**：先把事件翻译成「成功次数」的条件。比如机器人回到原点 ⇔ 前进次数 = 后退次数（奇数步不可能回到原点，概率为 0，理由要写出来）；向前 ≥ 20 cm ⇔ 前进次数 − 后退次数 ≥ 4 ⇔ 10 步中前进 ≥ 7 次，再用二项分布计算（P ≈ 0.3823）。

**真题**：2025A-Q15。相关的计数或几何概率：2021A-Q10(b)（列出和 ≥ 7 的组合，加权求和得 p = 7/24，不用二项）、2023A-Q13(a)（θ 均匀分布，几何概率 α/π）。
