## 阅卷组提醒

- **区分 pdf 和累积分布函数**（2023 报告：pdf 和 cdf 混用很普遍）。
- 求 k 或证 k 时，都要先写「总面积 = 1」再解，不能只写结果（2023A-Q11(a) 有 1 分给 "area under the curve must equal 1"；2025F-Q4(a) key：no mark for simply writing the value of k without justification）。
- 要能**说出分布的名字**（2021 报告：CF 的连续概率题里，分布名称是失分点；2021F-Q2(a) 的 key 答案是 "continuous uniform distribution"）。
- 期望值要换算成语境里的单位或时刻：小时转分钟；E(B) = 3.8 h after noon 写成 3:48 pm（2023A-Q11(c)）。2017A-Q11、2023A-Q11 都有 1 分专门给换算。方差的单位是平方单位（如 L²），也要写（2022A-Q8(a) key：units for both expected value and variance）。
- 题目指定精度（三位小数、exact、整数）时严格照办（如 2022A-Q12(a) 有 1 分给 rounds to three decimal places）；没有指定时至少保留 4 位小数（2020 报告），中间步骤不要只取 2 位。百分比题要换成百分数。

## 题型 1：相对频率直方图 → 概率（CF）

**思路**：概率 = 对应柱子的相对频率之和；区间端点落在柱子中间时，**按均匀分布线性插值**（2023F-Q3(c) 的 key 就是这样）。条件概率 = 交集 ÷ 条件。三天都准时 = p³（假设独立）。
- **频数**直方图要先除以总数换成概率（2023F-Q3：20 个太阳能场）。
- 累积概率表 P(W ≤ w) 与单个概率要分清（2023 报告 CF 部分点名）。
- 期望估计：E ≈ Σ 组中值 × 概率（2023F-Q3(c)(ii)、2024A-Q13(e)）。
- 线性插值的前提是题目写明 "assuming … uniformly distributed within each interval"。

**真题**：2017F-Q1、2020F-Q4(a)(b)、2023F-Q3、2024A-Q13(e)。

## 题型 2：pdf 的基本运算 ★

**四件套公式**
- 总面积：∫f(x)dx = 1（用来求 k 或 a）；
- 概率：P(a < X < b) = ∫ₐᵇ f(x)dx；
- 期望：E(X) = ∫x f(x)dx；方差：Var(X) = ∫x² f(x)dx − μ²，或 ∫(x − μ)² f(x)dx；
- 中位数 M：∫_{下界}^{M} f(x)dx = 0.5（分位数同理）。
- **已知累积分布函数 F(x) = P(X ≤ x)**：P(a < X ≤ b) = F(b) − F(a)；pdf = F′(x)（2023A-Q11(d)(e)：key 给「表示成 P(A ≤ 4) − P(A ≤ 3)」和「求出 pdf」各 1 分）。

**CF 技巧**
- pdf 由直线段组成时，**用三角形/梯形面积代替积分**（2019F-Q3、2022F-Q3、2025F-Q4 的 key 都接受）。
- 分段 pdf：每段分别积分；求后半段的 k 时，令后半段面积 = 1 − 前半段面积（2020F-Q4(d)）。
- 例（2025F-Q1）：f(x) = 1/(x ln 5)，1 ≤ x ≤ 5。E(X) = ∫₁⁵ 1/ln5 dx = **4/ln 5**；中位数：ln M / ln 5 = ½ ⇒ **M = √5**。

**CA 技巧**：写出积分式（1 分），再让 CAS 计算；求 c 使 P(X > c) = 0.01 时写方程 ∫_c^1 f = 0.01（2022A-Q8(b)，单位 10 000 L，最后换算到「最接近的升」）。

**得分点**：✓ 正确的积分表达式（含上下限）✓ 计算 ✓ 单位或时间换算。

**真题**：2017A-Q11、2018A-Q10、2019F-Q3、2020F-Q4(c)(d)、2022A-Q8、2022F-Q6(b)、2023A-Q11、2025A-Q13(c)(d)、2025F-Q1、2025F-Q4。

## 题型 3：均匀分布

**公式**：X ~ U(a, b)：f(x) = 1/(b − a)（a ≤ x ≤ b；其他处为 0）；E(X) = (a + b)/2；Var(X) = (b − a)²/12。
**注意**：公式表只列了 Var(X) = ∫(x − μ)²p(x)dx，**没有** (b − a)²/12。key 的给分是「写出 pdf 及定义域」+「写出方差的积分式」+「算出结果」（2024F-Q4(a)、2019F-Q6(e)、2016A-Q16(b)）。所以 (b − a)²/12 只用来验算，正式作答要写积分。

**常见变形**
- 已知 E(X) = 6、最大值 9 ⇒ 最小值 3 ⇒ f(x) = 1/6，3 ≤ x ≤ 9 ⇒ Var = ∫₃⁹ (x − 6)²·(1/6) dx = **3**（2024F-Q4(a)；可用 6²/12 = 3 验算）。
- 条件概率：P(X < −0.35 | X < 0) = 0.15/0.5（2019F-Q6(c)）。
- 「平方小于 0.09」⇒ −0.3 < X < 0.3（2019F-Q6(d)，key 有一分给「用 X 表达所求概率」）。
- 「在 3 天里恰好 2 天……」⇒ 先求单天概率，再用 Bin(3, p)（2025F-Q4(c)）。
- 「最晚几点出发才能使迟到概率不超过 4%」⇒ 从分布右端截掉 4% 的面积（2021F-Q2(d)）。

**真题**：2016A-Q16、2017F-Q2、2019F-Q6、2021F-Q2、2024F-Q4(a)、2023A-Q13(a)。

## 题型 4：正态分布 — 正向求概率与反向求分位点

**思路**
1. 写出概率表达式：P(X > 3.7)、P(395 < X < 405)（多数 key 单独给 1 分，所以一律先写）。
2. CAS normCdf 计算，按要求取小数位或换成百分数。
3. 反向：「heaviest 0.05%」⇒ P(X > m) = 0.0005 ⇒ invNorm(0.9995)；「top 1%」同理。
4. 条件概率：P(X < 75 | X > 67) = P(67 < X < 75) / P(X > 67)（2020A-Q8(b)，key 有一分给「认识到被限制在 jumbo 范围内」）。
5. 单位变换：Y = aX + b ⇒ μ_Y = aμ + b，σ_Y = |a|σ，Var(Y) = a²Var(X)（°C → °F、km → mile；2024A-Q13(c) 问的是方差）。反向：已知 μ_Y、σ_Y，列方程求 a、b（2025A-Q10(f)）。

**真题**：2016SA-Q12（样卷）、2017A-Q19、2018A-Q12(a)、2019A-Q11、2020A-Q8、2021A-Q8、2022A-Q12(a)、2024A-Q13、2025A-Q10。

## 题型 5：由两个概率反求 μ 和 σ ★

**识别**：已知两个尾部概率，求均值和标准差。例如 2016A-Q18：passengers wait for less than 55 minutes, 5% of the time, while there is a 13% chance that the waiting times will be greater than 100 minutes。

**固定三步（key 的得分点）**
1. 分别求两个 z 值（单独 1 分）：z₁ = invNorm(0.05) = −1.6449，z₂ = invNorm(0.87) = 1.1264。
2. 列方程组：μ − 1.6449σ = 55，μ + 1.1264σ = 100。
3. 解得 σ ≈ 16.24，μ ≈ 81.71（2016A-Q18）。

另一例（2023A-Q12）：P(X ≤ 150) = 0.0228 ⇒ z = −2，P(X ≥ 165) = 0.1587 ⇒ z = 1 ⇒ σ = 5，μ = 160（0.0228 和 0.1587 恰好是 z = −2 和 z = 1 的精确尾概率，所以 z 可以取整）。
只知道均值时：一个 z 值就够（2024A-Q13(a)、2019A-Q11(d)）。

**真题**：2016A-Q18、2019A-Q11(d)、2023A-Q12(a)、2024A-Q13(a)、2025A-Q10(e)。

## 题型 6：68–95–99.7 规则（CF）

**思路**：把数值换成「均值 ± k 个标准差」：163 ± 3×7 = 142 到 184 ⇒ 约 99.7%；170 = μ + σ ⇒ 大于它约 16%；最矮的 2.5% 在 μ − 2σ 以下。
**图像题（2021F-Q6）**：曲线越矮越宽，标准差越大；P(6 ≤ X ≤ 9) 是否 ≥ 0.5：key 的理由是「总面积 = 1，阴影明显不到一半」。也可以这样论证：μ = 7、σ ≈ 3，区间宽度 3 = σ，而宽为 σ 的区间概率最大也只有 P(μ − σ/2 < X < μ + σ/2) ≈ 0.38 < 0.5。连续分布 P(Y = 2) = 0，所以 P(Y ≥ 2) > P(Y > 2) 说明 Y 不可能是正态，但可以是二项。

**真题**：2018F-Q2、2021F-Q6。
