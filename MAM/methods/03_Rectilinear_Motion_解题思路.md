# MAM · 直线运动 — 题型与解题思路

> 依据：2016–2025 共 13 道直线运动真题的 marking key + 考试报告（2018、2024、2025 报告明确把直线运动列为弱项；2021 报告提醒区分 distance 与 displacement；2023 报告点名 signed area 与 dt 记号）。原题见 `topics/03_Rectilinear_Motion.pdf`。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 概念速查（报告说这里概念最容易混）

| 量 | 定义 | 注意 |
|---|---|---|
| 位移 x(t) | 相对原点的位置，有正负 | 「回到出发点」是 x(t) = x(0)，不是 v = 0 |
| 速度 v = x′(t) | 有正负（方向） | 「at rest」是 v = 0；「changes direction」是 v 变号 |
| 速率 speed = \|v\| | 非负 | 最大速率要比较极值点**和**端点的 \|v\| |
| 加速度 a = v′(t) | 有正负 | 速度在区间**内部**取极值处必有 a = 0；反过来不一定（如 v = t³ 在 t = 0；匀速段 a 恒为 0），端点另外比较 |
| 位移变化 = ∫ₐᵇ v dt | 有向面积 | 「signed area 代表什么」= change in displacement from t=a to t=b |
| 路程 = ∫ₐᵇ \|v\| dt | 非负 | 要在 v = 0 处分段 |

**加速还是减速**：v 与 a **同号**是 speeding up，**异号**是 slowing down。2024F-Q2 的 key 原话：只说 acceleration is negative 不算正确理由。
**注意**：2018A-Q11(c) 的 key 把 "heading south and decelerating at 0.5" 处理成 a = −0.5（按上面的定义，此时 v、a 同号，其实是在加速）。遇到这类措辞时，写清自己的理解，并注明正方向。

**时间用词**：「when it first appears」「initially」是 t = 0（2024 报告：很多人误代了 t = 1）；「during the fifth second」是 4 ≤ t ≤ 5。

## 题型 1：已知 x(t)，求 v、a 及其意义

**思路**：求导得 v；再求导得 a；代入所问时刻；**写单位**；解释时说清方向（正方向指什么，比如向北、向上、向右（2024F-Q2 中 x 是到屏幕左边缘的距离，key 写 "to the right"））。

**得分点**：✓ v(t) 表达式 ✓ 代值（含单位）✓ a(t) 表达式 ✓ 结论加理由（同号/异号）。

**真题**：2016F-Q4、2016A-Q19(a)、2022A-Q10(b)、2024F-Q2(a)(b)。

---

## 题型 2：已知 a(t) 或 v(t)，用初始条件反推

**识别**：「initial velocity is 5 cm/s」「x(0) = 0」「After 2 seconds displacement is −50 cm」，求常数 p、k。

**思路**
1. 积分 a → v（**+c**）→ 用 v(0) 定 c。
2. 再积分 v → x（**+c₂**）→ 用已知位置定 c₂。
3. 方程里含未知参数 p 时：把两个位置条件各写成一个方程，联立解 p 和常数（2017A-Q20）。
4. 三角形式的 v（如 v = 2 sin(t/3 + π/6)）积分时要除以内层系数 1/3，即乘 3，得 −6cos(t/3 + π/6) + C；计算器设弧度制。

**得分点（2018A-Q11(a)）**：✓ 积分得到 cos 形式 ✓ 写出常数并用 x(0) = 0 列方程 ✓ 求出 C 并写出 x(t)。

**真题**：2017A-Q20(b)、2018A-Q11、2019A-Q9(c)、2021A-Q17(a)、2022A-Q11(c)、2023A-Q8(e)（比较系数求 A、B）。

## 题型 3：何时静止 / 改变方向 / 回到出发点

**思路**
- 静止：解 v(t) = 0。改变方向：v 必须**变号**（要检查 v 在该点前后是否真的变号；如果 v 只是碰到 0 又回到原来的符号，例如 v = (t − 2)²，物体没有改变方向）。
- 回到出发点：解 x(t) = x(0)；经过原点：解 x(t) = 0（只有 x(0) = 0 时两者相同）。取题目要的「first」那一个正根。
- 只有符号表时（2025F-Q6）：x 变号 → 经过原点；v 变号 → 停下并转向；v、a 异号 → 减速。解释时要说出依据是「v 的符号改变」。

**真题**：2016A-Q19(a)、2017A-Q20(c)、2021A-Q17(b)、2022A-Q10(a)(c)、2023A-Q8(a)、2025F-Q6。

## 题型 4：总路程 vs 位移 ★ 必考

**识别**：「total distance travelled」「How far has … travelled」（问的是路程）vs「Evaluate ∫v dt and explain」（问的是位移变化）。

**标准流程（总路程）**
1. 解 v = 0，找出区间内所有停下的时刻 t₁, t₂…
2. 写路程表达式，两种写法都可以：
   - |x(t₁) − x(0)| + |x(t₂) − x(t₁)| + …（2024F-Q2(d) 的 key 写法）；
   - ∫|v(t)| dt，或者分段积分：**在 v < 0 的那一段前加负号**（或每段外面加绝对值）。2023A-Q8(c) 中 v = −2t sin t，在 (π/3, π) 上为负、在 (π, 4π/3) 上为正，所以写成 −∫_{π/3}^{π} v dt + ∫_{π}^{4π/3} v dt。key 对正负号单独给 1 分，**每个积分都要带 dt** 也有 1 分。
3. 计算并带单位。

**解释 ∫ₐᵇ v dt**：「the change in displacement (position) of … from t = a s to t = b s」——起止时刻也要写（2024F-Q2(c) 有 1 分专门给起止时刻）。

**得分点**：✓ 求停止时刻 ✓ 正确的分段表达式 ✓ 数值。

**易错**：直接 x(15) − x(0) 当作路程；分段时漏掉中间的转向点。

**真题**：2016A-Q19(b)(d)、2017A-Q20(d)、2018A-Q11(c)、2021A-Q14、2021A-Q17(c)、2023A-Q8(b)(c)、2024F-Q2(c)(d)。

## 题型 5：速度的最大值 / 加速度为零

**思路**：令 a(t) = v′(t) = 0 求出 t → 代入 v → **验证最大**：用 v″ < 0（或符号检验）确认，题目要求 using calculus 时这一步有分（2022A-Q11(b) key：confirms that v″ < 0）；问区间上的最大值时，再和端点比较。问最大**速率**时，还要比较端点处的 |v|（2016A-Q19(c) 的 key：examines velocity at endpoints）。

**真题**：2016A-Q19(c)、2022A-Q11(b)、2023A-Q8(d)、2021A-Q14、2019A-Q12(c)（前 2 分钟匀速，a 恒为 0，并不是极值）。

## 题型 6：语境与图像解读

**识别**：给出 a(t) 或 v(t) 的图像，问「explain what is happening to the velocity in 0 < t < 8」。

**写法**：「Since a(t) > 0 for 0 < t < 8, the (upward) velocity is increasing; since a(t) < 0 for 8 < t < 16, the velocity is decreasing (but still positive, still moving up).」评分要求：✓ 引用 a 的图像或符号 ✓ 前半段结论 ✓ 后半段结论。

**作图（2025F-Q6(d)）**：x(t) 图要同时满足 x、v、a 三套符号：从原点出发、初始斜率为正，只在 3 < t < 4 之间穿过 t 轴；斜率符号对应 v，凹凸对应 a。

**真题**：2019A-Q9(a)(b)、2025F-Q6(d)、2022A-Q10(d)（振幅包络 3e⁻ᵗ = 0.01）。
