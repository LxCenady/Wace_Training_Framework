# MAM Solution Approaches · Independent Review Record

**Review method**: Each handout is reviewed by an independent sub-agent. The reviewer was not involved in writing, works from a fresh context, and only reads, does not edit. The verification basis includes: the original text of the "Specific behaviours" in each question's marking key in `evidence/`, the full text of the 2016–2025 exam reports, the PDF pages of the original papers and keys, and independent verification using sympy/scipy.

**Handling principles**: The editor checks each review comment one by one. All high-severity comments were only modified after returning to the original exam text for verification; anything that could be verified by calculation was checked. For items marked "Doubtful" by the reviewer, changes were made only when supporting evidence could be found.

**Conclusion categories**: Accepted = modified as per comment; Partially accepted = wording changed but advice not fully followed; Rejected = not changed, with reasons stated.
