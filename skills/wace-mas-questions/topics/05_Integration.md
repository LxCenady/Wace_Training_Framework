# I · Integration techniques & applications 积分技巧与应用 (Unit 4.1)

Bank: `<ROOT>\MAS\topics\05_Integration.md` / `.pdf` — 44 questions, 284 marks (25 CF / 14 CA primary).

## Scope
- Substitution (given u; also x = tan u, x = 2 sin θ, x = 119u + 1 type linear), changing limits.
- Trig integrals with identities: sin², cos², sin·cos powers, product-to-sum (2019 F1), (sin x + cos x)² (2022 F3).
- Partial fractions: distinct linear, repeated linear (2019 F3, 2024 F4), irreducible quadratic (2020 F6, 2021 F5, 2022 F4); ∫1/(x² + a²) style via the inverse-tan derivative.
- Areas: between curves, with respect to y, implicitly defined curves, circles/ellipses (2025 A8), heart curve (2021 F8).
- Volumes of revolution about the x- and y-axes (glasses, vases, donut torus, spherical cap); depth for a given fraction of volume (2020 A9).
- Numerical evaluation on CAS for awkward integrals.

## How SCSA asks it
- CF: "Using the substitution …, evaluate exactly" (2017 F3, 2018 F5, 2019 F6, 2020 F7, 2021 F3, 2023 F3, 2023 F7, 2024 F3, 2025 F6); partial fractions then integrate (2016 F4, 2018 F6, 2019 F3, 2021 F5, 2022 F4, 2024 F4); volume of a glass as an integral (2017 F8, 2019 F8).
- CA: tangent + area + volume (2016 A17, 2018 A15), ∫x(1 + x)ⁿ by substitution (2016 A9), area of an implicit curve (2020 A16), sphere cap (2021 A13), torus nutrition (2024 A11), milkshake glass V = a h^(3/2) with related rates (2025 A14).

## Writing tips
- CF substitution must transform limits to nice values and leave a standard integral.
- Volume keys: ✓ correct formula π∫x²dy or π∫y²dx, ✓ limits, ✓ integrand in correct variable, ✓ value.
