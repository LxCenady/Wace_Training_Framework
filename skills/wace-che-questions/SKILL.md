## wace.db queries

Pattern code format: `CHE.<TOPIC>.<n>`, which equals catalogue ID `<TOPIC><n>` (for example `CHE.EQ.4` = `EQ4`, and `CHE.QNT.1` = `QNT1`).

- similar past questions: `SELECT DISTINCT qid FROM part_patterns WHERE pattern='CHE.EQ.4'`
- the pattern's method text: `SELECT title, method FROM patterns WHERE code='CHE.EQ.4'`
- marks a pattern carried in real questions: `SELECT qid, marks FROM pattern_marks WHERE pattern='CHE.EQ.4'`
- one-row-per-mark marking scheme: `SELECT label, text FROM points WHERE qid='<qid>' ORDER BY ord`. Trust it only when `SELECT points_ok FROM questions WHERE id='<qid>'` is 1; otherwise read the key PDF crop.
- restrict to Chemistry: `JOIN questions q ON q.id = pp.qid WHERE q.subject='CHE'`

## Paper format (verified from the 2016–2025 exam headers)

- **Whole paper**: 10 minutes reading time, 180 minutes working time, Chemistry Data booklet supplied (not to be handed in), question numbers run continuously across the sections.
- **Section One: Multiple-choice**: 25% (25 marks), 25 questions, all answered on the separate answer sheet, suggested 50 minutes. Not in the bank. The generator may write MC questions when asked (four options, one answer, a short justification in the key).
- **Section Two: Short answer**: 35% weight, suggested 60 minutes, 8–12 questions (2016 12, 2017 10, 2018 9, 2019 10, 2020 9, 2021 8, 2022 8, 2023 9, 2024 10, 2025 9). Raw marks: 83, 85, 79, 106, 76, 76, 71, 79, 81, 65.
- **Section Three: Extended answer**: 40% weight, suggested 70 minutes, 5–6 questions (2016 5, 2017 5, 2018 6, 2019 6, 2020 6, 2021 6, 2022 6, 2023 5, 2024 5, 2025 6). Raw marks: 85, 100, 94, 109, 88, 90, 90, 86, 87, 113.
- Raw totals differ by year (for SA + ER: 168, 185, 173, 215, 164, 166, 161, 165, 168, 178). Only the 25/35/40 weights are fixed. Do not write a raw total as a constant.
- Question headers: `Question N (x marks)`. Parts are `(a)`, `(b)`, with roman sub-parts `(i)`, `(ii)`. Parts sum to the question total (checked for all 150 bank questions).
- Question totals (2016–2025): SA 4–15 marks (median 8); ER 10–29 marks (median 16.5). ER questions are mostly multi-context (one scenario, several parts) and often carry a table, a titration result set, a diagram or a structure to complete.

## Workflow

1. **Pin down the request.** Topic(s), number of questions, section (default: SA for single-concept parts, ER for multi-step contexts), difficulty (基础 / 中等 / 压轴 ≈ early / mid / last part of a question), language (default English, like the paper; explanations in Chinese if the user writes Chinese). State the defaults you used rather than asking.
2. **Calibrate.** Read `topics/<NN_Topic>.md` for the topic. Pick the pattern(s) each question will test. Then find 2–4 past questions carrying the same pattern (`SELECT DISTINCT qid FROM part_patterns WHERE pattern='CHE.<TOPIC>.<n>'`), then read their stems in `questions.stem` (and the key PDF if the mark split matters). Do not copy or lightly reword any of them.
3. **Write original questions.** New context, new numbers, new structure. Use the SCSA voice: "Write an equation…", "Draw…", "Complete the table…", "Describe the observations…", "Explain…", "Justify your answer…", "Calculate… to three significant figures". Use Australian, everyday contexts (sport drinks, pool chemistry, stormwater, car batteries, bread-making, food preservation, mining, fertiliser). Number parts (a), (b)(i) with marks per part. Header: `Question N (x marks)`.
   - Give every numerical datum with its unit. Use the year's data booklet constants (or state any constant you use in the stem).
   - Keep structures, diagrams and tables fully specified in text (for example an edge list or a labelled table); say a figure is needed if one is.
4. **Write the marking key** in the SCSA Description/Marks format, one row per mark, then a `Total` row (see Conventions).
5. **Verify before showing.** Check each item below and say which ran.
   - Equations: every atom balanced; charge balanced for ionic equations; species correct for the stated conditions (acid or base); state symbols as the question requires.
   - Calculations: recompute every number with `fractions` or `decimal`, at the precision the stem gives. Significant figures and units follow the least precise datum given (state the rule in the key if it matters).
   - Mole ratios: check from the balanced equation (for example moles of product ≤ limiting reagent moles). For titrations, check the aliquot-to-flask scaling and that the titres used are concordant.
   - Observations: colour before and after, precipitate, gas evolution (effervescence or bubbles), no chemical names, no arrows.
   - Structures: every carbon has the right number of bonds; all H shown when the question asks for full structures; functional group correct.
   - Equilibrium and electrochemistry direction: the predicted shift matches the colour change and the cell's electron flow; E° cell is positive for a spontaneous reaction.
   - Report the result as: "Verified: balance ✓, charge ✓, sig figs ✓, units ✓, mole ratio ✓, observations ✓, structures ✓" with any item not applicable marked as such. Do not claim a check that did not run.
6. **Output.** Questions first, then a separator, then the marking key, so the user can attempt first. Use LaTeX for maths and chemical equations in a readable form (for example `$\mathrm{Mg(s)} + 2\,\mathrm{H^+(aq)}$`). After the key, one line per question: "最接近的真题: 2019 SA Q31 (CHE/questions.json; key CHE/papers/2019_CHE_MarkingKey.pdf)". If the user wants a file, save to `<ROOT>\generated\CHE\<topic>_<YYYYMMDD>.md`.

## Conventions every key must follow

- Format: a `Solution` line (optional) then a Description / Marks table. One row per mark (or per mark group, as the key uses 1–2 mark ranges). End with a `Total` row. Keep part marks summing to the question total.
- Alternatives: `or` between equally acceptable answers; `Accept other relevant answers` for open answers; `Any two of the following` / `Any three of …` for lists, with the list length as the cap.
- Reduced awards: say the maximum explicitly in a `Note:` line, for example "maximum 1 mark for correct and balanced molecular equations", "minor error: maximum 1 mark per structure", "inaccurate connectivity: maximum 1 mark per structure".
- Follow-through: a later mark can follow an earlier wrong value only if the earlier step has some merit, as the key states it ("Equation must have some merit for follow through marks").
- Equations: species, balancing (atoms, then charge for ionic) and state symbols. State symbols are required only where the question asks; keys commonly note they are not needed for full marks.
- Observations: name colours of the reagents before mixing and the change in the products; include a precipitate or gas when it forms; never name the chemicals; no "colourless gas" without evidence of effervescence or bubbles; "clear solution" is accepted only with the colour stated; no arrows in written answers (describe increase or decrease in words).
- Equilibrium predictions: the colour change must agree with the stated shift direction. Do not use arrows for left, right, increase or decrease.
- Numbers: units and sig figs on final answers; each number must say what it represents (examiners penalise bare numbers).
- Structures: full structural formulae showing the bonds and H as the question requires; no marks off for a correct full structure drawn in a different but valid form.
- Explanations: name the variable, the direction of change, the particle-level reason (collision frequency, energy, bond strength, intermolecular force), and the context. Generic words ("it is more reactive") earn nothing.

## Explain mode

## Known caveats (keep generated keys honest)

- **2025 SA/ER titration data (Q38(d) in the 2025 paper)**: the official key and the public examiners' report disagree on which titration results to use (per `CHE/README.md`). Do not write a titration question that depends on which trial is discarded, or state the rule explicitly in the stem.
- **Marks per pattern are rough**: `tools/catalogue_CHE.json` is still `draft_for_review`, and multi-pattern parts split their marks equally. Treat the typical marks in the topic files as guides, not as fixed values.
- **Section One is not tagged**: do not infer MC topic balance from the bank.
- **Data booklet**: values differ by year in principle. Quote the constant you use, or state it in the stem.
- **Keys**: the descriptions in `tools/catalogue_CHE.json` are generator descriptions, not SCSA wording. Quote no key text; write keys from the rules above.
- **Method notes**: `CHE/methods/` is incomplete; cite a note only if its file exists, and only by path.
