## 题型 1：狭义相对论的两条基本假设

**大纲编号**：S26-U3-SU-15 / S27-U3-SU-15

**考查频率**：3/10 个考试年份出现；共 9 分。

**分数奖励的是**：知识回忆 3 分，最终答案 2 分，定性解释 2 分，选择原理或关系式 1 分，代入与计算过程 1 分

**真题**：2016R-4(b)；2017R-5(d)；2017R-7；2023P-14(aii)；2023R-9

**要点**：本考点考查狭义相对论的两条基本假设：真空中的光速对所有观测者都相同，物理定律在所有惯性系中形式相同。考题通常以简短回忆假设、选择题或简答题（询问不同光源或颜色的光被观测到的速度）出现，也会出现推理题，要求将静止观测者与运动观测者对光传播的测量联系起来。

**识别**：注意题目中出现惯性系、以恒定速度运动的观测者、运动或远处光源发出的光，或两位观测者分别测量同一束信号在两点间传播的情况。若题目问“相对论基于哪两条假设”或“为什么两位观测者测得的速度相同”，则直接考查本点。凡答案取决于光速是否随光源、颜色或观测者运动而改变的题目，都需要用到这两条假设。

**步骤**

1. 用自己的话陈述两条假设：真空中的光速 c 对所有观测者相同；物理定律在所有惯性系中相同。
2. 对光信号，分别在每个参考系中确定该观测者自己测得的传播距离和所用时间。
3. 在每个参考系中应用 速度 = 距离 / 时间：静止观测者 c = d/t，运动观测者 c = d'/t'。
4. 由于两位观测者测得的都是同一个 c，将两式联立，并整理出待求量。
5. 对于光源或颜色相关的问题，得出测得的光速与发光体的运动无关，因此各种情况下光速相同。
6. 对于两个相对运动的观测者的对称性问题，论证不存在优选参考系，因此相对速度的大小从任一方测得都相同，只是方向相反。

**得分点**

- KNOW 的满分要求清楚写出两条假设，分别说明光速恒定和惯性系等价。
- ANSWER 的一分来自选出“光速与光源或颜色无关”的选项，而不是依据波长猜测。
- PRINCIPLE 的一分来自写出每位观测者测得的速度都等于 c，将假设与测量结果联系起来。
- CALC 的一分来自正确变形速度关系式，使待求量单独成为主项。
- EXPLAIN 的分数来自指出不存在优选参考系以及对称性论证，每一点都应作为独立且有依据的陈述给出。

**易错点**

- 只写“光速恒定”，而没有说明它对所有观测者都相同，从而失去与参考系相关的要点。
- 选择“运动光源发出的光更快或更慢”之类的选项，因为光源的速度不会改变所测得的 c。
- 混淆静止系与运动系，对两位观测者使用同一组距离或时间，而不是各自的测量值。
- 声称存在“优选参考系”或“以太”，这与第二条假设相矛盾。
- 给出速度大小相等的理由时没有提到对称性或不存在优选参考系，解释不完整。

## 题型 2：高速运动与牛顿力学的局限

**大纲编号**：S26-U3-SU-16 / S27-U3-SU-16

**考查频率**：1/10 个考试年份出现；共 1 分。

**分数奖励的是**：图像处理 1 分

**真题**：2025R-10

**要点**：本知识点考查牛顿力学在物体速度极高时为何失效，常见考点是相对论动能以及速度趋近光速c时的变化。由于抽样的历年试卷中只有一道小题，该点很少单独考查，通常是一道结合动能-速度图像与题纸公式表中公式进行解释的简答题。

**识别**：题目通常给出动能（或动量、质量）随速度变化的图像或表格，要求解释为什么有质量的物体不能达到光速，或比较牛顿公式与高速下的实际表现。出现“解释”一词并配有图像或公式，是典型信号。

**步骤**

1. 回忆牛顿动能公式 E_k = 1/2 mv^2，它在任何速度下（包括接近c时）都给出有限的能量。
2. 回忆相对论动能公式 E_k = (γ - 1)mc^2，其中 γ = 1 / √(1 - v^2/c^2)，该式可在公式与数据手册中查到。
3. 分析速度趋近c时的情况：1 - v^2/c^2 趋近于0，因此 γ 趋于无穷大，E_k 无限增大。
4. 读图：曲线陡升并以竖直线 v = c 为渐近线，说明当 v 趋近 c 时 E_k 趋于无穷。
5. 得出结论：有质量的物体要达到c需要无限的能量，这在物理上不可能，因此有质量的物体不能达到光速。
6. 指出牛顿模型在高速下不适用，因为它给出光速处仍为有限的能量，与观测不符。

**得分点**

- 一分通常给在指出随速度趋近c，E_k 趋于无穷（图像以 v = c 为渐近线）。
- 其余分数通常给在把无限能量与无法达到c联系起来，并利用相对论公式或 γ 因子作论证。
- 写出手册中的相对论公式本身会得分，单纯断言“光速是速度上限”不够。
- 得分点通常要求结论是由图像或公式推出的结果，而不是孤立的描述。

**易错点**

- 只说能量“很大”或“非常大”，而没有指出它趋于无穷，会丢掉关键分。
- 描述图像时没有把渐近线与光速联系起来。
- 把牛顿公式当作原因，而忽略了关键在于它在高速下失效。
- 以“物体太重难以加速”代替对无限能量极限的解释。
- 漏写结论，即有质量的物体不能达到光速c。

## 题型 3：同时的相对性

**大纲编号**：S26-U3-SU-17 / S27-U3-SU-17

**考查频率**：2/10 个考试年份出现；共 6 分。

**分数奖励的是**：定性解释 6 分

**真题**：2019R-11(c)；2022R-11(c)

**要点**：本考点考查：在一个惯性参考系中同时发生的两个事件，在另一个惯性参考系中是否仍然同时。在历年试题中通常以简短的 EXPLAIN 题出现，常要求解释两位观察者对运动物体长度得出看似矛盾的测量结果，答案关键在于“同时”因观察者而异。

**识别**：题目中有两个相对运动的惯性观察者，并且测量需要同一时刻记录两端或两个事件的位置，例如运动物体能否放进两个标记之间，或两人为何得到不同长度。常见关键词：simultaneously（同时）、at the same time（同一时刻）、contradictory results（结果矛盾）、both be correct（两者都正确）。

**步骤**

1. 明确测量步骤：在观察者自己的参考系中，同一时刻记录物体两端的位置，才得到长度。
2. 确定两个事件在哪个参考系中同时发生（该系中 Δt = 0），并求出两事件之间的空间间隔 Δx。
3. 对以速度 v 相对运动的第二个参考系，应用时间的洛伦兹变换：Δt' = γ(Δt − vΔx/c²)，其中 γ = 1/√(1 − v²/c²)。
4. 说明只要 Δx ≠ 0，就有 Δt' ≠ 0，因此两事件在另一参考系中不同时发生。沿运动方向更靠前的事件，在运动系中的计时更早。
5. 将其与长度联系起来：两位观察者取两端位置所对应的时刻不同，运动物体的长度为 L = L0/γ（运动观察者的测量结果），另一观察者由此得到的“能否放入”结论随之不同。
6. 结论：两人的结果都正确，都是在各自参考系中自洽的测量。分歧来自对“同时”的不同定义，而不是测量错误。

**得分点**

- 一分：指出测量长度需要在观察者自身参考系中同时确定物体两端的位置。
- 一分：指出同时性与参考系有关，因此两位观察者对“同一时刻”的理解不同。
- 一分：将非同时性与所得长度的不同联系起来，可使用长度收缩 L = L0/γ 或变换后的时间差。
- 一分：明确结论，说明两位观察者在各自的参考系中都是正确的。

**易错点**

- 把事件理解为在现实中先后发生的不同时刻，而不是“在一个系中同时、在另一个系中不同时”。
- 只用时间膨胀解释分歧，而忽略了测量的非同时性才是关键。
- 只写长度收缩，却不解释为何测量过程依赖同时性。
- 断言某位观察者出错，或认为某一测量结果才是“真实”的。两者在各自参考系中都有效。
- 沿用日常的绝对时间观念，认为所有人对同时性的判断相同，从而丢失答案的核心。

## 题型 4：时间膨胀与长度收缩

**大纲编号**：S26-U3-SU-18 / S27-U3-SU-18

**考查频率**：10/10 个考试年份出现；共 93 分。

**分数奖励的是**：选择原理或关系式 26 分，最终答案 23 分，代入与计算过程 21 分，定性解释 13 分，单位、有效数字与方向 5 分，知识回忆 2 分，图像处理 2 分，评价与结论 1 分

**真题**：2016R-12(a)；2016R-12(b)；2016R-7；2017P-17(bi)；2017P-17(bii)；2017P-17(biii)；2017R-2；2018P-16(a)；2018P-16(b)；2018P-16(c)；2018P-16(d)；2019P-15(d)；2019R-11(a)；2019R-11(b)；2019R-11(c)；2019R-9；2020P-14(ci)；2020P-14(cii)；2020P-14(d)；2020P-14(e)；2020P-15(a)；2020P-15(b)；2020P-15(c)；2021P-18(c)…

**要点**：本考点考查时间和长度依赖于观察者参考系：相对于不静止的观察者，运动的时钟走得慢，运动物体沿运动方向变短，并可用相对论速度叠加公式合成速度。试卷中通常以多小题计算形式出现，把速度或时间的结果代入下一步求距离或行程时间，也会配以简短的解释题，说明观察者为什么会看到这种现象。

**识别**：注意题中是否出现两个参考系（如地球与飞船、μ子与地面观察者、两艘相向或相背飞行的飞船），速度以 c 的倍数给出，题目给出某一参考系中的固有时间或固有长度，却要求在另一参考系中求值，或出现“以……测量”“从……观察”“在……参考系中”等措辞。要求解释为何粒子或时钟的表现与经典预测不同的题目也属于此类。

**步骤**

1. 先确定每个量所属的参考系：固有时间 t0 或固有长度 l0 是在时钟或物体静止的参考系中测得的；题目所问的量则是在另一参考系中测得的。
2. 求时间时用 t = t0 / √(1 − v²/c²)，使看到运动时钟的观察者测得更长的时间间隔；求长度时用 l = l0 √(1 − v²/c²)，使运动物体沿运动方向显得更短。
3. 同一直线上的两个速度用 u = (u′ + v)/(1 + u′v/c²) 合成，其中 u′ 是运动参考系中的速度，v 是该参考系相对观察者的速率；先统一规定正方向，再一致地赋予正负号。
4. 在最终结果之前，保留 1/√(1 − v²/c²) 的多位有效数字，最后按题目要求的精度取整。
5. 若结果要用于后续小题，应在正确的参考系中继续计算，例如在地球参考系中用速度乘以时间求距离，并检查结果是否小于 c。
6. 解释类小题要说明哪个量发生了膨胀或收缩、由哪位观察者测量，并把它与观测到的结果联系起来（例如粒子存活更久，或行进的距离更短）。

**得分点**

- 大部分分数给予正确地写出并运用相应的相对论关系式，之后才代入数值。
- 通常会因为正负号约定一致、并正确判断未知量属于哪个参考系而得分。
- 计算分取决于数值是否代入正确位置，包括平方根因子。
- 最终答案需要正确的单位和合理的取位；方法正确而最终数值错误时，仍能获得大部分方法分。
- 解释分奖励正确指出效应名称（时间膨胀或长度收缩）、说明观察者，并把效应与观测结果联系起来。

**易错点**

- 把固有时间或固有长度放错位置，例如把运动参考系中的数值当作 t0 或 l0 代入。
- 使用普通的速度相加，或忽略速度叠加公式分母中的项。
- 物体反向运动时符号出错，导致结果符号或大小错误。
- 只说“时间变慢”或“长度变短”而不说明是谁的测量，或在解释中遗漏测量运动长度时“同时测量两端位置”的要点。
- 单位与取位错误：km 与 m 混用、秒与年混用，或过早对洛伦兹因子取整。

## 题型 5：μ子：狭义相对论的实验证据

**大纲编号**：S26-U3-SHE-02 / S27-U3-SHE-02

**考查频率**：1/10 个考试年份出现；共 2 分。

**分数奖励的是**：定性解释 2 分

**真题**：2016R-12(b)

**要点**：本考点要求用高速 μ 子（在高空大气中产生）的实验观测，说明其支持狭义相对论。考题通常是解释题：为什么到达地面的 μ 子比经典计算预测的多。该考点在所审阅的试题中出现很少，只有一个对应小题。

**识别**：题目中出现在高空大气中产生、并能到达地面的 μ 子（或其他寿命很短的高速粒子），要求与经典预测作比较，并解释差异。关键词：高速、寿命、飞行距离、地球上的观察者、μ 子的参考系。

**步骤**

1. 写出经典预测：静止 μ 子的平均寿命很短，以接近光速运动时，飞行距离只有几百米，远小于大气层厚度，因此应当几乎全部衰变。
2. 认识到 μ 子速度接近光速 c，相对论效应显著。使用 γ = 1/√(1 − v²/c²)。
3. 地球观察者参考系：μ 子寿命变长（时间膨胀），观测寿命为 γ 倍固有寿命 τ，飞行距离为 v × γ × τ。
4. μ 子参考系：大气层厚度发生长度收缩，L = L₀/γ，因此 μ 子需要走的距离变短，得以存活到达地面。
5. 得出两个参考系结论一致：μ 子确实到达地面。观测到的数目符合相对论预测而非经典预测，因此支持狭义相对论。
6. 用文字把效应与到达地面的粒子数量联系起来，并提及实验观测结果。

**得分点**

- 给分点：指出时间膨胀（从地球参考系看寿命变长）和/或长度收缩（从 μ 子参考系看距离变短）。
- 给分点：把该效应与到达地面的 μ 子数量多于经典预测联系起来。
- 给分点：说明观测结果支持狭义相对论而非经典模型，而不只是描述现象。

**易错点**

- 描述膨胀或收缩时没有说明是哪一个观察者看到的，从而失去与参考系相关的分数。
- 说 μ 子速度变快或质量改变，而不是说寿命或距离发生变化。
- 只说 μ 子“速度快”，没有指出与之比较的经典预测。
- 直接说“因为相对论所以 μ 子到达地面”，没有把效应与观测到的数目联系起来。
- 把结果当作相对论的证明，而不是与相对论相符的证据。

## 题型 6：广义相对论现象：GPS、黑洞、引力透镜

**大纲编号**：S26-U3-SHE-03 / S27-U3-SHE-03

**考查频率**：1/10 个考试年份出现；共 2 分。

**分数奖励的是**：定性解释 2 分

**真题**：2016R-11(b)

**要点**：本考点要求学生结合现象解释广义相对论的预言：为何GPS卫星钟需要修正、黑洞的成因、引力波如何被探测，以及引力透镜如何产生。历年真题样本很少（仅见一道2分的EXPLAIN题），因此通常以简短文字解释或定性比较的形式出现，较少涉及计算。

**识别**：题目通常用文字描述现象，如卫星上的时钟、光都无法逃离的区域、两臂互相垂直的探测器、遥远恒星的光被星系弯折等，并使用explain、describe或account for等动词。除回忆概念外通常不需要数值计算。

**步骤**

1. 先确定问题涉及的效应：引力时间膨胀、黑洞、引力波或引力透镜。
2. 与弯曲时空相联系：质量和能量使时空弯曲，物体和光沿弯曲的路径运动，而不是像牛顿引力那样受到一个力的直接拉扯。
3. 对GPS时钟，比较两种效应：卫星所在处引力较弱，使时钟走得更快；卫星的轨道速度使其走得更慢（狭义相对论）。净效应是需要修正的偏差。
4. 对黑洞，使用史瓦西半径 r_s = 2GM/c^2：在此半径之内，时空弯曲极强，包括光在内的任何东西都无法逃离。
5. 对引力波，说明其在与传播方向垂直的方向上交替拉伸和压缩空间。干涉仪两臂的长度变化取决于其相对方向：一臂被拉伸而垂直的一臂被压缩时变化最大，两臂受影响相同时几乎没有变化。
6. 对引力透镜，说明光沿大质量天体附近弯曲的时空路径传播，因此观测到的光源位置发生偏移，或出现多个像。

**得分点**

- 完整的解释需要点明机制（时空弯曲）并将其与观测到的效应相联系。
- 通常会因正确陈述比较结论而得分，例如哪种效应占主导，或哪一臂被拉长、哪一臂被缩短。
- 说明引力波对两臂的影响与其传播方向的关系，而不仅仅说“改变距离”，可获得方向相关的分。
- 最后一句将原因与观测结果联系起来的清晰结论，常是第二分的必要条件。

**易错点**

- 把引力描述为直接拉扯光或时钟的力，而不提及弯曲时空。
- 忘记GPS同时需要引力效应和速度效应，只说明其中一种。
