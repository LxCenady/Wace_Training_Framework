# MAS · 复数 — 题型与解题思路

> 依据：2016–2025 共 43 道复数真题 marking key + 考试报告。原题见 `topics/01_Complex_Numbers.pdf`。数值例已用 sympy 验算。另引 2016 样卷 2 题（`2016S-F1`、`2016S-A18`，原卷见 `papers/2016Sample_*`）。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 阅卷组提醒

- **该用极坐标形式时要用**（2016 报告：(√3 − i)⁵ 不转极坐标的人吃了大亏）。乘方、开方一律用极坐标；乘除看形式而定（例如 (2+i)/(1−i)² 用共轭更快，2016F-Q2(a)）。
- **第三象限的辐角**（2020 报告点名 2020A-Q15(a)：第三象限的复数化不对极坐标）：例如 −1 − i 的主辐角是 −3π/4，不是 π/4，也不能写 5π/4（超出主值范围）。先画图确认象限。
- **复数的向量意义**（2018、2021、2025 报告：z + r、−z 的辐角、正六边形）：z + r、z − k（如 2023A-Q12）、−z 都要画成向量来做（菱形、等腰三角形、正六边形）。
- **展开括号的基本功**（2021、2023、2024 报告）：(z − (2+4i))(z − (2−4i)) = z² − 4z + 20 经常算错；z² − 2z + 3 = 0 要用配方或求根公式，**不能**拆成 (z − 3)(z + 1)。
- **确切三角值要熟**（2019、2021、2023 报告）。
- 「Show that (z − 2i) is a factor」：代入后要写出**各项的计算过程**，key 写的是「provides evidence, i.e. not just the statement P(2i) = 0」。

## 题型 1：代数形式运算与形式转换（多见于 CF）

**思路**
- 除法：分子分母同乘分母的共轭。
- 转极坐标：r = √(a² + b²)；θ 按象限确定。例：已知 z = 3 + bi 且 tan θ = 2 ⇒ b = 6，r = √45 = 3√5（2024F-Q1）。
- 高次幂：(√3 − i)⁵ = (2 cis(−π/6))⁵ = 32 cis(−5π/6) = −16√3 − 16i。key 也接受二项式展开，但要多写好几步。

**得分点**：✓ 模 ✓ 辐角 ✓ 用 De Moivre ✓ 化为 a + bi。
**真题**：2016F-Q2、2017A-Q10(a)、2019A-Q12(a)(b)、2021A-Q11(a)(b)、2024F-Q1。

## 题型 2：解 zⁿ = w（求 n 次根）★ 每年都有

**标准流程**
1. 把 w 写成 R cis φ（模 1 分、辐角 1 分）。
2. z = R^{1/n} cis((φ + 2kπ)/n)，k = 0, 1, …, n−1（写出通式 1 分）。
3. 按题目要求的范围（常见 −π < θ ≤ π）列出**全部** n 个根；相邻根的辐角相差 **2π/n**。
4. 例：z⁴ = −16i = 16 cis(−π/2) ⇒ z = 2 cis(−5π/8)、2 cis(−π/8)、2 cis(3π/8)、2 cis(7π/8)。
   z⁴ = 2 − 2√3 i = 4 cis(−π/3) ⇒ √2 cis(−7π/12)、√2 cis(−π/12)、√2 cis(5π/12)、√2 cis(11π/12)。

**变形**
- 已知一个根的图，反求 k（2025F-Q1）：w₂³ = ki。
- 根在第一象限的个数 ⇒ 求 n 的可能值，要写出理由（2017A-Q19(b)）。
- zⁿ = 1 的根：在单位圆上，等距分布，间隔 2π/n（2024A-Q9(c) 的解释 2 分：半径 1 的圆、等间隔）。
- 根的乘积（2019F-Q9）：所有根之积 = (−1)^{n+1}，n 奇数时为 1，偶数时为 −1。
- 共同根：z⁴³ = 1 与 z⁴⁷ = 1 只有 z = 1 是公共根，因为 43 与 47 互质（2021F-Q7）。

- zⁿ 为正实数（2022F-Q6(c)）：n·arg z 必须是 2π 的整数倍。z₁ = 4 cis(5π/6) ⇒ 5n/6 = 2k ⇒ 最小 n = 12，r = 4¹² = 2²⁴。

**真题**：2016A-Q14、2017A-Q19、2018F-Q7(a)、2020A-Q13、2022A-Q18(b)、2022F-Q6、2023F-Q6、2024A-Q9、2025F-Q1。

## 题型 3：多项式的复根（因式定理 + 共轭根定理）

**标准流程**
1. 「Show that (z − α) is a factor」：计算 P(α)，**写出每一项**，得到 0。
2. 实系数多项式 ⇒ 共轭 ᾱ 也是根 ⇒ (z − α)(z − ᾱ) = z² − 2Re(α)z + |α|² 是一个**实二次因式**。
3. 多项式除法或比较系数，求出剩下的因式。
4. 解剩下的二次方程（配方或求根公式）。

例（2021F-Q6）：P(2 + 4i) = 0 ⇒ 因式 z² − 4z + 20 ⇒ P = (z² − 4z + 20)(z² − 2z + 3) ⇒ z = 2 ± 4i，1 ± √2 i。

**反求系数（2023F-Q2）**：已知根 1 + i、2 + √3 i ⇒ 共轭根也是根 ⇒ Q(z) = (z² − 2z + 2)(z² − 4z + 7) ⇒ 由常数项 14 推出实根 z₀，再展开比较系数。

**真题**：2016F-Q3、2016S-F1、2017F-Q2、2018F-Q7(b)(c)、2019F-Q2、2021F-Q6、2022A-Q13(a)(b)、2023F-Q2、2024F-Q7。

## 题型 4：乘法的几何意义（旋转 + 伸缩）

**识别**：「Describe the geometric transformation performed by successive multiplication by z」。

**模板（2 分）**：「Multiplication by w = r cis θ **dilates** the modulus by a factor r and **rotates** the vector **anticlockwise by θ** (or clockwise by |θ| if θ < 0) about the origin.」两个要素各 1 分；乘 z⁻¹ 则倍数取倒数、旋转方向相反（2023A-Q10(d)）。

**延伸**
- 求 zwⁿ 落在第二象限的所有 n：每乘一次 w 转 30°，列出落在 90° < 辐角 < 180° 的 n。|w| = 1 时每 12 次回到原位，所以答案要写全：n = 3 + 12k、4 + 12k、5 + 12k（k 为非负整数）；只写 3、4、5 拿不到 "all the possible values" 那一分（2025A-Q19(b)）。
- 由图读出 z 的模和辐角，再写极坐标（2019A-Q12(b)）。

**真题**：2017A-Q10、2019A-Q12、2023A-Q10、2025A-Q19。

## 题型 5：轨迹 — 由方程画图

| 方程或不等式 | 图形 |
|---|---|
| \|z − a\| = r | 以 a 为圆心、r 为半径的圆 |
| \|z − a\| = \|z − b\| | a、b 连线的垂直平分线 |
| Arg(z − a) = θ | 从 a 出发的射线（**端点 a 不在轨迹上**，画空心圈）|
| \|z − a\| + \|z − b\| = k | k > \|a − b\| 时为椭圆；**k = \|a − b\| 时退化为线段 ab**（2022A-Q9(a)）|
| \|z + 2\| = \|z − i\| + √5 | 差等于两点间距离 ⇒ 从 i 出发、沿 −2→i 方向延伸的射线，**端点 i 在轨迹上（实心点）**，与 Arg 型射线相反（2020A-Q10(b) key 有 1 分专门给这一点）|
| (z + i)·conj(z + i) = 2 | \|z + i\|² = 2 ⇒ 圆心 −i、半径 √2（2022A-Q9(b)）|
| z − z̄ ≤ 6i | 2i·Im(z) ≤ 6i ⇒ Im(z) ≤ 3（2024A-Q10(b)）|

**画图得分点**：✓ 关键点或圆心 ✓ 边界位置 ✓ 边界实线/虚线 ✓ 阴影区域正确。

**真题**：2016A-Q10(a)(b)、2016S-A18、2020A-Q10(b)、2022A-Q9(a)(b)、2024A-Q10(b)、2025A-Q10(b)。

## 题型 6：轨迹 — 由图写方程

**思路**：先认出形状，再用 z 写方程（不能用 x、y）：圆 ⇒ \|z − 圆心\| ≤ r；射线 ⇒ Arg(z − 端点) = θ；扇形 ⇒ 用两个 Arg 不等式加一个模不等式。端点的角度要用三角函数精确求出（2020A-Q10(a)）。

**真题**：2018A-Q11(a)(b)、2019A-Q10(a)、2020A-Q10(a)、2021A-Q11(d)、2022A-Q9(c)、2025A-Q10(a)。

## 题型 7：轨迹上的最值

**思路**：画图 → 找到达到最值的几何位置 → 用勾股定理或三角函数计算。
- 圆上点到 c 的最远距离 = \|圆心 − c\| + r，最近距离 = \|圆心 − c\| − r（c 在圆外时；c 在圆内时为 r − \|圆心 − c\|）（2016A-Q10(c)、2024A-Q10(a)(ii)）。
- 圆上点的最大辐角：在**切线**位置取到。sin θ = r/d 求出的 θ 只是「切线与 O→圆心连线的夹角」，还要再加减圆心的辐角，并注意题目规定的辐角范围（2018A-Q11(c)：0 ≤ arg z < 2π，答案为 2π − α ≈ 5.64）。
- 射线上点到 i 的最短距离：作垂线（2019A-Q10(b)）。

**得分点**：✓ 在图上指出取到最值的位置 ✓ 写出表达式 ✓ 精确值。

## 题型 8：用向量或几何求模与辐角（CF 与 CA 都出现）

**思路**：把 z + w 画成平行四边形，z − k 画成三角形，再利用：
- 两向量模相等 ⇒ 菱形 ⇒ 对角线平分角：arg(z + r) = θ/2（2018F-Q3(b)(ii)）；
- 等腰三角形、圆周角定理、正弦或余弦定理（2017F-Q6、2021F-Q1(b)、2023A-Q12）；
- 正六边形：**以原点为中心**时，相邻顶点辐角差 π/3、各模相等。2025F-Q7 的顶点 z₀ **在原点**，六边形不以原点为中心：边向量依次转 π/3；用余弦定理得 \|z₂\| = \|z₄\| = √3r、\|z₃\| = 2r，所以 \|z₁z₂z₃z₄z₅\| = r·√3r·2r·√3r·r = **6r⁵**；z₃ = 2r cis(π/3)，Arg(z₅ − z₃) = −5π/6（2025 报告点名这道题的六边形几何）。

**真题**：2017F-Q1、2017F-Q6、2018F-Q3、2020A-Q11、2020A-Q15、2021F-Q1、2023A-Q12、2025F-Q7。

## 题型 9：证明与技巧题

- 恒等式：用 conj(z) = r cis(−θ)，加上 cos 是偶函数、sin 是奇函数（2018A-Q10）。
- 分组求和：n·iⁿ 本身不是周期的，但每连续 4 项（第 4m+1 到 4m+4 项）之和恒为 2 − 2i，共 505 组 ⇒ Σₙ₌₁²⁰²⁰ n iⁿ = 505 × (2 − 2i) = 1010 − 1010i = 1010√2 cis(−π/4)（2020F-Q8）。
- 借助复数解实方程组：(a + bi)³ = (a³ − 3ab²) + i(3a²b − b³) = 14 − 2√5 i ⇒ 取模：(a² + b²)³ = 196 + 20 = 216 ⇒ **a² + b² = 6**（2023F-Q8）。
- 用复数乘法证明反正切和（2025A-Q19(c)）。
