# MAS · 变化率与微分方程 — 题型与解题思路

> 依据：2016–2025 共 41 道真题 marking key + 考试报告。几乎只在 Calculator-assumed 卷出现。原题见 `topics/06_Rates_DiffEq.pdf`。数值例已用 Python 验算。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 阅卷组提醒

- **v 是 x 的函数时的运动**（2018、2020、2022 报告**三次点名**）：a = dv/dt = (dv/dx)(dx/dt) = v·dv/dx = d(½v²)/dx。**dv/dx 本身不是加速度**，对 x 求导后要乘 v。
- **隐函数求导**：很多人不愿意用（2017 报告），或者二阶导做不出来（2025 报告）。
- **不是所有增长都是 logistic**（2025 报告）：dP/dt = 0.001(100 − P)² 这类方程，很多人按 rP(k − P) 的 S 形去画，结果错了。要从给出的方程本身分析斜率。
- **斜率场中斜率无定义的地方**（2019 报告）：分子不为 0 时，解曲线在该处是竖直切线，曲线在此折返、关于该直线对称。
- 变化率要写**单位**（2020、2021 报告）。
- **logistic 方程的使用**是 2024 报告点名的难点（Q13(c)，由显式解求 r、k）。
- **认出标准微分方程**：SHM 与指数衰减（2017 报告）。
- ln 的反导数要带绝对值（2022 报告）。

## 题型 1：隐函数求导（切线、水平点、二阶导）

**标准流程**
1. 两边对 x 求导：含 y 的项要乘 dy/dx；乘积用 product rule，复合用 chain rule，如 3(x² + y² − 1)²(2x + 2y y′)。
2. 题目要求时把 dy/dx 解出来；也可以直接代点求值（2018A-Q20 明确要求**不要**解出 dy/dx："Do not attempt to obtain dy/dx as the subject"）。
3. **水平切线**：dy/dx = 0 ⇒ 分子 = 0，再与原方程联立求点（2018A-Q20(c)、2021A-Q18(b)）。
4. **二阶导**（2025F-Q5）：对已经求导一次的式子再求一次导，代入 x、y、y′ 的值。
5. 反三角函数的导数（2020F-Q6(b)、2024F-Q8(d)）：x = 2 tan y ⇒ 1 = 2 sec²y·y′ ⇒ 用 1 + tan²y 把结果换成 x 的式子。

**真题**：2016A-Q13(a)、2017A-Q12(a)、2018A-Q15(a)、2018A-Q20、2021A-Q18、2022F-Q7(a)、2025F-Q5。

## 题型 2：相关变化率 ★

**标准流程（4–5 个得分点）**
1. 写出量与量之间的关系（几何或物理），**建立变量之间的关系式，必要时消去多余的变量**（也可以保留两个变量，隐式对 t 求导）：V = 4h²（三棱柱水箱）、正六边形面积 A = (3√3/2)s²、x = 50 tan θ（灯塔）、s(10 − h) = 30（影子）。
2. 对 t 求导（链式法则或隐函数求导）：dA/dt = 3√3 s · ds/dt。
3. 代入已知变化率和**该时刻的值**（有时要先求出 θ 或 h）。
4. 带单位。例：s = 4、ds/dt = 0.5 ⇒ dA/dt = 6√3 ≈ 10.39 cm²/s（2022A-Q8）。
5. 灯塔类（2021A-Q9）：每分钟 3 转 ⇒ dθ/dt = 6π rad/min = π/10 rad/s；在 x = 100 时 sec²θ = 1 + (100/50)² = 5。

**真题**：2016S-A11(a)、2016A-Q15、2017A-Q18(c)、2019A-Q18(c)、2020A-Q20(b)、2021A-Q9、2022A-Q8、2023A-Q19、2025A-Q14(b)。（2023A-Q17(c) 是增量公式题，见题型 8。）

---

**圆周运动中的相关变化率（摩天轮、旋转木马）**

**思路**
1. 角速度：一圈 2π 弧度需要 T 秒 ⇒ dθ/dt = 2π/T（「show that」1 分）。
2. 用几何关系建模：余弦定理 s² = 89 − 80cos θ（2017A-Q18(b)），或者相对中心的高度 y = 80 sin(θ − π/2)（2019A-Q18(b)，要解释相位 α 的取值；离地高度 = y + 80，所以离地 100 m 对应 y = 20）。
3. 对 t 隐函数求导：2s·ds/dt = 80 sin θ · dθ/dt。
4. 求最大变化率：再求一次导令其为 0；也可以用几何理解，PC 与圆相切时 ds/dt 最大。

**真题**：2017A-Q18、2019A-Q18。

## 题型 3：斜率场

**常见问法与思路**
- 求某点的斜率值：直接代入（1 分）。
- 由斜率场反推方程：观察斜率只随 x 变（同一竖线上各点平行）还是只随 y 变；在哪些地方斜率为 0；斜率在哪里无定义。比如 2016A-Q18：dy/dx = a − bx（a, b > 0）；一个条件从图上读（x = 2 处斜率为 0），一个是题给的（A(1, 2) 处斜率为 0.5）⇒ dy/dx = 1 − 0.5x。(a) 的得分点要求说明截距为正、斜率为负。
- 画解曲线：经过指定点、**顺着短线段的方向**、标出对称性；在斜率无定义处切线竖直（2019A-Q11(b)、2021A-Q10(c)）；斜率为 0 处有水平切线；斜率取最大值的那条线上，曲线出现拐点。2025A-Q16：dy/dx = (x − 1)/((y + 1)² + 1)，x = 1 处是最低点，**拐点在 (3, −1)**（斜率在 y = −1 上最大），key 有 1 分。
- 解析解：分离变量求解（见题型 4）。

**真题**：2016A-Q18、2016S-A21、2017A-Q11、2019A-Q11、2021A-Q10、2023A-Q11、2025A-Q16。

## 题型 4：分离变量法

**标准流程（3–4 分）**
1. 写成 g(y) dy = f(x) dx，**两边写上积分号**（2021A-Q10(b)、2022A-Q17(d) 的 key 原话是「separates the variables as an integration statement」，其他年份写「separates the variables correctly」）。
2. 两边积分，只加**一个**常数；ln 要带绝对值。
3. 代入初始条件求常数。
4. 按要求写成 y = … 的显式形式。

**常见模型**
- dP/dt = kP ⇒ P = P₀eᵏᵗ（2019A-Q17(a)：**瞬时**增长率为种群的 10%，即 dP/dt = 0.1P，由 P(45) = 30000 倒推 1963 年：P₀ = 30000e^{−4.5} ≈ 333。不能当成「每年增长 10%」用 1.1ᵗ 算，那样得约 412）。
- dA/dt = −0.4A ⇒ A = 8e^{−0.4t}（2017A-Q17(c)）。
- dh/dt = −1/(100h) ⇒ h² = h₀² − t/50（2016A-Q15(d)）。
- dv/dt = −9.8 − 2v ⇒ v = 4.9(e^{−2t} − 1)；**深度要对 v 积分**（2024A-Q17）。
- dV/dt = 300e^{−V/12000} ⇒ 分离得 e^{V/12000}dV = 300 dt（2022A-Q17(d)）。

**真题**：2016A-Q15、2016S-F3、2017A-Q11(c)、2019A-Q11(c)、2021A-Q10(b)、2022A-Q17(d)、2023A-Q11(b)、2024A-Q17(c)、2025A-Q17(c)。

## 题型 5：Logistic 增长 ★

**公式**：dP/dt = rP(k − P) ⇔ P(t) = k / (1 + Ae^{−rkt})。
- 极限值（承载量）= k（t → ∞）；
- **增长最快时 P = k/2**（拐点），最大增长率 = r(k/2)²；
- 由显式解反推 r、k：例如 P = 18000/(10.25e^{−0.15t} + 1) ⇒ k = 18000，rk = 0.15。题目写成 dP/dt = (1/r)P(k − P) 时，1/r = 0.15/18000 ⇒ r = 120000；最大增长率 = 0.15 × 9000 × ½ = **675 匹/年**（2024A-Q13，与 key 一致）。

**常见问法**
- 由初始变化率求比例常数（2018A-Q18(a) 中题目把它记作 k：60 = k·100·1500 ⇒ k = 0.0004；承载量是 1600）。**字母以题目为准**：承载量 = 使 dP/dt = 0 的非零 P。
- 增量估计：δP ≈ (dP/dt)·δt，注意时间单位（1 个月 = 1/12 年，15 分钟 = 0.25 小时）。
- 用部分分式分离变量，推出显式解（2016S-A20、2018A-Q18(c)）。
- 解释增长：「P < k/2 时增长率随 P 增大而增大；P > k/2 时增长率减小，P 趋近于 k」（2022A-Q16(a)）。
- 承载量改变后作图：新的拐点、新的水平渐近线（2022A-Q16(b)）；**k/2 < P₀ < k 时，曲线全程 concave down、递增趋近 k，没有拐点**（2020A-Q19(e)：P₀ = 1.3，k = 2.4）；P₀ > k 时曲线递减并趋近 k。
- **非 logistic**（2025A-Q17）：dP/dt = 0.001(100 − P)² ⇒ 斜率随 P 增大单调减小，没有拐点，渐近线是 P = 100。

**真题**：2016S-A20、2018A-Q18、2019A-Q17(b)–(d)、2020A-Q19、2022A-Q16、2024A-Q13、2025A-Q17。

## 题型 6：速度是位移的函数（v = f(x)）★★ 报告重点

**标准流程**
1. **加速度**：a = v·dv/dx（或 d(½v²)/dx）。
   - v = −0.2x ⇒ a = (−0.2x)(−0.2) = 0.04x；
   - v = x/8 ⇒ a = (x/8)(1/8) = x/64。
2. **求 x(t)**：dx/dt = v(x) ⇒ 分离变量 ⇒ 代入初始位置。
   - v = x/8，x(0) = 192 ⇒ x = 192e^{t/8}，v(0) = 24 与题设一致 ⇒ 11 秒时速度 24e^{11/8} ≈ 94.92 m/s，路程 192(e^{11/8} − 1) ≈ 567.37 m（2022A-Q11）。
   - v = −0.2x，x(0) = 4 ⇒ x = 4e^{−0.2t} ⇒ x = 2 时 t = 5 ln 2 ≈ 3.47 s（2020A-Q14）。
3. **判断是不是 SHM**：a 与（相对平衡点的）位移成正比、方向相反才是 SHM，即 a = −n²(x − c)。a = 0.04x 系数为正，不是（2020A-Q14(b)）。

**真题**：2018A-Q13、2020A-Q14、2022A-Q11。

## 题型 7：简谐运动（SHM）

**公式**：ẍ = −n²x ⇒ x = A cos(nt + φ) 或 A sin(nt + φ)；周期 T = 2π/n；最大速率 = An；v² = n²(A² − x²)。

**常见问法**
- 由初始条件定 A 和相位：x(0) = 0 且 v(0) > 0 ⇒ x = A sin(nt)（2017A-Q17）。2024A-Q12 只说从平衡位置出发、没给方向，±25 sin(πt/2) 都给分（上下总跨度 50 cm ⇒ A = 25）。
- 由 v² = n²(A² − x²) 求振幅：n = 2，x(0) = −1，v(0)² = 32 ⇒ 32 = 4(A² − 1) ⇒ **A = 3**，T = π（2025A-Q15）。
- **路程**：每个周期走 4A，每半个周期走 2A。2025A-Q15(b)：10π 秒 = 10 个周期 ⇒ 4 × 3 × 10 = **120 cm**。2017A-Q17(b)：T = 2，5 秒 = 2.5 个周期 ⇒ 10A = 80 cm。不足半个周期、且起点不在平衡位置或端点时，用 ∫|v| dt。
- 振幅衰减（阻尼）：dA/dt = −kA ⇒ A = A₀e^{−kt}；看起来停止的条件是 A < 0.01（2017A-Q17(d)）。

**真题**：2016S-A15、2017A-Q17、2019A-Q18(d)（证明摩天轮的 y(t) 满足 d²y/dt² = −(π/36)²y）、2021A-Q12、2024A-Q12、2025A-Q15。

## 题型 8：增量公式（MAS 版）

δy ≈ (dy/dx)δx，同样适用于微分方程：δN ≈ (dN/dt)·δt，其中 dN/dt 由方程直接给出（2018A-Q18(b)、2020A-Q19(c)、2025A-Q17(b)）；δh ≈ δV / (dV/dh)（2023A-Q17(c)）。
**真题**：2016A-Q11(b)、2018A-Q18(b)、2020A-Q19(c)、2022A-Q17(b)、2023A-Q17(c)、2025A-Q17(b)。
