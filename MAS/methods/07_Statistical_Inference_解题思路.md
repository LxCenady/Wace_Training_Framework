# MAS · 统计推断（样本均值）— 题型与解题思路

> 依据：2016–2025 共 17 道真题 marking key + 考试报告。只在 Calculator-assumed 卷出现。原题见 `topics/07_Statistical_Inference.pdf`。数值例已用 scipy 验算。另引 2016 样卷 A9、A13（原卷见 `papers/2016Sample_*`）。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 公式卡

- 样本均值：**X̄ ~ N(μ, σ²/n)**（近似），总体本身是正态时，任意 n 都精确成立；总体不是正态时，由中心极限定理，n 足够大（经验上 ≥ 30）时近似成立，与总体形状无关。
- 样本均值的标准差（标准误）：σ_X̄ = σ/√n。
- n 个变量之和：key 的做法是把「总和 < T」换成「X̄ < T/n」（2016A-Q19(b)、2020A-Q18(a)）。总和 ~ N(nμ, nσ²) 只作验算用，key 没有给出这种写法。
- μ 的置信区间：x̄ ± z·σ/√n（σ 未知时用样本标准差 s 代替）；z = 1.645 / 1.960 / 2.576。
- 由区间反推：x̄ = 区间中点；z·σ/√n = 半宽 ⇒ 可以解出 σ/√n、s 或 n。

## 阅卷组提醒

- **写数学语句，不写计算器语言**（2016、2017、2018 报告）：写 P(X̄ > 83) = P(Z > 1.5) = 0.0668，而不是 normCdf(83, ∞, 80, 2)。
- **「State the distribution」3 分**：✓ 写明 X̄ 近似正态（顺带写上 n > 30 或 CLT 更稳妥；各年 key 第 1 分只要求写出「正态」）✓ 均值 ✓ 标准差 σ/√n（或方差）。
- **解释时要说清楚是哪个量**：「the standard deviation **of the sample mean** decreases」，不能只说 "standard deviation decreases"，也不要用 "it"（2019 报告）。
- **要针对题目作答**，不要照搬往年标准答案的句子（2025 报告）。

## 题型 1：写出 X̄ 的分布并求概率 ★ 高频

**标准流程**
1. 「By the Central Limit Theorem, since n = 100 is large, X̄ is approximately normal with mean μ = 80 and standard deviation σ/√n = 20/10 = 2.」
2. 写出概率表达式，再计算。
3. 「与 μ 相差小于 d」= P(|X̄ − μ| < d) = P(μ − d < X̄ < μ + d)。
4. 总和类：50 次共 < 8.96 kL ⇔ X̄ < 179.2 L ⇒ X̄ ~ N(175, 2.1213²) ⇒ P ≈ **0.9761**（2016A-Q19(b)）。

**总体不是正态时**（均匀分布 2017A-Q9、指数分布 2018A-Q12、右偏 pdf 2021A-Q15、飞镖距离 2025A-Q13）：做法与正态总体相同，因为 n 足够大，X̄ 仍然近似正态。2018A-Q12(c) 专门考了这一点（2 分：答案不变 + 理由是 CLT）。
**画 X̄ 的分布**：以 μ 为中心的钟形，宽度约 ±3σ/√n，比原分布窄很多；题目要求时，在图上标出前一问算的概率区域（2017A-Q9(b) 有 1 分，2021A-Q15(b)）。

**真题**：2016A-Q19(a)(b)、2017A-Q9、2018A-Q12(a)(b)、2019A-Q14(a)(b)、2020A-Q18(a)、2021A-Q15(a)、2022A-Q12(a)(b)、2023A-Q13(a)(b)、2024A-Q14(a)(b)、2025A-Q13(a)(b)。

## 题型 2：求样本量 n（使概率或区间满足要求）

**标准流程**
1. 先画图判断是双侧、单尾还是半区间，再写概率语句。双侧：P(|X̄ − μ| < 0.2) = 0.98；单尾：P(X̄ > 25) = 0.03 ⇒ z = 1.881（2018A-Q12(d)）；半区间：P(80 < X̄ < 82) > 0.4 ⇒ P(0 < Z < k) = 0.4，k = 1.282，n = 165（2019A-Q14(d)）。
2. 求临界 z（98% ⇒ z = 2.326）。
3. 列方程或不等式：z·σ/√n = d ⇒ n = (zσ/d)²。
4. **取整**：要求「至少达到」时向上取整。例：(2.326 × 1.5/0.2)² = 304.3 ⇒ **n = 305**（2020A-Q18(b)）；600.25 ⇒ 601（2024A-Q14(f)，要求「至少」时小数部分再小也要进位）。由已知区间反推 n 时，取最接近的整数（2022A-Q14(a)：z 取 2.576 得 200.0 ⇒ 200，key 也接受用 2.58 得 201；2025A-Q13(c)：283.0 ⇒ 283，也接受 284）。

**真题**：2016A-Q19(d)、2018A-Q12(d)、2019A-Q14(d)、2020A-Q18(b)、2022A-Q14(a)、2024A-Q14(f)、2025A-Q13(c)；2016S-A9、2016S-A13(b)（样卷）。反求误差限：2024A-Q14(c)（50% 概率对应 m ≈ 1.7 分钟）。

## 题型 3：置信区间的计算与反推

**计算**：x̄ ± z·s/√n。例：x̄ = 10300，s = 400，n = 100，95% ⇒ 10300 ± 1.96 × 40 = (10221.6, 10378.4)（2017A-Q13(a)：中心、标准误、z、上下限各 1 分）。
**反推**
- 上限 40.62、宽度 1.08 ⇒ x̄ = 40.08；0.54 = 2.576 × s/20 ⇒ s ≈ **4.19**（2018A-Q16）。
- 区间 150 ≤ μ ≤ 200 ⇒ x̄ = 175，σ_X̄ = 25/1.96 ≈ 12.76；样本量加倍后 σ_X̄ = 12.76/√2 ≈ 9.02 ⇒ P(|X̄ − μ| < 10) ≈ **0.7325**（2020A-Q17）。
- 已知区间与 n，反求置信水平：先求 z = 半宽 / 标准误，再查对应的百分比（2017A-Q13(d)）。
- 样本量变化：宽度 ∝ 1/√n ⇒ 宽度变为 1/4 需要 16n（2021A-Q17(c)）；样本量变为 2n，标准误除以 √2。

**真题**：2016S-A13、2017A-Q13、2018A-Q16、2019A-Q15、2020A-Q17、2021A-Q17、2022A-Q12(c)、2023A-Q13(c)(d)、2023A-Q15、2024A-Q14(d)。

## 题型 4：解读置信区间（判断对错）★ 几乎每年都考（2016、2020 除外）

**必背的正确说法**
1. μ 是一个**固定但未知**的数。某个具体的区间要么包含 μ，要么不包含，**无法知道是哪一种**（2018A-Q16(d)、2019A-Q15(d)、2021A-Q17(e)、2022A-Q14(c)）。
2. 「95% 置信」指的是重复抽样时约 95% 的区间会包含 μ，**不是**「μ 落在这个区间里的概率是 95%」（2023A-Q15(c)：Ali 的说法错误）。
3. 区间宽不代表更可能包含 μ（2022A-Q14(c)：James 错误）。
4. 下一个样本的均值**不一定**落在这个区间里（2017A-Q13(b)(i)）；单个个体的取值更不一定，因为个体的变异远大于样本均值的变异（2017A-Q13(b)(ii)）。
5. 50 个区间里有 10 个下限低于 1.00，并不说明设定有误，这是随机抽样的正常波动（2023A-Q13(e)）。
   **反过来**：如果大量区间中不包含 μ 的比例远超 5%，那就是证据。2025A-Q13(e) 中 500 个 95% 区间有 298 个不含 μ = 100，key 判定 Chen 的陈述 1（样本不太可能来自 μ = 100 的总体）**正确**；但仍不能断定原因，陈述 2（选手站得不是 3.50 m）**错误**。
6. 两个区间嵌套或重叠，**不能**推出两个总体均值相同；样本均值更低，也不能单凭这一点说新方法更好（2024A-Q14(e)；key 给 Sanjeet 的理由是：两个区间基于不同的样本量，不能直接这样比较）。
7. 把**同一个样本复制一遍**凑成 2n，不是新的随机样本，不反映真实的波动，区间并没有真正变窄（2022A-Q12(d)）。注意：两个**独立**随机样本合并是合法的，n 更大，精度更高（2019A-Q15(c)）。

**写法**：先表态（True / False / Not correct），再给一句针对本题语境的理由，各 1 分。

## 题型 5：用区间检验说法（某公司用水更多吗？）

**标准流程（4 分）**
1. 由新样本求 x̄ 和 s：6.57 kL / 36 = 182.5 L，s = 15。
2. 构造 μ_new 的置信区间：182.5 ± 1.96 × 15/6 = (177.6, 187.4)。
3. 比较：原来的 μ = 175 **不在**区间内。
4. 结论：有证据支持「WolliWorks 用水显著更多」（2016A-Q19(e)）；反之，若在区间内，则没有足够证据（2020A-Q18(c)）。

**注意**：只能对「均值是否不同」下结论，不能推断出样本来源（例如 Anika 说的「很可能取自 100 个青少年」），因为来源未知（2021A-Q15(c)）。

**真题**：2016A-Q19(e)、2020A-Q18(c)、2021A-Q15(c)、2025A-Q13(d)(e)。

## 题型 6：影响精度的因素

| 变化 | X̄ 的标准差 | 区间宽度 | 「X̄ > 83」这类尾部概率（2019A-Q14：μ = 80，阈值 83 在 μ 上方）|
|---|---|---|---|
| n 增大 | 减小 | 变窄 | 减小（83 相对更极端）|
| 置信水平提高 | — | 变宽 | — |
| σ（或 s）增大 | 增大 | 变宽 | 增大 |

样本越大、标准误越小，精度越高（2019A-Q15(c)：合并样本 3n 的精度最高）。
比较两个区间谁更窄：比较 z·s/√n（2021A-Q17(f)）。
