# MAS 解题思路 · 独立审校记录

**审校方式**：每份讲义由一个独立的子代理审校。审校员没有参与写作，以全新上下文工作，只读不改。核对依据包括：`evidence/` 里每题 marking key 的 "Specific behaviours" 原文、2016–2025 考试报告全文、原卷与 key 的 PDF 页面，并用 sympy/scipy/numpy 独立验算。

**处理原则**：编者逐条复核审校意见。高严重度的意见全部回到原卷原文核实，能验算的都重新验算过。审校员标「存疑」的条目，只在找到依据时才改。

**结论分类**：采纳 = 已按意见修改；部分采纳 = 改了措辞但没有完全照建议；驳回 = 不改，并写明理由。
