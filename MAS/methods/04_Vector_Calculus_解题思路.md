# MAS · 向量微积分与运动 — 题型与解题思路

> 依据：2016–2025 共 12 道真题 marking key + 考试报告。只在 Calculator-assumed 卷出现。原题见 `topics/04_Vector_Calculus.pdf`。

## 阅卷组提醒

- **路程与位移向量的区别**（2025 报告重点）：∫ₐᵇ v(t) dt 是**位移变化向量**（有方向），∫ₐᵇ |v(t)| dt 是**路程**（标量）。
- **积分常数是向量**（2018 报告：很多人写不清怎样用积分常数推出 r(t)）：r(t) = ∫v dt + **c**，然后用 r(0) 解出 c 的每个分量。
- **记号**：向量要标记（波浪线或粗体），速度向量和速率要分开写；2019A-Q13、2022A-Q10 的 key 都有 1 分专门给 notation。
- 消参得到笛卡尔方程后，**要写出取值限制**（常常 x、y 都要限制）（2016A-Q16、2024A-Q18、2025A-Q12 的 key 都有这一分）。

## 公式卡

| 量 | 表达式 |
|---|---|
| 速度 | v(t) = r′(t)（逐个分量求导）|
| 加速度 | a(t) = v′(t) |
| 速率 | \|v(t)\| = √(ẋ² + ẏ² (+ ż²)) |
| 路程（弧长） | ∫ₐᵇ \|v(t)\| dt |
| 位移变化 | ∫ₐᵇ v(t) dt = r(b) − r(a) |
| 运动方向 | 与 x 轴的夹角 tan⁻¹(ẏ/ẋ)，注意象限 |

## 题型 1：已知 r(t)，求速度、加速度、速率

**思路**：逐个分量求导 → 代入时刻 → 速率取模 → 在图上画出向量（起点放在该时刻的位置，箭头指向运动方向）。
**常速判断**（2020A-Q12）：r = (10cos 0.1t, 10sin 0.1t, 0.2t) ⇒ v = (−sin 0.1t, cos 0.1t, 0.2) ⇒ |v| = √(sin² + cos² + 0.04) = √1.04 ≈ 1.02 m/s，与 t 无关 ⇒ **速率恒定**（constant speed），但速度向量的方向一直在变，不是匀速直线运动。必须写出用到了 sin² + cos² = 1（单独 1 分）。观景台高度 = 0.2 × 65 = 13 m。

**真题**：2016A-Q16(b)、2017A-Q15(a)(d)、2019A-Q13(a)(b)、2020A-Q12、2023A-Q16(a)、2024A-Q18(b)(d)。

## 题型 2：已知 a(t) 或 v(t)，积分求 r(t)

**标准流程**
1. 逐个分量积分，加**常数向量** c = (c₁, c₂)。
2. 用初始条件（r(0)、v(0)）解出每个分量。
3. 写出完整的 r(t)。

**抛体，两种模型**：
- 重力 + 风（2018A-Q19）：a = (0, −9.8) ⇒ v = (70cos θ + w, 70 sin θ − 9.8t) ⇒ r = ((70cos θ + w)t, 70 sin θ · t − 4.9t²)。风只影响水平分量。
- 水平阻力 + 竖直升力（2021A-Q19）：从 E(100, 120) 水平飞出；x′ = 32e^{−0.05t}；竖直加速度 h″ = s − 9.8（s 为升力），由给出的 r 反求 s = 4.8，于是 r = (740 − 640e^{−0.05t}, 120 − 2.5t²)。
**射程或落点**：y(t) = 0（或等于斜坡高度）⇒ 解出 t ⇒ 代入 x(t)。射程最大 ⇒ 对 θ 求导或用 CAS 求极值。
**落地角度**：用落地瞬间的速度向量与斜坡或水平面的夹角（2021A-Q19(e)）。

**真题**：2017A-Q15(c)、2018A-Q19(a)(c)、2021A-Q19、2022A-Q10(b)。

## 题型 3：消参得到笛卡尔方程 ★

**常用恒等式**
- cos²t + sin²t = 1 ⇒ 圆或椭圆（2022A-Q10(c)）；
- cos 2t = 1 − 2sin²t 或 2cos²t − 1，直接得到 x 与 y 的关系 ⇒ 抛物线一段（2016A-Q16：x = 2y² − 4）；
- 先用倍角公式把两个分量化成同一角度，再用 sin² + cos² = 1 消参 ⇒ 一般曲线（2019A-Q13(d)：(1 − y)² + (x²/2 − 1)² = 1，「8」字形）；
- x 是 t 的一次式：直接由 x 解出 t 代入 y（2018A-Q19(b)；2018 报告点名这一问答得差）；
- (eᵗ + e⁻ᵗ)² − (eᵗ − e⁻ᵗ)² = 4 ⇒ 双曲线 x² − y² = 4（2024A-Q18(e)）；
- 指数参数：由 x 解出 t = ln(…)，再代入 y（2025A-Q12(a)）。

**最后一步不能漏**：写出实际路径的范围，**由 t 的范围推出**，key 原文：2016A-Q16：−2 ≤ y ≤ 2（或 −4 ≤ x ≤ 4）；2024A-Q18：x ≥ 2 **且 y ≥ 0**（只写 x ≥ 2 会包含下半支，丢分）；2025A-Q12：1 ≤ x ≤ e³。

**真题**：2016A-Q16(a)、2018A-Q19(b)、2019A-Q13(d)、2022A-Q10(c)、2024A-Q18(e)、2025A-Q12(a)。

## 题型 4：路程（弧长）与位移的解释

**思路**
1. 找出起止时刻。**一圈的时长 = 各分量周期的最小公倍数**：2022A-Q10 是 2π，2019A-Q13 是 4π（含 t/2），2017A-Q15 是 6π（含 t/3）。这两题各有 1 分给正确的上下限。也可以由坐标反求 t：B 点在 t = ln 3 时为 (10/3, 8/3)。
2. 写出 **∫ₐᵇ √(ẋ² + ẏ²) dt**（通常的得分点：起止 t 值或上下限、速率表达式、计算结果或记号，各年分配不同；"Do not evaluate" 题没有计算分）。
3. 题目说 "Do not evaluate" 时，只写含三角函数的积分式即可。

**解释积分的意义（2 分）**
- ∫₀¹ v(t) dt：「the change in displacement (position vector) during the first second」。
- ∫₀^{2π} |v(t)| dt：「the distance travelled in one complete circuit (2π seconds)」（2022A-Q10）。
- ∫₀³ r′(t) dt：位移变化向量，在图上画成从 r(0) 指向 r(3) 的箭头（2025A-Q12(c)）。

**真题**：2016A-Q16(c)、2017A-Q15(b)(e)、2019A-Q13(c)、2022A-Q10(a)、2023A-Q16(b)、2024A-Q18(c)、2025A-Q12(b)–(d)。

## 题型 5：直线运动物体的最近距离（3D）

**思路**
1. 写出两个物体的位置：r_K(t) = r_K0 + t·v_K，r_B(t) = r_B0 + t·v_B。
2. 相对位置 d(t) = r_K(t) − r_B(t)。P 相对 Q 的位置 = r_P − r_Q；题目问相对位置向量时顺序要对（2017A-Q14(b)："from the top of the tower" ⇒ r_drone − r_tower，key 有 1 分）。只求距离时，顺序不影响模长。
3. 最近距离：令 d(t)·(v_K − v_B) = 0，或用 CAS 求 |d(t)| 的最小值。
4. 「在 50 m 内的时间段」：解 |d(t)| < 50，求出时间区间的长度（2017A-Q14(c)）。
5. 两条轨道之间的最短距离（2024A-Q16(c)：可以调整**速度和出发时间**，问题就化为两条直线之间的最短距离）：用两个独立参数 λ、μ，要求公垂向量同时垂直于两个方向向量（2024A-Q16(c)）。
6. 下降角（与水平面的夹角）：先求速度向量与 k 的夹角 φ，下降角 = **|90° − φ|**（Ben 的 v = (−0.5, 1, −1.5)，φ ≈ 143.3°，90° − φ = −53.3°，答 53°；2024A-Q16(b)）。也可以直接用 sin⁻¹(|v_z| / |v|)。

（摩天轮、旋转木马题（2017A-Q18、2019A-Q18）不含向量，已归入「变化率与微分方程」讲义的相关变化率题型。）

**真题**：2017A-Q14、2024A-Q16。
