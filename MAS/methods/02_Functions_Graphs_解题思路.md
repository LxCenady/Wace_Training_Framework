> 依据：2016–2025 共 31 道真题 marking key + 考试报告。原题见 `topics/02_Functions_Graphs.pdf`。以 CF 为主（作为主知识点时 CF 21 题、CA 7 题）。

## 阅卷组提醒

- **复合函数定义域是本专题最常被点名的失分点**：2016、2017、2022、2023、2024、2025 年报告都点了名（2018 年反而列为答得好）。2017 报告指出根源是不愿列、不会解不等式。
- **解释时不要用 "it"**（2018、2019、2021、2022、2024 报告）：「g is not one-to-one because g(1) = g(−1) = 1」，而不是「it is many to one」。
- 求值域可以借助倒数函数的图像（2019 报告建议：先画 1/f 的图再读值域）。
- ln 的反导数要带绝对值（2022 报告；例如 2020F-Q6(d) 的 ln|x − 3|）。

## 题型 1：复合函数的表达式、定义域、值域 ★★

**核心原则**：f(g(x)) 有定义 ⇔ ① x 在 g 的定义域内，**并且** ② g(x) 落在 f 的定义域内。

**标准流程**
1. 写出 f(g(x))，代入后**不要先化简**，否则可能丢掉限制条件。
2. 列出两组条件：g 本身的限制（分母 ≠ 0、根号下 ≥ 0、**根号在分母时 > 0**、ln 的真数 > 0；例：2025F-Q2(a) 的 y = 1/√f(x) 要求 f(x) > 0），以及「g(x) ∈ dom f」转化成的不等式。
3. 解不等式并取交集。

**例**
- 2017F-Q4：f(x) = 1 − √(x − 4)，g(x) = 1/x² ⇒ f(g(x)) = 1 − √(1/x² − 4)。条件：x ≠ 0，且 1/x² ≥ 4 ⇒ x² ≤ ¼ ⇒ **−½ ≤ x ≤ ½，x ≠ 0**。
- 2022F-Q1：f(x) = √(4 − x)，g(x) = 1/x² ⇒ 4 − 1/x² ≥ 0 ⇒ x² ≥ ¼ ⇒ **x ≤ −½ 或 x ≥ ½**。
- 2016F-Q1：g∘f = 1/ln x ⇒ 定义域 x > 0 且 x ≠ 1；值域 y ≠ 0。
- 2019F-Q4(d)：f(h(g(x))) = 1/(√(x²) − 1) = 1/(|x| − 1)，**不等于** f(x)，因为 √(x²) = |x|。

**得分点**：通常每个限制条件各 1 分（如「states x ≠ 0」「states −½ ≤ x ≤ ½」）。
**真题**：2016F-Q1、2017F-Q4(c)(d)、2018F-Q1、2019F-Q4、2021F-Q2(d)(e)、2022F-Q1、2023F-Q4(b)(c)、2024F-Q2(a)、2025F-Q2(a)。

## 题型 2：反函数（存在性、表达式、图像）

**标准流程**
1. **存在性**：f 必须是一一对应（one-to-one），可以用水平线检验。不是的话就限制定义域；「最大可能的定义域」取到顶点为止，如 x ≤ 1（2016F-Q8(c)）。
2. **求表达式**：交换 x 和 y（key 有 1 分专门给「interchanges x, y」）→ 解出 y → 按 **ran f⁻¹ = dom f**（即原函数定义域的限制）**选正负号**，dom f⁻¹ = ran f（2016F-Q8(d) key：y − 1 = −√(x + 4) since R_{f⁻¹} = D_f；2016 报告把这一步列为 area of concern）。
3. **定义域与值域互换**：dom f⁻¹ = ran f。
4. **作图**：关于 y = x 对称；标出端点和截距的对应点，例如 (a, b) ↔ (b, a)。
5. 「f⁻¹(−1) = 4 对吗」：要检查 −1 是否在 f 的值域里。f(x) = √(x − 3) ≥ 0，所以 f⁻¹(−1) 没有定义（2018F-Q1(c)）。

**反三角函数（2020F-Q6、2024F-Q8）**：y = 2 tan x ⇒ f⁻¹(x) = tan⁻¹(x/2)。求导用隐函数求导：x = 2 tan y ⇒ 1 = 2 sec²y · y′ ⇒ y′ = 1/(2(1 + tan²y)) = 2/(4 + x²)。

**真题**：2016F-Q8(c)(d)、2017F-Q4(a)(b)、2019F-Q5、2019F-Q7、2020F-Q6、2021F-Q2、2023F-Q4(a)、2024F-Q8、2025F-Q2(b)。

## 题型 3：倒数函数 y = 1/f(x) 的图像 ★ CF 常客

**画法规则（key 的得分点）**
| f(x) 的特征 | 1/f(x) 的对应特征 |
|---|---|
| 零点 x = a | 竖直渐近线 x = a |
| x → ±∞ 时 f → ±∞ | 1/f 有水平渐近线 y = 0 |
| f 的竖直渐近线 x = b | 1/f 在 (b, 0) 处是空心点（1/f 在 x = b 无定义，值域去掉 0；2025A-Q9(b)）|
| f 的水平渐近线 y = c（c ≠ 0）| 1/f 的水平渐近线 y = 1/c（2025A-Q9(b) 中 y = 2 → y = 0.5）|
| 局部极大 (a, m)，m ≠ 0 | 局部极小 (a, 1/m)（反之亦然）|
| f(x) = ±1 的点 | f 与 1/f 的公共点（位置不变）|
| f > 0 / f < 0 | 符号不变 |
| f 的空心点 (a, b)，b ≠ 0 | 1/f 的空心点 (a, 1/b)（2018A-Q14(a)）；若 b = 0，则对应单侧竖直渐近线（2022F-Q2）|

**值域**：从 1/f 的图读值域，并注意不可达的值（2020F-Q5(b)、2024F-Q2(b)、2025A-Q9(b)）。

**真题**：2016F-Q8(a)、2018A-Q14(a)、2020F-Q5、2022F-Q2(b)、2024F-Q2(b)、2025A-Q9(b)。

## 题型 4：绝对值函数

**三种变换**
- y = |f(x)|：x 轴下方部分翻到上方。
- y = f(|x|)：保留 x ≥ 0 部分，再关于 y 轴镜像。
- y = f(−|x|)：保留 x ≤ 0 部分，再镜像到右边（2023F-Q4(d)）。

**常见问法**
- 由图确定 y = a|x − b| + c 的参数（顶点给出 b、c，斜率给出 a）（2016A-Q12、2017A-Q16(a)）。
- |f(x)| = d 恰有 4 个解（2016A-Q12(b)，f(x) = −2|x − 3| + 5）：先画 |f| 的图（W 形），再用水平线 y = d 去截，找出 d 的区间（0 < d < 5）；端点 d = 0、d = 5 要单独检查。
- 解的个数函数 N(k)：用 y = k 扫过 |f(x)| 的图，逐段记录交点个数（2020A-Q21）。
- |x + 1| = k − |x + a| 的解集是一个区间 ⇒ 改写为 |x + 1| + |x + a| = k。两个绝对值之和在 −a 与 −1 之间是常数 |a − 1|（平底），平底的区间就是解集 ⇒ a = 3，k = 2（2023F-Q4(e)；key 的说法是两图沿一段线段重合）。
- W 形图 W_k(x) = |k/2 · |x − k| − k|：先画内层，再翻折；∫_{k−2}^{k+2} W_k dx = 两个零点 k ± 2 之间的一个三角形面积 = ½·4·k = 2k（2024A-Q15）。

**真题**：2016A-Q12、2016F-Q8(b)、2017A-Q16、2018A-Q14(b)(c)、2019F-Q7、2022F-Q2(a)（|f(x)| = x，key 要求排除 x = 0、包含 x = 2）、2020A-Q21、2023F-Q4(d)(e)、2024A-Q15、2025F-Q2(c)(d)。

## 题型 5：有理函数 — 由图定参数

**思路**：x 截距 ⇒ 分子的因式；竖直渐近线 ⇒ 分母的因式；水平渐近线 ⇒ 首项系数之比（如 a(x² − b)/((x + c)(x − d)) → a）；重根 (x − c)² 表示图像在该处**接触但不穿过** x 轴，或者渐近线两侧同号；最后用 y 截距或一个已知点定 k。

**理由要写**（key 一般有 1 分专门给 justification）：例：「c = 3 since x = 3 is a vertical asymptote」（2023F-Q1、2024F-Q5）。分母有重因子 (x − c)² 时，渐近线两侧同号（2023F-Q1 两侧都趋于 −∞）；分子有重因子时，图像在该处接触 x 轴但不穿过。
**斜渐近线**：多项式除法，f(x) = 商 + 余式/分母 ⇒ 渐近线 y = 商（2024F-Q5(b)、2023A-Q18(a)）。
**对称轴给定的有理函数**（2022A-Q15）：q(x) = a(x − 3)² + c，**a、c 同号**（key：a, b > 0）才保证没有零点；结果 f = 2/(x² − 6x + 10)。

**真题**：2018F-Q4、2020F-Q3、2022A-Q15、2023A-Q18、2023F-Q1、2024F-Q5、2025A-Q9(a)。

## 题型 6：有理函数作图

**清单（每项 1 分）**：x 截距、y 截距、竖直渐近线、水平或斜渐近线、转折点（有就标出，即使题目没明说也可能给分，如 2017F-Q5）、渐近线附近的弯曲方向（从左右两侧逼近时 → ±∞）。
**技巧**：先因式分解，检查有没有约掉的因子（洞）；f(x) = x − 1 − 3/(x + 1) 这类形式能直接读出斜渐近线 y = x − 1（2021F-Q4）。

**真题**：2017F-Q5、2021F-Q4。
