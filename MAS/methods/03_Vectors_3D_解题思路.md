## 阅卷组提醒

- **三个平面没有唯一解时怎么写**：「无唯一解」的理解和几何意义被 2018、2020、2021、2022、2023、2024 报告点名。2022 报告特别指出：很多人写到「有无穷多解」就停了（2023 报告提到同类问题）。必须**写出解集**——用参数，或用一个变量表示其余变量（key："expresses correct relationships between variables"）；题目要 vector equation 时写成 r = p + t·d（2023F-Q5(c)）。还要说明几何意义。
- 「无解」有两种几何情形，要分清：存在**平行平面**；或者三个平面**两两相交成三条平行直线**（像三棱柱，2020F-Q4 正是这种情况；报告说这种情形 2016–2019 从没考过，部分考生毫无准备）。
- **证明两条直线不相交**：要写出分量方程并说明无解，「CAS 说 no solution」不算证明（2021 报告）。
- **向量记号**：要区分位置向量和平面内的方向向量（2017 报告）；报告批评向量记号不规范（2018、2022、2025），2020A-Q20、2025A-Q18 的 key 有分绑定正确记号。（编者建议：向量加波浪线或粗体，点乘、叉乘符号不要混用。）
- 叉乘计算出错是 CF 常见失分（2020 报告）。

## 工具卡

- 直线：r = a + λd；平面：r·n = p·n（p 为平面上一点）⇔ ax + by + cz = k，其中 n = (a, b, c)；参数形式 r = a + λu + μv，其中 **n = u × v**。
- 球：|r − c| = R ⇔ (x − c₁)² + (y − c₂)² + (z − c₃)² = R²（由一般式配方得到）。
- 线面夹角：cos φ = |d·n| / (|d||n|)（取绝对值保证 φ 为锐角），线面角 = 90° − φ；等价地 sin θ = |d·n| / (|d||n|)。
- 点到平面距离 = |n·(P − A)| / |n|，A 为平面上任一点。**此式不在公式表上**（2019A-Q19 就是要你证明它），CA 题直接用最好附一句推导，或者用「过点作法线、求交点」的方法（2018A-Q17(c)）；平行六面体体积 = |c·(a × b)|。

## 题型 1：解线性方程组并讨论解的情况 ★★ 近 10 年有 7 年在 CF 出现（另 2021 年在 CA）

**标准流程**
1. 消元：用两对方程各消去同一个变量（key 第 1 分），解出第一个变量（第 2 分），回代求另外两个（第 3 分）。
2. **含参数 k**：化成 (系数含 k)·z = (常数含 k)，例如 (k − 2)z = c − 5（2025F-Q4）：
   - k − 2 ≠ 0 ⇒ **唯一解**（c 可以取任意实数）⇒ 三个平面交于一点；
   - k − 2 = 0 且 c − 5 ≠ 0 ⇒ **无解**；
   - k − 2 = 0 且 c − 5 = 0 ⇒ **无穷多解** ⇒ 交于一条直线。
3. **无穷多解时写出直线**（2022F-Q5）：设 z = t ⇒ y = t − 1，x = (11 − 3t)/2 ⇒ r = (11/2, −1, 0) + t(−3/2, 1, 1)。
4. **判断平行**：法向量互为倍数 ⇔ 平面平行。先检查法向量，再决定是「平行平面导致无解」还是「三条平行交线（棱柱）」。

**几何解释模板**
| 代数结果 | 几何意义 |
|---|---|
| 唯一解 | three planes intersect at a single point |
| 无穷多解（含一个参数） | three planes intersect in a common line（可能其中两个平面重合，如 2021A-Q14，key 要求两点都写）|
| 无穷多解（含两个参数） | three planes coincide（解集是一个平面）|
| 无解，有法向量成倍数 | at least two planes are parallel (and distinct) |
| 无解，法向量两两不平行 | planes intersect pairwise in three parallel lines (triangular prism) |

**真题**：2016F-Q6、2016S-A8、2018F-Q2、2020F-Q4、2021A-Q14、2022F-Q5、2023F-Q5、2024F-Q6、2025F-Q4。

## 题型 2：平面方程（求法向量）

**思路**
- 已知参数式：n = u × v（叉乘每个分量写清楚），再代一个点求 d（2020F-Q2、2018A-Q17(b)）。
- 过三点：两条边向量叉乘（2022A-Q19(a)），或者设 ax + by + cz = d 代入三点求解。
- 已知 z = 2x + y + 4 ⇒ 改写成 2x + y − z = −4 ⇒ n = (2, 1, −1)（2019A-Q16(a)、2023A-Q14(a)）。
- 包含一条直线且垂直于另一平面 ⇒ n₂ = d_L × n₁（2019A-Q16(c)、2023A-Q14(d)）。
- 包含两条相交直线 ⇒ n = d₁ × d₂（2025A-Q11(b)）。

**真题**：2016F-Q7(b)、2017F-Q7(a)(ii)、2018A-Q17、2019A-Q16、2020F-Q2、2022A-Q19(a)、2023A-Q14、2025A-Q11。

## 题型 3：交点、夹角、最近点

**直线与平面的交点**：把 r = a + λd 代入平面方程 ⇒ 解 λ ⇒ 求出点（3 分：代入、解 λ、写出点）。
**直线与球**：代入后得到关于 λ 的二次方程。两个解 ⇒ 两个交点；一个重根 ⇒ 相切；无实根 ⇒ 不相交（2019A-Q16(d)、2023A-Q9(b)）。另一种做法：比较球心到直线的距离与半径。
**两条直线**：令分量相等得到三个方程，用其中两个解出 λ、μ，**再代入第三个检验**。不成立 ⇒ 不相交（2021A-Q16(c) 要求的「proof」就是这个）。
**平面上离点 L 最近的点**：过 L 作沿法向量的直线 L + λn，与平面求交点（2022A-Q19(b)）。
**线面夹角**：cos φ = |d·n| / (|d||n|)，所求角 = 90° − φ（2023A-Q14(c)、2024A-Q16(b) 下降角）。

**真题**：2016A-Q20(a)、2019A-Q16(b)(d)、2021A-Q16(c)、2022A-Q19(b)、2023A-Q9、2023A-Q14(c)、2025A-Q11(a)。

## 题型 4：球

**思路**
- 由直径端点：球心 = 中点（报告：很多人把位置向量算错），半径 = |AB|/2（2016F-Q7(a)）。
- 一般式 → 标准式：配方。例：x² + y² + z² − 4x + 2y − 6z + 5 = 0 ⇒ (x − 2)² + (y + 1)² + (z − 3)² = 9 ⇒ |r − (2, −1, 3)| = 3（2023A-Q9(a)）。
- 与平面相切：半径 = 球心到平面的距离；或者过球心作法线、与平面求交点（2018A-Q17(c)）。
- 过长方体所有顶点：球心是体对角线中点（2021A-Q16(b)）。

## 题型 5：向量证明（CF 与 CA 都出现）

**标准写法**
1. 用给定的基向量（a、b、e）表示所需向量：PQ = OQ − OP = (a + kb) − ka。
2. 计算点积并展开（key 有一分给「展开得到 4 项」）。
3. **使用已知条件**：正方形 ⇒ a·b = 0 且 |a| = |b|；中点 ⇒ ½(a + b)。
4. 得出结论：PQ·QR = 0 ⇒ ∠PQR = 90°。

**真题**：2016S-A10（点到直线距离公式的证明）、2019A-Q19（平行平面间距离）、2020A-Q20（正方形中的直角）、2018F-Q8(b)（为什么 c·(a × b) 是体积：|a × b| 是底面积，c 在法向上的投影是高）、2025A-Q18（金字塔）。

## 题型 6：语境应用（激光反射、坡道最速下降、无人机靠近铁塔）

- 反射（2016A-Q20(b)）：**从 B 指向 S** 的单位向量 + **从 B 指向 R** 的单位向量 = k·n（菱形的对角线）。等价写法：d̂_出 − d̂_入 ∥ n。注意 key 文字写的是 "direction of SB"，实际代入的是 B→S 方向；按 S→B 方向相加得到的向量平行于镜面，不平行于 n。
- 坡道上最陡的下降方向：在坡面内且垂直于水平线 AB（2022A-Q19(c)）。
- 运动与距离要分两类（详见「向量微积分」讲义）：
  - (i) 同一时间参数 t：求最近距离用 r(t)·(相对速度) = 0；求 |r(t)| < R 持续多久要解不等式（2017A-Q14(c)）。
  - (ii) 两条空间直线的最短距离：用两个独立参数 λ、μ，令 PQ·d₁ = PQ·d₂ = 0（2024A-Q16(c)：Ben 可以调整速度和出发时间；2021A-Q16(c) 的另一种解法）。
