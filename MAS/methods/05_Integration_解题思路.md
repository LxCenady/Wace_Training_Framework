# MAS · 积分技巧与应用 — 题型与解题思路

> 依据：2016–2025 共 44 道真题 marking key + 考试报告。原题见 `topics/05_Integration.pdf`。数值例已用 sympy 验算。
> 审校状态：已经过一轮独立审校并按意见修订（见 `审校记录.md`）。

## 阅卷组提醒

- **ln 的反导数要写绝对值**（2022 报告）。近年的 key 把它算进「反导数」那一分里，没写绝对值可能整分不给；真数恒为正时（如 ln(x² + 2)），key 注明可以不写。
- **不定积分要写 + c**（几乎每道 partial fractions 题都有这 1 分）。
- **代数基本功**：(√3 tan u + 1)² 的展开有超过 30% 的考生做错（2018 报告）；错用分配律，把 √(2 − sin²θ) 写成 √2 − sin θ（2021 报告，F-Q8(c)）；partial fractions 通分后的分子表达式写错（2024 报告）。
- 用给定的代换求积分时，换元后**要化简干净**再积分（2020、2023 报告）。
- 体积式要写 π；所有积分式都要写 dx/dy 和上下限（2022A-Q17、2021A-Q13 的 key 把「上下限 + 正确记号」合并给 1 分）。

## 题型 1：给定代换的定积分 ★ CF 几乎每年都考（2016–2025 只有 2022 没考），4–7 分

**固定五步（key 的 5 个得分点基本就是这五步）**
1. 由代换求 dx：u = 1 − x ⇒ dx = −du；x = 2 sin θ ⇒ dx = 2cos θ dθ。
2. **换上下限**：x = 0 → u = 1，x = 1 → u = 0。
3. 把被积函数完全写成新变量的式子并化简（常用 1 − sin²θ = cos²θ，1 + tan²u = sec²u）。
4. 求反导数。
5. 代入上下限，给出精确值。

**三类代换**
- 线性或根式：u = 1 − x，u = √(x + 2)，x = 119u + 1（2020F-Q7、2021F-Q3、2023F-Q3、2024F-Q3）。
- 幂函数凑微分：u = sin 2x，u = cos 2x（2016F-Q5(a)、2018F-Q5）。
- **三角代换**：x = a sin θ 处理 √(a² − x²)；x = a tan u 处理 (x² + a²)。

**三角代换例**（2019F-Q6）：∫₀^√3 √(1 − x²/4) dx，令 x = 2 sin θ，上下限变为 0 → π/3 ⇒ ∫₀^{π/3} 2cos²θ dθ = ∫(1 + cos 2θ)dθ = **π/3 + √3/4**。

**真题**：2016F-Q5、2017F-Q3、2018F-Q5、2018F-Q9、2019F-Q6、2020F-Q7、2021F-Q3（代换要自己选）、2021F-Q8(c)、2023F-Q3、2023F-Q7(b)、2024F-Q3、2025F-Q6。
**不定积分版**（2016A-Q9，∫x(1 + x)ⁿ dx）：没有换上下限这一步，最后要回代成 x。

## 题型 2：三角恒等式化简后积分（CF 3–5 分）

**常用恒等式**
- cos²x = ½(1 + cos 2x)，sin²x = ½(1 − cos 2x)；
- (sin x + cos x)² = 1 + sin 2x ⇒ ∫₀^{π/2} = **π/2 + 1**（2022F-Q3）；
- 积化和差：2 sin A cos B = sin(A + B) + sin(A − B) ⇒ ∫₀^{π/2} 6 sin(5x/2) cos(x/2) dx = **4**（2019F-Q1）；
- tan²x = sec²x − 1（2016F-Q5(b)）；
- ∫₀^π (4cos²x − sin x) dx = ∫(2 + 2cos 2x − sin x)dx = **2π − 2**（2020F-Q1）。

**真题**：2016F-Q5(b)、2019F-Q1、2020F-Q1、2022F-Q3。

## 题型 3：部分分式 ★ CF 高频（10 年中 8 年考到，2017、2023 没考）

**标准流程**
1. 设出形式：
   - 不同一次因式：A/(x − a) + B/(x − b)；
   - **重根**：A/(x + 1) + B/(x + 1)²（2024F-Q4）；A/x + B/x² + C/(x + 3)（2019F-Q3）；
   - **不可约二次式**：A/(x − 2) + (Bx + C)/(x² + 2)（2021F-Q5、2020F-Q6 的 x² + 4）。
   - 题目指定形式时照题设做：2022F-Q4 要求写成 a/(x − 1) + (bx + c)/(x² + 3x + 1)（这个二次式本身其实可以分解，判别式为 5 > 0）。
2. 通分后让分子恒等，代入特殊值或比较系数，求出常数（「equivalence of numerators」1 分，解出常数 1 分）。
3. 逐项积分：A/(x − a) → A ln|x − a|；B/(x + 1)² → −B/(x + 1)；(2x + 3)/(x² + 3x + 1) 这类分子恰好是分母导数的 → ln|x² + 3x + 1|；q/(x² + 4) → (q/2) tan⁻¹(x/2)（由反三角函数的导数得到，2020F-Q6）。
4. 写 **+ c**。

**例**：1/(x² − 1) = ½[1/(x − 1) − 1/(x + 1)] ⇒ ∫ = ½ ln|(x − 1)/(x + 1)| + c（2018F-Q6）。(5x + 3)/(x + 1)² = 5/(x + 1) − 2/(x + 1)² ⇒ ∫ = 5 ln|x + 1| + 2/(x + 1) + c（2024F-Q4）。
**没有提示时**（2025F-Q3）：先自己把分母因式分解（key 第 1 分）。

**真题**：2016F-Q4、2018F-Q6、2019F-Q3、2020F-Q6(c)(d)、2021F-Q5、2022F-Q4、2024F-Q4、2025F-Q3。

## 题型 4：面积（对 x 积分或对 y 积分）

**思路**
1. 求交点、切点作为上下限。
2. **选择积分变量**：曲线写成 x = g(y) 更方便时，对 y 积分（2016A-Q13 的 2x = sin y、2017A-Q12、2022F-Q7）。key 往往两种方法都给分，但对 y 积分通常只需一个积分。
3. 面积 = ∫(右 − 左)dy 或 ∫(上 − 下)dx。
4. 利用对称性：椭圆 2025A-Q8；2022A-Q13(c) 关于 x 轴对称乘 2；心形 2021F-Q8 的 4 = 关于 y 轴对称的 2 × 上下两支之差 2√(2 − x²) 中的 2。
5. 把定积分解释为面积：2017A-Q16（u = 2x − a 代换后等于某区域面积）、2024A-Q15(c)（三角形面积 = 2k）。
5. 圆的弓形面积：由圆方程解出 y = 4 ± √(4 − (x − 3)²)，上下两支之差 = 2√(…)（2023F-Q7(a)）。
6. 判断曲线是不是圆：数值面积与 πr² 比较（2020A-Q16(b)）。

**真题**：2016A-Q13、2017A-Q12、2017A-Q16、2022A-Q13(c)、2024A-Q15(c)、2018A-Q15(b)、2020A-Q16、2021F-Q8、2022F-Q7、2023A-Q18(b)、2023F-Q7、2024F-Q8(e)、2025A-Q8。

## 题型 5：旋转体体积 ★ CA 高频

**公式**
- 绕 x 轴：V = π∫ₐᵇ y² dx；绕 y 轴：V = π∫ₐᵇ x² dy（**先把 x² 写成 y 的函数**）。
- 两条曲线之间的区域：V = π∫(y_外² − y_内²)dx（**不是** π∫(y_外 − y_内)²dx）。
- 圆环（甜甜圈，2024A-Q11）：x = 3 ± √(4 − y²) ⇒ V = π∫(R² − r²)dy = ∫₋₂² 12π√(4 − y²) dy。

**语境问法**
- 杯子的容积公式：用含字母 a、b、h 的积分推导（2017F-Q8）。
- 装到 80% 时的深度：令 ∫₀ʰ π x² dy = 0.8 × V_满，解出 h（2020A-Q9）。
- 注水的相关变化率：dV/dt = (dV/dh)·(dh/dt)（2025A-Q14(b)：由 V = ah³ 求 dV/dh）。
- 增量公式：δh ≈ δV ÷ (dV/dh)，其中 dV/dh = πx²|_{y=h}（2023A-Q17(c)）。
- 2022A-Q17 的体积积分在 (a)，(b)–(d) 是围绕 dV/dt = 300e^{−V/12000} 的增量、流速与分离变量（见「变化率与微分方程」讲义）。
- 球冠（2021A-Q13）：由圆方程得 y² = 20x − x²，对 x 从 0 到 h 积分。

**得分点**：✓ 用 x 或 y 表示半径 ✓ 正确的积分式（上下限 + π + 平方）✓ 计算（含单位、四舍五入）。
**真题**：2016A-Q17(c)、2017F-Q8、2018A-Q15(c)、2019F-Q8、2020A-Q9、2021A-Q13、2022A-Q17、2023A-Q17、2024A-Q11、2025A-Q14。
