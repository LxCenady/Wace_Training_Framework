# WACE Mathematics Applications · Cheat Sheet（题型 + 注意事项）

**通用规则**：公式表已给的公式不再重复，这里只写公式表之外的规则 · 解释题写清「哪个量 + 单位 + 增减方向 + 语境」· 两分题也要写过程（阅卷报告多次点名）· 图要用直尺、标刻度、标箭头（有向图、虚活动）· CA 题写出所用的输入（N、I、PV、PMT、FV、P/Y、C/Y 或回归/矩阵式）和关键输出，不写计算器按键 · 离散量（人数、期数、周数）按题意取整：「至少」向上，「最迟 / 最多」向下 · 金钱保留到分（题目另有要求时照办）

## 1 双变量数据分析（BIV）

**① 两向表与百分比** ★
- 行、列合计互相核对总数；缺失格由合计倒推（合计减已知格）。
- 百分比方向看解释变量：解释变量在行 ⇒ 行百分比（每行合计 100%）；在列 ⇒ 列百分比。每个百分比 = 格 ÷ 所在组合计 × 100。
- 比较关联：「A 组中 X 占 a%，B 组占 b%，高出 c 个百分点」，再说方向并结合语境。只比较人数、或比较错误的两组都失分。
- 多维表找最高率：先固定比较基准，逐维比较率，不比人数。

**② 散点图与 r** ★
- 描述关联三要素：方向（正/负）+ 形态（线性/曲线，明显弯曲直接说非线性）+ 强弱（weak / moderate / strong，引用 r 的数值）。
- r 与斜率同号；只给 r² 时 r = ±√r²，符号由斜率决定（平方根不能为负）。
- r 只量化线性关联；解释题要同时点出两个变量名。
- r 强不等于因果：说出第三变量（混杂因素）、反向因果或巧合，并举出语境中的具体因素。

**③ 最小二乘线** ★
- 计算器两变量统计读出 a、b；方程用题目的变量名，y = a + bx（y 为响应变量，x 为解释变量）；按题目要求取位数。
- 画线：取两个 x 值算出 y，描两点、用直尺连线，并标明这两点的坐标；线要穿过数据范围，经过关键近似点。
- 斜率：「x 每增加 1 个单位（写单位），y 平均增加（或减少）|b| 个单位（写单位）」。负斜率写 decrease。
- 截距：x = 0 时的预测值；x = 0 不现实或超出范围则无实际意义。
- r²：「约 r² × 100% 的 y 的变异可由 x 的线性关系解释，其余为未解释部分」；未解释比例 = 1 − r²（由未解释比例反求 r² 时同理）。

**④ 预测与外推** ★
- 代入前核对变量编码（如年份 ⇒ n）。
- x 在数据范围内（interpolation）且 r 强 ⇒ 预测可靠；x 超出范围（extrapolation）⇒ 不可靠；r 只是中等 ⇒ 结论写成「可能不有效」。
- 有多个预测变量时选 r 最强者，并写出理由。

**⑤ 残差与残差图** ★
- 残差 = 观测值 − 预测值；为负 ⇒ 实际值低于预测值，写出这句话。
- 残差图：横轴为题目指定的变量，纵轴为残差，画零线，负残差画在零线下方，按刻度描点。
- 诊断：残差随机分布在零线两侧 ⇒ 线性模型合适；呈曲线、漏斗形或有趋势 ⇒ 不合适。结论要写出残差的模式，不能只引用 r。

**⑥ 角色与结论**
- 解释变量是用来解释/预测的变量，响应变量是被解释的结果；按时间先后、或变量由谁设定（如价格由商家定）判断。
- 问 "does it prove …" ⇒ 答 No：不是所有区间（或关联）都成立，且无法排除偶然。

⚠ 易错：r² 当 r；截距与斜率写反；变量名不用题目的；残差符号写反；只写「高/低」不说相对于预测值。

## 2 数列的增长与衰减（SEQ）

**① 下标与初值**（公式表给出 T₁ = a 的形式，以题目下标为准）
- 递推式必须同时写出初值，并注明它是 T₀ 还是 T₁。
- 递推式与通项式要分清：问「第 n 项的规则」时写通项；问「每期如何变化」时写递推式。

**② 等差与等比** ★
- 等差：公差 d 的数值和符号各 1 分；减少时 d 为负。由 d 与截距写 T_n = dn + c 时，说明斜率 d、截距 c。
- 等比：减少 x% ⇒ r = 1 − x%（如 14% 减少 ⇒ 0.86，不是 0.14）；由数据求 r 用相邻两项之比。
- 平均变化率：减少时为 1 − r。
- 「第一次达到」某值：解指数或对数方程，取满足条件的最小整数期（「至少 / 首次」向上取整），写出完整结论（第几周、第几年末）。

**③ 累计量（公式表未给出）**
- 等差和 Sₙ = n(T₁ + Tₙ)/2；等比和 Sₙ = T₁(1 − rⁿ)/(1 − r)。
- 累计量 = 各项之和 + 初始量；比较两人或两方案时，分别求出各自达到目标的日期再比较。
- 项数差 1（只加到第 n − 1 项）是常见错误。

**④ 一阶线性递推 Tₙ₊₁ = aTₙ + b** ★
- a 是每期保留比例（1 − 损失率）；b 是每期固定增减，写单位并与 T 的单位一致（如千人）。
- 稳态（steady state）：S = b/(1 − a)，要求 |a| < 1；令 Tₙ₊₁ = Tₙ = S；写出数值，并与题目的阈值比较（能否耗尽、能否达到目标）。
- 维持稳定所需的取出量 = 稳态下每期的增长量；离散对象（如鱼数）向下取整。
- 由三个连续项反求 a、b：列出两个方程联立解。
- 分段：变化点之后换用新的 a、b，从变化时的值开始递推。
- 作图：只描点不连线，按题目指定的间隔取点，读准刻度。

⚠ 易错：r 与 1 − r 混淆；下标错位（第 5 周开始时 ≠ 第 5 项）；稳态方程写错；不检验收敛；分段后仍用旧参数；取整方向错。

## 3 图与网络（GRF）

**① 术语与性质** ★
- simple：无环、无重边（两条理由分别给分）；connected；complete Kₙ 的边数 n(n − 1)/2；tree：连通、无回路、n − 1 条边。
- bipartite：顶点分成两组，每条边只连接两组；画图时两组明显分开。
- bridge（割边）：去掉后图不连通的边；题目问哪条边不能删，找的就是割边。
- walk ⊃ trail（边不重复）⊃ path（顶点不重复）；closed walk 的起点与终点相同；cycle 是闭合的 path。
- 区分 Eulerian（每边一次）与 Hamiltonian（每点一次）。

**② 邻接矩阵** ★
- 无向图矩阵对称；有向图按箭头填写，通常不对称；加权网络填权重；对角线非零表示环。
- 第 i 行的非零元素个数 ⇒ 从 i 出发的一步路线数（重边按重数计）；M ⁿ 的 (i, j) 元素 = 从 i 到 j 恰好经过 n 步的路线数（包括往返）。
- 列路线时列全（至少 3 条、列全各有分）；路线应为 open path（起点与终点不同，不重复顶点）。
- 由矩阵画图：1 画一条边，2 画重边，对角线非零画环；无向图只数一次。

**③ Euler 公式与平面图** ★
- v + f − e = 2（公式表）。验证时先写 v、e、f 的数值（f 包括外部的面），再写 LHS = RHS；由此可求 e 或 f。
- 重画为平面图：绕行使边不交叉，保留全部顶点与边，每条重画的边都可得分。
- 限定面数补边：由 Euler 公式算出所需总边数，再减去已有边数。

**④ Eulerian 判定** ★
- 先确认连通；数奇度顶点个数：0 个 ⇒ Eulerian（有欧拉回路，回到起点）；2 个 ⇒ semi-Eulerian（欧拉迹，起止于这两个奇度顶点）；4 个或更多 ⇒ 两者都不是。
- 使其可行：在两个奇度顶点之间加边；写出加边后的路线。
- 语境路线（巡检、送货）：起点、停车点选奇度顶点，理由是路线不回到起点。
- 解释结论时写出奇度顶点的个数。

**⑤ Hamiltonian** ★
- 每个顶点恰好经过一次：闭合为 cycle（回到起点），不闭合为 path（终点不同于起点）；写出字母序列，并说明它是哪一类。
- 注意题目是否允许重复经过顶点：不允许时不要重复。

**⑥ 最短路线（加权图）** ★
- 在网络上标注：从起点出发，逐点标出到该点的最短距离，直到终点；再从终点回溯写出完整顶点序列。路线和长度分别得分。
- 有向图必须沿箭头方向；单位换算（百米 ⇒ 米、分钟、元）。
- 费用 = 固定费用 + 单价 × 距离；途中停留 = 行程 + 停留时间。
- 改造道路：设新路长为 x，比较经新路与原最短路线的长度，列不等式求 x 的范围。

**⑦ 访问所有顶点的最短行程**
- 列出全部可行路线（题目允许重复时要比较完整总权重），逐条计算总长，取最小者；写出路线、最短总长、终点。

⚠ 易错：connected 与 complete 混为一谈；只写 not simple 而不说明是环还是重边；有向图忽略箭头；只写长度不写路线；割边题只答边不答名称；Euler 验证只写 verified 而不写代入。

## 4 时间序列分析（TSI）

**① 移动平均** ★
- 奇数点（3、5 点）：窗口的平均放在中间期。
- 偶数点（4、6 点）：中心化，首尾数据各取一半权重后再除以窗口长度，结果放在中间期（写出「centred」）。
- 窗口 = 周期长度：季度数据 4；每周 5 个营业日 ⇒ 5；每周 6 天 ⇒ 6；每周 7 天 ⇒ 7。
- 作用：平滑掉短期与季节性波动，使长期趋势更清楚。

**② 季节指数（平均百分比法）** ★
- 百分比 = 实际值 ÷ 对应的季节均值（中心化移动平均）× 100%；同一季节的百分比取平均得原始指数，再归一化使平均为 100%（季度指数之和 400%，5 天一周指数之和 500%）。
- 计算用小数（110.76% ⇒ 1.1076），不要把百分数直接相乘或相除。
- 补全表格：缺项 = 归一化总和减去其余各项。
- 解释：指数 > 1 表示该季节高于平均水平，< 1 表示低于平均水平；写出季节或星期，并说明高出或低出的百分比。

**③ 去季节化与还原** ★
- 去季节化值 = 实际值 ÷ 季节指数（小数）；还原 = 去季节化值 × 季节指数。
- 乘除方向不能搞反；注意单位（如百元 vs 元）；取整放在最后一步。

**④ 时间编码与线性趋势** ★
- 对去季节化数据做最小二乘，写 y = a + bt，用题目的变量名。
- 时间编码：季度连续编号；按天计的数据，按每周 k 天逐天数，t = (周数 − 1) × k + 当周第几天。例：周一至周五的数据，第 4 周周五 t = 3 × 5 + 5 = 20；周二至周日（6 天）的数据，第 4 周周四 t = 3 × 6 + 3 = 21。代入前核对。
- 斜率：正 ⇒ 增长，负 ⇒ 下降；写出每期平均变化 |b| 和单位。
- 画趋势线：取两个 t 值算出 y，描两点，用直尺连线，标明截距位置。

**⑤ 预测与可靠性** ★
- 去季节化预测 = a + bt；实际预测 = 去季节化预测 × 对应季节指数；按题意取整。
- 预测时期超出已知数据范围 ⇒ 外推（extrapolation），结论写成「不可靠（unreliable）」并说明理由。

**⑥ 描述与决策**
- 描述趋势（斜率方向及语境）与季节（高季、低季，并写指数值）。
- 安排员工休假等决策：选季节指数最低的时段，并引用指数值作为依据。
- 用趋势结论判断长期前景：引用斜率，不只描述图形。

⚠ 易错：指数用了百分数；偶数窗口忘记中心化或首尾未减半；时间编码差一；用原始数据而不是去季节化数据回归；把外推当作可靠预测；移动平均值放错期。

## 5 贷款、投资与年金（FIN）

**① 计息与递推**（复利与有效利率公式见公式表）
- 每期利率 = 年利率 ÷ 每年计息次数；期数 = 年数 × 次数。
- 递推式：Aₙ₊₁ = (1 + r)Aₙ ± d（存入为 +，还款为 −），并写出初值 A₀（本金或当前余额）。
- 名义年利率 = 每期利率 × 每年次数（不是有效年利率）；由增长因子求每期利率 = 因子 − 1。
- 比较方案：同一名义利率下计息越频繁，有效年利率越高；投资取较高的有效利率，借款取较低的有效利率；按日计息时 m = 365。

**② 财务求解器（TVM）** ★
- 逐项写出参数：N（付款次数，不是年数）、I（名义年利率）、PV、PMT、FV、P/Y、C/Y；两者若相同则按每期计息。题干写期初付款则用 BEG，期末付款用 END。
- 符号：同一方的现金流同号、对方异号；借款还清时 FV = 0；存款目标时 FV 与存入的 PMT 异号。
- 求 N 得到小数时，按题意取整（还清用向上，最多能支付用向下），再进入下面的末期处理。
- 求 PMT：按题目要求的期限和精度取值，通常向上取整到分。
- 求 I：N、PV、PMT、FV 已知，解得后写出利率并换算。

**③ 贷款还款表与总额** ★
- 每期利息 = r × 期初余额；期末余额 = 期初余额 × (1 + r) − R（R 为每期还款）；表格每一列都要正确。
- 完整期数 N 后的余额 Bₙ；末期还款 = Bₙ × (1 + r)；总还款 = N × R + 末期还款；总利息 = 总还款 − 本金；若问总成本，再加首付。
- 中间的利率与余额保留足够的小数位，不用四舍五入后的利率代入（否则末期还款会偏差很大）。
- 若每期还款不超过当期利息，余额不会下降，永远还不清，要写出这一理由。

**④ 年金提取、永续与利率换算** ★
- 提取型年金：Aₙ₊₁ = (1 + r)Aₙ − P（P 为每期提取额）；复利按月、提取按年时先求有效年利率，再写递推式。
- 保持本金不减少的最大提取额 = 每期利息 = r × PV。
- 可维持的年数：求解器输入 PV、PMT、I、FV = 0，取小数形式的 N 后再按题意取整。
- 永续年金：PV = PMT ÷ 每期利率（PMT = PV × 每期利率）；年金转永续时，先求转换时刻的余额，作为新的 PV。
- 每期利率按付款周期取，不直接用年利率除以付款次数。

⚠ 易错：直接用年利率算每期利息；P/Y 与 C/Y 不一致却未换算；N 用了年数；存取款符号相同；忘记末期余额的利息；把最大提取额算成本金的一个比例；2 分题只写答案没有参数。

## 6 网络与决策数学（NDM）

**① 生成树与 Prim 算法** ★
- 生成树：连接全部顶点、无回路、恰有 n − 1 条边。
- Prim：任选起点，每步加入与已选顶点相连、权重最小且不成回路的边；列出每一步选的边及其长度，并在图上高亮；总长度带单位。
- 强制连接（如必须接入主电源）要先算进树中。
- 最短路线（GRF）与最小生成树（NDM）不同，不要混用。

**② 最小连接方案（情境）**
- 成本 = 总长 × 单价；与预算比较后写出结论。
- 边的成本变化或某条边不可用：写出被去掉的边、新加入的边和成本变化量，并判断树是否改变。

**③ 项目网络** ★
- 活动名与时长标在箭线上，所有箭线都要有方向；紧前活动全部指向后续活动。
- 虚活动（dummy，时长 0，画成虚线）用于表达依赖关系：两个活动的紧前活动不完全相同时需要，且要画箭头。
- 紧前活动表要完整，漏写一个前驱即失分。

**④ 扫描、浮时与关键路径** ★
- 正向扫描：ES = 所有紧前活动 (ES + 时长) 的最大值（取大，不取和）；终点的 ES 即最短工期。
- 反向扫描：LST = 所有后续活动 LST 的最小值 − 时长（取小）；终点的 LST = 工期。
- 浮时 = LST − ES；浮时为 0 的活动即关键活动；关键路径是从起点到终点全部由关键活动组成的路径，要写出完整顺序。
- 延误不超过浮时，工期不变；同一路径上的浮时共享。
- 缩短或延误活动后，要重新扫描，关键路径可能改变；只缩短非关键活动无效。
- 时间换算：先算天数或小时，再换成钟点或日期。

**⑤ 最大流与最小割** ★
- 列出全部 S → T 路径（系统地展开，避免遗漏）；每条路径的流量 = 路径上剩余容量的最小值；按顺序分配并扣减共享弧的容量；各路径流量之和为最大流。
- 割的容量 = 只计从 S 侧指向 T 侧的弧之和（反向弧不计）；割必须把 S 与 T 分在两侧。最大流 = 某个割的容量时，该割即最小割，据此验证。
- 流量守恒：中间节点流入 = 流出；S 的总流出 = T 的总流入；流量等于容量的弧为满容量。
- 单位：每分钟 × 60 = 每小时。
- 增广路径：沿剩余容量的路径增加流量；只有最小割上的弧被升级才能增大最大流。

**⑥ 分配问题与匈牙利算法** ★
- 二分图：左侧为人员，右侧为任务，行对应人员、列对应任务；不可行的格按题目约定填写；行列数不等时补零行或零列成方阵。
- 求最大化：用矩阵中的最大元素减去每个元素，转为求最小化。
- 每行减去该行最小值；每列减去该列最小值。
- 用最少的水平线和竖线覆盖所有 0：线数 = 阶数 ⇒ 每行每列各取唯一的 0 作分配；线数 < 阶数 ⇒ 在未覆盖元素中取最小值 m，未覆盖元素减 m，两线交叉处加 m，回到覆盖步骤。
- 总成本或总产量要用原矩阵的数值相加，不用调整后的矩阵。

⚠ 易错：最大化问题忘记转换；覆盖线数判断错误；取和而不是取大（ES）；浮时非零的关键活动；割计算把反向弧算入；最大流漏写路径；匈牙利分配没有唯一性；有向网络漏画箭头（包括虚活动）；每分钟与每小时混淆。
