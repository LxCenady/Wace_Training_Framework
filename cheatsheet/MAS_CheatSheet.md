# WACE Mathematics Specialist · Cheat Sheet（题型 + 注意事项）

**通用规则**：主辐角 −π < θ ≤ π · 写数学语句，不写计算器语言 · 解释时不写 "it"，写清是哪个量（如 "SD **of the sample mean**"）· ln|…| 加绝对值（真数恒正时可不写）· 不定积分 + c · 变化率带单位 · 展开括号、抄写时防符号错（各年报告反复点名）· 熟记特殊角三角值 · 题目要求 prove / show 时用代数，"CAS 说无解" 不算证明 · 写清结论

## 1 复数

**① 形式转换与运算**
- 除法：分子分母乘分母的共轭。乘方、开方：先写成 r cis θ 再用 De Moivre（(√3 − i)⁵ = 32 cis(−5π/6) = −16√3 − 16i）。
- ⚠ 第三象限：−1 − i 的主辐角是 −3π/4，不是 π/4，也不能写 5π/4。先画图定象限。
- 已知 z = 3 + bi、tan θ = 2 ⇒ b = 6，r = 3√5。

**② 解 zⁿ = w** ★ 每年都有
- w 写成 R cis φ（模 1 分、辐角 1 分）→ z = R^(1/n) cis((φ + 2kπ)/n)，k = 0, …, n − 1（通式 1 分）→ 按题目范围列出**全部** n 个根，相邻间隔 2π/n。
- 例：z⁴ = −16i ⇒ 2 cis(−5π/8)、2 cis(−π/8)、2 cis(3π/8)、2 cis(7π/8)。
- zⁿ = 1 的根：在单位圆上等距（解释 2 分：半径 1、等间隔）；全部根之积 = (−1)ⁿ⁺¹；z⁴³ = 1 与 z⁴⁷ = 1 只有公共根 1（43、47 互质）。
- zⁿ 为正实数：n·arg z 是 2π 的整数倍（z = 4 cis(5π/6) ⇒ 最小 n = 12）。

**③ 多项式的复根**
- "Show (z − α) is a factor"：算 P(α)，**写出每一项**，得 0（key：not just the statement）。
- 实系数 ⇒ ᾱ 也是根 ⇒ (z − α)(z − ᾱ) = z² − 2Re(α)z + |α|² → 用除法或比较系数求剩余因式 → 解二次。
- 例：P(2 + 4i) = 0 ⇒ 因式 z² − 4z + 20，剩余 z² − 2z + 3 ⇒ z = 1 ± √2 i。⚠ z² − 2z + 3 不能拆成 (z − 3)(z + 1)（2021 报告）。
- 已知两个复根反求系数：两对共轭根各给一个二次因式，再由常数项求实根。

**④ 乘法的几何意义**
- 模板（各 1 分）：「Multiplication by w = r cis θ dilates the modulus by a factor r and rotates anticlockwise by θ (clockwise by |θ| if θ < 0) about the origin.」乘 z⁻¹：倍数取倒数，转向相反。
- 求 zwⁿ 落在第二象限的 n：每次转 arg w；|w| = 1 时有周期，答案写全，如 n = 3 + 12k、4 + 12k、5 + 12k。

**⑤ 轨迹：由方程画图**
- |z − a| = r：圆。|z − a| = |z − b|：a、b 的中垂线。Arg(z − a) = θ：射线，**端点 a 空心**。
- |z − a| + |z − b| = k：k 大于 |a − b| 时是椭圆，**等于时退化为线段**。
- |z + 2| = |z − i| + √5（差等于两点距离）：从 i 出发的射线，**端点 i 实心**。
- (z + i)·conj(z + i) = 2 ⇒ 圆心 −i、半径 √2；z − z̄ ≤ 6i ⇒ Im z ≤ 3。
- 画图得分点：关键点或圆心、边界位置、实线或虚线、阴影区域。

**⑥ 轨迹：由图写方程**：只能用 z，不用 x、y；圆 ⇒ |z − c| ≤ r；扇形 ⇒ 两个 Arg 不等式 + 一个模不等式；角度用三角函数精确求。

**⑦ 轨迹上的最值**
- 圆上点到 c 的距离：最远 d + r，最近 |d − r|（d = 圆心到 c 的距离）。射线上的最近点：作垂线。
- 最大辐角在切线处：先由 sin θ = r/d 求出切线与圆心连线的夹角，再加上圆心的辐角，注意题目规定的范围。

**⑧ 向量与几何法**
- z + r（两个等长向量相加）构成菱形 ⇒ arg(z + r) = θ/2；z − k 构成三角形，用正弦或余弦定理。
- 正六边形：先看中心在哪里。以原点为中心时，各顶点模相等、辐角相差 π/3；2025F-Q7 中 z₀ 在原点，模依次为 r、√3r、2r、√3r、r，乘积为 6r⁵。
- 技巧：Σ n·iⁿ 每 4 项一组，每组和为 2 − 2i；(a + bi)³ 取模 ⇒ (a² + b²)³ = |…|²。

## 2 函数与图像

**① 复合函数定义域** ★ 最常被点名（6 个年份）
- f(g(x)) 有定义 ⇔ x ∈ dom g **且** g(x) ∈ dom f。代入后先别化简；每个限制条件通常各 1 分。
- 限制来源：分母 ≠ 0；根号下 ≥ 0；**根号在分母时 > 0**；ln 的真数 > 0。
- 例：f = 1 − √(x − 4)，g = 1/x² ⇒ 1/x² ≥ 4 ⇒ −½ ≤ x ≤ ½ 且 x ≠ 0。f = √(4 − x)，g = 1/x² ⇒ x ≤ −½ 或 x ≥ ½。
- ⚠ √(x²) = |x|，所以 f(h(g(x))) 未必等于 f(x)。

**② 反函数**
- 存在 ⇔ 一一对应（水平线检验）；否则限制定义域，「最大可能的定义域」取到顶点为止。
- 求法：交换 x、y（1 分）→ 解出 y → 正负号由 **ran f⁻¹ = dom f** 决定；dom f⁻¹ = ran f。
- 图像关于 y = x 对称，标出对应的端点 (a, b) ↔ (b, a)。f⁻¹(−1) 是否有定义：先看 −1 在不在 ran f 里。
- 反三角函数：x = 2 tan y ⇒ y′ = 2/(4 + x²)（用隐函数求导，再用 1 + tan²y 换成 x）。
- 解释 "g is not one-to-one"：「because g(1) = g(−1) = 1」，别写 "it is many to one"。

**③ y = 1/f(x) 作图** ★ CF 常考
- f 的零点 ⇒ 竖直渐近线；x → ±∞ 时 f → ±∞ ⇒ 水平渐近线 y = 0。
- f 的竖直渐近线 x = b ⇒ 1/f 在 (b, 0) 是空心点（值域去掉 0）；f 的水平渐近线 y = c（c ≠ 0）⇒ y = 1/c。
- 极大值 (a, m) ↔ 极小值 (a, 1/m)；f = ±1 的点不动；正负号不变；f 的空心点 (a, b) ⇒ 1/f 的空心点 (a, 1/b)，b = 0 时变成单侧渐近线。
- 求值域：读 1/f 的图，注意取不到的值。

**④ 绝对值函数**
- |f(x)|：x 轴下方翻到上方；f(|x|)：保留右半边再镜像到左边；f(−|x|)：保留左半边再镜像到右边。
- |f(x)| = k 的解的个数：用水平线 y = k 去截，端点 k 单独检查；可以画出个数函数 N(k)。
- |x + 1| + |x + a| = k 的解集是区间 ⇒ 两个绝对值之和的平底区间就是解集（a = 3，k = 2）。
- 由图定 y = a|x − b| + c：顶点给出 b、c，斜率给出 a。

**⑤ 有理函数：由图定参数 / 作图**
- 零点 ↔ 分子的因式；竖直渐近线 ↔ 分母的因式；水平渐近线 = 首项系数之比；斜渐近线 = 多项式除法的商（x − 1 − 3/(x + 1) ⇒ y = x − 1）。
- 重因子：在分子 ⇒ 图像接触 x 轴但不穿过；在分母 ⇒ 渐近线两侧同号（同趋于 −∞）。
- 理由要写（1 分）：「c = 3 since x = 3 is a vertical asymptote」。没有零点的二次式 a(x − 3)² + c 要求 a、c 同号。
- 作图清单（各 1 分）：x 截距、y 截距、竖直渐近线、水平或斜渐近线、转折点（有就标）、渐近线两侧的趋势。先检查有没有约掉的因子（洞）。

## 3 三维向量与线性方程组

**① 线性方程组** ★ 10 年中 7 年在 CF 出现
- 消元三步（各 1 分）：用两对方程消去同一个变量 → 解出一个变量 → 回代。
- 含参数：化成 (k − 2)z = c − 5 ⇒ k ≠ 2：唯一解（c 任意）；k = 2 且 c ≠ 5：无解；k = 2 且 c = 5：无穷多解。
- ⚠ **无穷多解要写出解集**（2022 报告：很多人写到「无穷多解」就停了），用参数或变量关系表示。例：z = t ⇒ y = t − 1，x = (11 − 3t)/2，即 r = (11/2, −1, 0) + t(−3/2, 1, 1)。
- 几何解释：唯一解 = 三平面交于一点；一个参数 = 交于一条直线（可能有两个平面重合，两点都要写）；两个参数 = 三平面重合；无解 = 有平行平面，**或者**三个平面两两相交成三条平行直线（三棱柱，2020F-Q4）。先看法向量是否成比例。

**② 平面方程**
- 参数式 r = a + λu + μv ⇒ n = u × v（叉乘每个分量写清楚）⇒ r·n = a·n，即 ax + by + cz = k。
- 过三点：两条边向量叉乘；z = 2x + y + 4 ⇒ n = (2, 1, −1)。
- 包含直线 L 且垂直于平面 1 ⇒ n₂ = d_L × n₁；包含两条相交直线 ⇒ n = d₁ × d₂。

**③ 交点、夹角、距离**
- 直线与平面：把 r = a + λd 代入，解 λ，写出点（3 分）。直线与球：得到 λ 的二次方程，两个解、相切、无交点；或比较球心到直线的距离与半径。
- 两条直线：令分量相等，用两个方程解 λ、μ，**代入第三个检验**；不成立就是不相交，这一步就是证明。
- 平面上离点 L 最近的点：过 L 沿法向量作直线，与平面求交点。
- 线面角：sin θ = |d·n|/(|d||n|)。点到平面距离 = |n·(P − A)|/|n|，A 为平面上任一点，此式不在公式表上，用时附推导或改用法线法。平行六面体体积 = |c·(a × b)|。

**④ 球**：一般式配方，如 x² + y² + z² − 4x + 2y − 6z + 5 = 0 ⇒ |r − (2, −1, 3)| = 3；直径端点 ⇒ 球心是中点（报告：常算错）；与平面相切 ⇒ 半径 = 球心到平面的距离；过长方体所有顶点 ⇒ 球心是体对角线中点。

**⑤ 向量证明**（CF、CA 都有）：用基向量表示所需向量 → 展开点积（key：得 4 项）→ 用已知条件（正方形 ⇒ a·b = 0、|a| = |b|）→ 下结论。记号有分。

**⑥ 应用**：反射 ⇒ B→S 与 B→R 的单位向量之和 ∥ n；坡道上最陡的下降方向在坡面内且垂直于水平线；运动物体的距离问题见下一节。

## 4 向量微积分与运动（只在 CA 卷）

**① 求导**：v = r′，a = v′，逐个分量求；速率 |v|；在图上画向量（起点放在该时刻的位置）。速率恒定 ≠ 匀速（方向在变），要写出用到了 sin² + cos² = 1（1 分）。

**② 积分求 r(t)**
- 逐个分量积分，加**常数向量**，用 r(0) 定每个分量（2018 报告：很多人写不清）。
- 重力 + 风：a = (0, −9.8) ⇒ r = ((70cos θ + w)t, 70 sin θ·t − 4.9t²)；射程：令 y = 0 解 t，再代入 x。
- 水平阻力 + 竖直升力：x′ = 32e^(−0.05t)，h″ = s − 9.8，由给出的 r 反求 s。落地角用速度向量与坡面的夹角。

**③ 消参得笛卡尔方程** ★
- sin² + cos² = 1 ⇒ 圆或椭圆；倍角公式直接得 x、y 关系 ⇒ 抛物线一段；先化成同一角度再用 sin² + cos² ⇒ 一般曲线（如「8」字形）；(eᵗ + e⁻ᵗ)² − (eᵗ − e⁻ᵗ)² = 4 ⇒ x² − y² = 4；x 是 t 的一次式 ⇒ 直接解出 t 代入 y。
- ⚠ **写出取值范围**，由 t 的范围推出，常常 x、y 都要限制：x ≥ 2 **且 y ≥ 0**（只写 x ≥ 2 丢分）；1 ≤ x ≤ e³。

**④ 路程与位移**
- 路程 = ∫ₐᵇ √(ẋ² + ẏ²) dt；先定起止时刻：一圈的时长 = 各分量周期的最小公倍数（2π、4π、6π 都考过），或由坐标反求 t。
- 解释：∫₀¹ v dt =「the change in displacement (position vector) during the first second」；∫|v| dt = 路程。2025 报告点名这两者混淆。在图上画位移向量：从 r(a) 指向 r(b)。

**⑤ 最近距离与相对位置**
- 同一时间参数：相对位置 d(t) = r_P − r_Q（问相对位置时顺序要对，1 分）；最近 ⇔ d(t)·(v_P − v_Q) = 0；「多久在 50 m 以内」⇒ 解 |d(t)| < 50。
- 速度和出发时间都可调 ⇒ 两条直线之间的最短距离：用独立参数 λ、μ，令 PQ 同时垂直于 d₁、d₂。
- 下降角 = |90° − φ|（φ 为速度与 k 的夹角），或直接用 sin⁻¹(|v_z|/|v|)。

## 5 积分技巧与应用

**① 给定代换的定积分** ★ CF 几乎每年（4–7 分）
- 五步（各 1 分）：由代换求 dx → **换上下限** → 把被积式完全化成新变量并化简 → 积分 → 代值得精确值。
- 三角代换：√(a² − x²) 用 x = a sin θ；x² + a² 用 x = a tan θ。例：∫₀^√3 √(1 − x²/4) dx，x = 2 sin θ ⇒ ∫₀^(π/3) 2cos²θ dθ = π/3 + √3/4。
- 不定积分版（∫x(1 + x)ⁿ dx）：不换限，最后回代成 x。⚠ 代换后化简常出错（2020、2023 报告）。

**② 三角恒等式**：cos² = ½(1 + cos 2x)；sin² = ½(1 − cos 2x)；(sin x + cos x)² = 1 + sin 2x；积化和差 2 sin A cos B = sin(A + B) + sin(A − B)；tan² = sec² − 1。

**③ 部分分式** ★ CF 高频
- 形式：不同一次因式 A/(x − a) + B/(x − b)；重根 A/(x + 1) + B/(x + 1)²；不可约二次 (Bx + C)/(x² + 2)。题目指定形式时照题设写。
- 通分后让分子恒等（1 分）→ 代特殊值或比较系数求常数（1 分）→ 逐项积分：ln|x − a|、−B/(x + 1)、分子是分母导数时 ln|二次式|、q/(x² + 4) → (q/2)tan⁻¹(x/2) → 写 + c。
- 例：1/(x² − 1) ⇒ ½ ln|(x − 1)/(x + 1)| + c；(5x + 3)/(x + 1)² = 5/(x + 1) − 2/(x + 1)²。没给提示时先自己分解分母（1 分）。

**④ 面积**
- 先求交点、切点；曲线写成 x = g(y) 更方便时对 y 积分（key 两种方法都给分）。
- 对称性：椭圆、关于坐标轴对称的图形乘倍数；圆的弓形：上下两支之差 2√(…)。
- 定积分可以解释为几何面积（三角形、梯形）。用数值面积与 πr² 比较，可以判断曲线是不是圆。

**⑤ 旋转体体积** ★ CA 高频
- 绕 x 轴 π∫y² dx；绕 y 轴 π∫x² dy（先把 x² 写成 y 的函数）；两曲线之间 π∫(R² − r²)，⚠ 不是 π∫(R − r)²。
- 积分式要写 π、上下限、dx 或 dy（上下限 + 记号合给 1 分）。
- 语境：装到 80% 时的深度 ⇒ 令 ∫₀ʰ πx² dy = 0.8V 解 h；注水速率 dV/dt = (dV/dh)(dh/dt)；增量 δh ≈ δV ÷ πx²|_(y=h)；圆环 R、r = 3 ± √(4 − y²)。

## 6 变化率与微分方程

**① 隐函数求导**
- 两边对 x 求导，含 y 的项乘 y′，乘积和复合照常用法则。题目说不要解出 y′ 时就别解，直接代点求值。
- 水平切线：令分子 = 0，与原方程联立；二阶导：对已求出的式子再求一次导，代入 x、y、y′。

**② 相关变化率** ★
- 写关系式（必要时消去多余变量，也可以保留两个变量隐式求导）→ 对 t 求导 → 代入**该时刻**的值（往往先求出 θ、h）→ 带单位。
- 例：正六边形 A = (3√3/2)s²，s = 4、ds/dt = 0.5 ⇒ dA/dt = 6√3 ≈ 10.39 cm²/s。灯塔每分钟 3 转 ⇒ dθ/dt = π/10 rad/s。
- 圆周运动（摩天轮、旋转木马）：dθ/dt = 2π/T；用余弦定理 s² = 89 − 80cos θ 或 y = R sin(θ + α)；对 t 隐式求导；求 ds/dt 的最大值再求一次导（几何上是 PC 与圆相切时）。⚠ 离地高度 = 相对中心的高度 + R。

**③ 斜率场**
- 代点求斜率（1 分）；由场反推方程：看斜率只随 x 变还是只随 y 变，哪里为 0、哪里无定义。
- 画解曲线：经过指定点、顺着短线方向、标出对称性；分母为 0 而分子 ≠ 0 处切线竖直，曲线在此折返；斜率为 0 处是水平切线；**斜率最大处是拐点**（2025A-Q16 拐点在 (3, −1)）。

**④ 分离变量**
- 写成 ∫g(y)dy = ∫f(x)dx（1 分）→ 积分，只加一个常数，ln 带绝对值 → 代初值 → 写成显式。
- dP/dt = kP ⇒ P = P₀eᵏᵗ。⚠ 「瞬时增长率为 10%」是 dP/dt = 0.1P（P₀ = 30000e^(−4.5) ≈ 333），不能当成每年 1.1 倍（≈ 412）。
- 例：dh/dt = −1/(100h) ⇒ h² = h₀² − t/50；dv/dt = −9.8 − 2v ⇒ v = 4.9(e^(−2t) − 1)，深度要再对 v 积分。

**⑤ Logistic 增长** ★
- dP/dt = rP(k − P) ⇔ P = k/(1 + Ae^(−rkt))：承载量 = 使 dP/dt = 0 的非零 P；**增长最快时 P = k/2**，最大增长率 = r(k/2)²。
- ⚠ 字母以题目为准（有的题 k 是比例常数，有的写成 (1/r)P(k − P)）。例：P = 18000/(10.25e^(−0.15t) + 1) ⇒ 承载量 18000，最大增长率 0.15 × 9000 × ½ = 675 匹/年。
- 作图：k/2 < P₀ < k ⇒ 全程 concave down，没有拐点；P₀ > k ⇒ 递减趋近 k；承载量改变 ⇒ 新的拐点和渐近线。
- 解释：P < k/2 时增长率随 P 增大，P > k/2 时减小并趋近 k。不是 logistic 的方程（如 0.001(100 − P)²）要直接分析斜率的变化。

**⑥ 速度是位移的函数 v = f(x)** ★★ 报告三次点名
- a = dv/dt = v·dv/dx = d(½v²)/dx。⚠ dv/dx 本身不是加速度。例：v = −0.2x ⇒ a = 0.04x；v = x/8 ⇒ a = x/64。
- x(t)：dx/dt = v(x) 分离变量，代初始位置。例：v = x/8，x(0) = 192 ⇒ x = 192e^(t/8)。
- 判断 SHM：a = −n²(x − c)（与位移成正比、方向相反）才是；a = 0.04x 不是。

**⑦ 简谐运动 SHM**
- ẍ = −n²x ⇒ x = A cos(nt + φ)；T = 2π/n；v_max = An；v² = n²(A² − x²)。
- 定 A 和相位：x(0) = 0 且 v(0) > 0 ⇒ A sin(nt)；没给方向时 ±A sin 都给分；n = 2、x(0) = −1、v(0)² = 32 ⇒ A = 3。
- 路程：每个周期 4A、每半个周期 2A；不足半个周期且起点不在平衡位置或端点时用 ∫|v| dt。阻尼：A = A₀e^(−kt)，A < 0.01 视为停止。

**⑧ 增量公式**：δy ≈ (dy/dx)δx；δN ≈ (dN/dt)·δt（dN/dt 直接由方程给出，注意时间单位）。

## 7 统计推断（只在 CA 卷）

**① X̄ 的分布与概率** ★
- 「By the CLT, since n is large, X̄ is approximately normal with mean μ and SD σ/√n」（正态、均值、标准差共 3 分）。总体是正态时任意 n 都成立。
- 总体不是正态（均匀、指数、偏态）：做法相同；被问「答案变不变」时答不变 + CLT 理由。
- 总和题：50 次共 < 8.96 kL ⇔ X̄ < 179.2 L。画 X̄ 的分布：以 μ 为中心的窄钟形，宽约 ±3σ/√n，要求时标出概率区域。

**② 求样本量**
- 先画图判断是双侧、单尾还是半区间，再求临界 z：P(|X̄ − μ| < d) = 0.98 ⇒ z = 2.326；P(X̄ > 25) = 0.03 ⇒ z = 1.881；P(0 < Z < k) = 0.4 ⇒ k = 1.282。
- n = (zσ/d)²：要求「至少」时向上取整（304.3 ⇒ 305，600.25 ⇒ 601）；由区间反推 n 时取最近整数（z 取 2.576 和 2.58 造成的差异 key 都接受）。

**③ 置信区间**
- x̄ ± z·s/√n。反推：中点 = x̄；半宽 = z·σ_X̄（150 ≤ μ ≤ 200 ⇒ σ_X̄ = 25/1.96 = 12.76）；由宽度和 n 求 s。
- 样本量变化：宽度 ∝ 1/√n（n × 16 ⇒ 宽度变为 1/4）；2n ⇒ 标准误除以 √2。

**④ 解读置信区间** ★ 必背（先表态 True / False，再给理由）
- μ 固定但未知；某个具体区间要么含 μ，要么不含，**无法知道**。
- 95% 指重复抽样时约 95% 的区间含 μ，**不是**「μ 落在这个区间里的概率是 95%」。
- 下一个样本均值不一定落在区间内；单个个体更不一定（个体的变异远大于样本均值的变异）。
- 区间更宽不代表更可能含 μ；50 个区间里有 10 个偏低属于正常波动；但大量区间不含 μ（远超 5%，如 500 个中 298 个）就是证据，只是仍不能断定原因。
- 把同一个样本复制一遍凑成 2n 不是新的随机样本，区间没有真正变窄；两个独立随机样本合并是可以的，精度更高。
- 不同样本量的区间不能直接这样比较；样本均值更低也不能单凭这一点说新方法更好。

**⑤ 用区间检验说法**：构造新样本的 μ 区间（如 182.5 ± 1.96 × 15/6 = (177.6, 187.4)）→ 说法的值 175 在不在区间里 → 下结论。只能对均值是否不同下结论，不能推断样本来源。

**⑥ 精度因素**：n 增大 ⇒ σ_X̄ 减小、区间变窄、远离 μ 一侧的尾部概率变小；置信水平提高 ⇒ 区间变宽；σ（或 s）增大 ⇒ 区间变宽。
