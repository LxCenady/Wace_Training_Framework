# WACE Mathematics Methods · Cheat Sheet（题型 + 注意事项）

**通用规则**：show that 每步都写 · 题目要求 using calculus 的优化必须验证极值（f″ 或符号表，1 分）· 计算器用弧度制（sin 求导出现 π/180 就是开成了角度制）· 应用题带单位 · 解释写清「哪个量 + 在何时 + 变化多少 + 单位」，结合语境 · 概率至少 4 位小数（题目指定 3 位、exact、整数时照办）· CA 题写出所解的方程和关键输出，不写计算器语法 · 读题看清 "first / initially"（t = 0）、"more than"（≥ k+1）、"at least"

## 1 微分及其应用

**① 直接求导**（CF 开头 2–4 分）
- 先判断结构：乘积 → product；分式 → quotient；复合 → chain，常常叠加使用（如 x² ln(4x + 3)）。
- 基本式：(eᵏˣ)′ = keᵏˣ；(ln f)′ = f′/f；(sin kx)′ = k cos kx；(tan x)′ = 1/cos²x（2017A-Q10 要求用商法则证明）。
- ⚠ 方法分要求写出两项结构**且至少一项正确**；(2x³+1)⁵ 别漏乘 6x²；e⁻ˣ 求导别漏负号；说 "do not simplify" 就不必化简。

**② 表格 / 图像给值求导**
- 先写一般式（1 分）：(fg)′ = f′g + fg′；(g/h)′ = (g′h − gh′)/h²；[h(g(x))]′ = h′(g(x))·g′(x)。
- ⚠ 复合先算内层：h′(g(1)) = h′(3)，不是 h′(1)（2019 报告：复合求导作答差）。
- 图像：直线段的斜率就是导数；折点（尖角）处不可导。

**③ "rate of change of f′(x)" / 解释导数**
- 就是求 f″(a)（认出这一点单独 1 分）。
- 解释模板：「When x = a, the gradient of f is increasing at a rate of … per unit of x」；f′(a) = 0 且 f″(a) < 0 ⇒ 局部极大。

**④ 函数全分析**（10–15 分大题）
- f′ 因式分解，写出 eˣ > 0（永不为零）→ 解 f′ = 0 → 代回**原函数**求 y 坐标（单独给分）。
- 性质：f″(a) > 0 极小，< 0 极大；⚠ **f″(a) = 0 时必须改用符号表**（2023 报告）。
- 拐点：f″ = 0 **并且** f″ 在两侧变号。⚠ 只有 f′ = f″ = 0 不够（x⁴ 在 0 处是极小点）。
- 作图：截距、驻点、拐点标坐标；渐近线写方程（ln(x + 3) 的定义域 x > −3、竖直渐近线单独 1 分）；端点画开闭圈；凹凸与 f″ 的符号一致。
- 例：2021A-Q12 共 15 分 = 求导 2 + 驻点与性质 7 + 拐点 2 + 作图 4。

**⑤ 由条件反求系数 / 由条件作图**
- 过点 f(a) = b；转折点 f′(a) = 0；拐点 f″(a) = 0；面积 ∫f = A。先写出 f′、f″ 的一般式。
- 例：2018A-Q15 的「增长在 t = 6 暂停，之后继续增长」⇒ 水平拐点 ⇒ P′(6) = 0 且 P″(6) = 0。
- 由条件作图（2022F-Q5）：f″(−1) > 0 ⇒ 极小；只有两个驻点且 f′(2) > 0 ⇒ x = 1 是水平拐点。

**⑥ 优化** ★
- show that：用约束（体积固定、周长 500 m、勾股关系）消去一个变量，代入目标函数，化简到题目给的形式。
- 求导 = 0，舍去不合理的解（r = 0、θ 越界）→ **验证**：在驻点处算出 A″(x₀) < 0，或画符号表 → 回答**全部尺寸**（半径和高都要），按要求取整并带单位。
- 题目写 "You do not need to verify" 时可省验证；只能取整数时比较相邻两个整数的值（2020A-Q13：74 和 75）。

**⑦ 增量公式** δy ≈ f′(a)·δx
- 写出 δx（⚠ 1° = π/180 rad；1 个月 = 1/12 年）→ 在**起点**处求导 → 相乘；问新值时再加上 f(a)。
- 例：ln 2.02 ≈ ln 2 + (1/2)(0.02) = 0.703（2021F-Q3）。

**⑧ 相关变化率 / 切线**
- dy/dt = (dy/dθ)(dθ/dt)：先用几何关系写函数（灯塔 y = 12 tan θ）→ 求导 → 代入该时刻的值（先由 y = 5 求出 cos θ = 12/13）。
- 切线：切点满足 f′(a) = 斜率、f(a) = 切线上的值；切线方程 y − f(a) = f′(a)(x − a)。

**⑨ 描述与解释**（每年 1–3 分）
- 分段描述：「For … the company makes a loss; profit increases to a maximum of $… at x = …; then decreases.」
- 最大增长率在图像斜率最大处，也就是拐点（2025A-Q9(c)）。

## 2 积分及其应用

**① 反导数与由 f′ 求 f**
- ∫eᵏˣ = eᵏˣ/k；∫cos kx = sin kx/k；∫(ax + b)ⁿ = (ax + b)ⁿ⁺¹/[a(n + 1)]（n ≠ −1）；∫f′/f = ln f(x) + c（考试中一般 f > 0）。
- 分子凑成分母的导数：∫(3x + 1)/(3x² + 2x + 1) = ½ ln(…)（凑系数单独 1 分）。
- 由 f′ 求 f：积分并写 + c → 代入已知点 → 写出完整的 f(x)，必要时用对数律化简。

**② "Hence" 积分**（CF 高频）
- 固定三步：两边同时积分 → 左边用 FTC 抵消 → 拆开右边并移项。
- 例：d/dx(x ln x) = ln x + 1 ⇒ ∫ln x dx = x ln x − x + c。后面常接一问求期望、定积分或面积。

**③ 图形上的定积分**
- 把区域拆成矩形、三角形、扇形；x 轴上方为正、下方为负。∫(f − 2) = ∫f − 2 × 区间长；∫ₐᵇ f′ = f(b) − f(a)（直接从图上读两个值）。
- 求 α 使 ∫₀^α f = 0：令上方面积等于下方面积。

**④ FTC 与积分定义的函数** ★（多次被报告点名）
- d/dx ∫ₐˣ f(t)dt = f(x)（答案写成 x 的函数）；上限是 g(x) 时乘 g′(x)，如 D(t) = ∫₀^(πt) … ⇒ D′(t) = π·(…)。
- 下限是变量：∫ₜ³ f = −∫₃ᵗ f ⇒ 导数为 −f(t)。
- 画 A(x) = ∫ₐˣ f：A(a) = 0；f 由正变负 ⇒ A 极大，由负变正 ⇒ A 极小；f 的转折点 ⇒ A 的拐点；端点标出 A 的值。
- 判断 F(x) 的正负：比较 0 到 x 之间的正面积和负面积，理由要引用面积。

**⑤ 面积**
- 先求交点（常单独 1 分）→ ∫(上 − 下)dx → 积分式要写上下限和 **dx**（2025F-Q5 有 1 分专给记号）。
- 要分段的情况：求与 x 轴之间的面积而曲线跨过 x 轴；或两条曲线的上下关系交换。上下界由多个函数组成时也要拆开（2024 报告）。
- 矩形减法：y = eˣ、y = 2 与 y 轴围成的面积 = 2 ln 2 − ∫₀^(ln2) eˣ dx = 2 ln 2 − 1。
- 反函数面积：ln x 在 x < 1 时位于 x 轴下方，要加负号（2020A-Q11(e)）。

**⑥ 含参数的定积分方程**：算出含参表达式 = 给定值，再解（ln b − ln a = ln 3 ⇒ b = 3a）。

**⑦ 黎曼和**
- 下和取各小区间上较小的函数值，上和取较大的；**递增时左端点低估、右端点高估，递减时正好相反**（1/x）。解释单独 1 分。
- 最佳估计 = (L + U)/2；改进方法：加多矩形，或求出函数后积分。

**⑧ 语境应用**：截面积 × 长度（宽度）= 体积；总变化 = ∫变化率；水位未知时，先把截面积写成 h 的函数（上限含 h），再解 h；注意单位统一（cm 与 m）。

## 3 直线运动

**概念对照**
- 位移 x 可正可负；"at rest" ⇔ v = 0；改变方向 ⇔ v **变号**（v 碰到 0 又回到原符号不算，如 v = (t − 2)²）。
- 回到出发点 ⇔ x(t) = x(0)；经过原点 ⇔ x(t) = 0（只有 x(0) = 0 时两者相同）。
- 时间用词："first appears / initially" 是 t = 0（2024 报告：很多人代了 t = 1）；"during the fifth second" 是 4 ≤ t ≤ 5。

**① 加速还是减速** ★
- v 与 a **同号** ⇒ speeding up；**异号** ⇒ slowing down。⚠ 只说 "acceleration is negative" 不给分（2024F-Q2 的 key 原话）。
- ⚠ 2018A-Q11(c) 的 key 把 "heading south and decelerating at 0.5" 当作 a = −0.5，遇到这类措辞要写明自己的理解和正方向。

**② 由 a(t) 或 v(t) 积分反推**
- 每次积分都加常数，用 v(0)、x(0) 定常数；有两个位置条件时联立，解出参数和常数（2017A-Q20：p = 12）。
- 三角函数积分要除以内层系数：∫2 sin(t/3 + π/6) dt = −6 cos(t/3 + π/6) + C。

**③ 路程与位移变化** ★ 必考
- 路程：解 v = 0 找出所有停下的时刻 → 分段 → 在 v < 0 的那段积分前加负号（或每段加绝对值）→ 求和带单位。正负号单独 1 分，**每个积分写 dt** 也有 1 分（2023A-Q8(c)）。
- 也可写成 |x(t₁) − x(0)| + |x(t₂) − x(t₁)| + …（2024F-Q2(d)）。
- 解释 ∫ₐᵇ v dt：「the change in displacement from t = a s to t = b s」（起止时刻要写，单独 1 分）。
- ⚠ 不能直接用 x(终) − x(始) 当路程。

**④ 速度最大 / 加速度为 0**
- 区间内部的极值处必有 a = 0，但反过来不一定（匀速段 a 恒为 0）；用 v″ < 0 或符号表验证（题目要求 using calculus 时有分）。
- 求最大**速率**时还要比较端点的 |v|。

**⑤ 图像与符号表解读**：由 a 的符号说明 v 的增减，前后两段各 1 分；只有 x、v、a 的符号表时：x 变号 ⇒ 经过原点，v 变号 ⇒ 停下转向，v、a 异号 ⇒ 减速。

## 4 指数与对数

**① 对数律与用字母表示**（CF）
- log(mn) = log m + log n；log(m/n) = log m − log n；log mᵏ = k log m；换底 logₐb = log_c b / log_c a。
- 常数写成对数：4 = ln e⁴，2 = log₁₀100，9 = log₁₀10⁹（这是好几道题的关键一步）。
- 例：p = ln 2、r = ln 5 ⇒ ln 6.25 = ln(5²/2²) = 2r − 2p；m = log₃6、n = log₆5 ⇒ log₃10 = (m − 1) + mn；e^(ln2 + ln3) = 6。

**② 解指数 / 对数方程**（CF 精确值）
- 合并同类项：4e²ˣ = 81 − 5e²ˣ ⇒ e²ˣ = 9 ⇒ x = ln 3。
- eˣ 的二次式：设 u = eˣ，因式分解，舍去 u ≤ 0。
- 对数方程：先合并成单个对数再去掉 log；⚠ 检查定义域，2 ln x = … 只能取正根（2025F-Q7 只给一个解的分）。

**③ 对数函数图像与变换**
- y = m logₐ(x − p) + q：竖直渐近线 x = p，过点 (p + 1, q)；由渐近线定 p，再代两个点解 m、q。
- 作图 3 分：渐近线（画出并写方程）、一个特殊点、正确的形状。
- 变换：ln 4x = ln x + ln 4（向上平移）；ln√x = ½ ln x（竖直伸缩）；ln x + 4 = ln(e⁴x)（水平伸缩）；log₂(1/(x − 1)) = −log₂(x − 1)。
- 用图读数要在图上画出读数过程（2024A-Q15 "show clearly how you used the graph"）。

**④ 增长 / 衰减模型 P = P₀eᵏᵗ** ★ CA 高频
- 初值：t = 0；k 由半衰期 ½ = e^(k·T½) 求；到达某值：令模型等于目标值，用 ln 解。
- 换算成时刻并**按题意取整**：例 4e^(−0.05t) = 2.5 ⇒ t ≈ 9.40 h ⇒ 9 am + 9 h 24 min = 6:24 pm（latest 要向下取，6:25 已太晚）。
- 变化率 dP/dt = kP：问 rate of change 就给带符号的值；问 rate of decrease 写成正数并说明 decreasing。
- 分段模型：后一段的初值等于前一段末的值；长期行为：t → ∞ 时 e^(−kt) → 0。

**⑤ 对数刻度**（分贝、里氏、站点排名）
- L = k·log(I/I₀) ⇒ I₂/I₁ = 10^((L₂ − L₁)/k)。⚠ 不同题 k 不同：分贝 k = 10（90 dB 比 60 dB 为 1000 倍）；声压 k = 20；里氏 k = 1；站点排名 k = 2。
- 读数之差不是答案，还要化成 10 的幂；求 I₀：代入一组 (L, I) 后化成指数式。
- log P 对 t 呈直线 ⇒ P = 10^B·(10^A)ᵗ，用斜率比较增长快慢。

**⑥ 对数模型 + 求导**：由已知点定参数（A(0) = 21、A(1) = 53 ⇒ c = 21、b = 64）；ds/dD = 40.6/D 随 D 增大而减小，用来下结论；数量向下取整；1 < x < 2 属于「第 2 周」。

## 5 离散随机变量与二项分布

**① 分布表**
- 等可能情形列样本空间（两颗骰子用表格）；有未知数时用 ΣP = 1 和 E(X) = μ 列两个方程（各 1 分）。
- 由累积分布 P(X ≤ x)：P(X = k) = F(k) − F(k − 1)；条件概率 P(X = 1 | X ≤ 3) = P(X = 1)/P(X ≤ 3)。
- 新变量要分情况：未卖出数 Y = max(0, 3 − X)。

**② 期望、方差、线性变换**
- E(X) = Σxp；Var(X) = Σx²p − μ²；E(aX + b) = aE(X) + b；Var(aX + b) = a²Var(X)；SD(aX + b) = |a|·SD。
- ⚠ Var(25 − 2X) = 4Var(X)，常数不影响方差。
- 缩放到新的均值和标准差：**先由 SD 定 a**（取 a > 0 保持名次顺序），再由均值定 b。费用涨 20% 再加收 $1 ⇒ 新均值 1.2μ + 1，新 SD 1.2σ。

**③ 游戏 / 筹款期望**（10 年中 6 年考过）
- 先定收益变量，想清楚站在谁的角度（玩家还是主办方）→ 列「净收益 + 概率」表 → E = Σ值 × 概率 → 下结论（"on average / in the long run"）。
- 定价：令期望利润等于目标；最低收费 = 期望赔付（2025A-Q8：E = 0.8，每个红球 $5 ⇒ 至少 $4）。

**④ 二项分布** ★
- 写 X ~ Bin(n, p)，通常名称 1 分、参数 1 分；说明 n、p 在语境中指什么。
- E = np，Var = np(1 − p)；由均值、方差反求：np = ½、np(1 − p) = 5/12 ⇒ p = 1/6、n = 3。
- 边界：more than three ⇒ X ≥ 4；系统少于 2 个能工作 ⇔ 坏掉 ≥ 4 个；情境变化时换参数（拆掉一个 ⇒ Bin(4, p)）。
- 假设（2 分）：各次**相互独立**；成功概率 **p 相同且不变**，结合语境写。"两种结果""n 固定"一般是题设，写了不一定得分。
- 不是二项：试验次数不固定；不放回导致各次不独立（改进：放回）。
- 很小的概率要多保留几位（2019A-Q18(c) 约 0.00003，key 要求至少 5 位小数）。

**⑤ 正态 → 二项**：先用正态求单件概率 p（保留足够位数）→ Y ~ Bin(n, p)（写出 "binomial" 和参数）→ 求 P(Y ≥ k)。

**⑥ 路径与计数**：把事件翻译成成功次数。例：回到原点 ⇔ 前进次数 = 后退次数（奇数步不可能，概率 0，要写理由）；前进 ≥ 20 cm（每步 5 cm）⇔ 10 步中前进 ≥ 7 次。

## 6 连续随机变量与正态分布

**① 直方图 → 概率**（CF）
- 相对频率相加；**频数**直方图要先除以总数。
- 端点落在柱子中间时按比例插值（前提是题设「组内均匀分布」）；E ≈ Σ 组中值 × 概率；累积概率表与单个概率要分清。

**② pdf 四件套**
- 总面积 = 1（求 k 或证 k 都要写出这一步）；P(a < X < b) = ∫ₐᵇ f；E = ∫x f；Var = ∫x²f − μ² 或 ∫(x − μ)²f；中位数 ∫^M f = 0.5。
- 已知 cdf F(x)：P(a < X ≤ b) = F(b) − F(a)；pdf = F′(x)。
- CF 卷里直线段组成的 pdf 用三角形、梯形面积算；分段 pdf 要分别积分。
- 例：f = 1/(x ln 5)，1 ≤ x ≤ 5 ⇒ E = 4/ln 5，中位数 √5。
- 期望要换成语境单位或时刻（3.8 h after noon ⇒ 3:48 pm）；方差的单位是平方单位。

**③ 均匀分布**
- f = 1/(b − a)，写出定义域 a ≤ x ≤ b，其余为 0；E = (a + b)/2。
- ⚠ 方差要写积分式作答（key 给「pdf 及定义域」「积分式」各 1 分），(b − a)²/12 不在公式表上，只用来验算。例：E = 6、最大值 9 ⇒ U(3, 9)，Var = ∫₃⁹ (x − 6)²/6 dx = 3。
- 条件概率：P(X < −0.35 | X < 0) = 0.15/0.5；X² < 0.09 ⇔ −0.3 < X < 0.3。

**④ 正态分布**
- 先写概率语句（多数 key 单独 1 分）再计算；反向求分位点：P(X > m) = 0.0005 ⇒ invNorm(0.9995)。
- 条件概率：P(X < 75 | X > 67) = P(67 < X < 75)/P(X > 67)。
- 单位变换 Y = aX + b：μ_Y = aμ + b，σ_Y = |a|σ，Var(Y) = a²Var(X)；也可能反过来由 μ_Y、σ_Y 求 a、b。

**⑤ 由两个尾部概率求 μ、σ** ★
- 求两个 z 值（1 分）→ 列方程组 → 解。例：5% < 55，13% > 100 ⇒ z = −1.6449、1.1264 ⇒ σ ≈ 16.24，μ ≈ 81.71。
- P(X ≤ 150) = 0.0228、P(X ≥ 165) = 0.1587 恰好对应 z = −2、z = 1 ⇒ σ = 5，μ = 160。只知道均值时，一个 z 就够。

**⑥ 68–95–99.7**（CF）：把值写成 μ ± kσ；曲线越矮越宽，σ 越大；宽度为 σ 的区间概率最多约 0.38。

**⑦ 正态模型不合适的理由**：直方图不对称或偏斜；变量有界；模型给出不可能的值（如 P(重量 < 0) > 0）。

## 7 样本比例与置信区间

**① p̂ 的分布**
- 写「approximately normal（n 足够大）+ 均值 p + 方差 p(1 − p)/n」，共 3 分，然后求概率。
- 分布图不对称（如 n = 36、p = 0.05）⇒ 不能用正态近似。
- n 增大 ⇒ p̂ 的标准差减小、分布更集中 ⇒ P(p̂ ≤ 0.03) 这类概率变大（两点各 1 分）。

**② 计算置信区间**
- p̂ ± z√(p̂(1 − p̂)/n)，z = 1.645（90%）/ 1.960（95%）/ 2.576（99%）；按要求保留小数位。
- 由区间反推：p̂ = 中点，E = 半宽；已知区间和 n 反求置信水平：z = E/SE，再查百分比。

**③ 样本量** ⚠ 最易错
- 求最小样本量（minimum / guarantee / ensure margin at most）**一律用 p̂ = 0.5**，即使前面已经算出 p̂（2023A-Q7(c)：用 0.5 得 2401，代 0.38 得 2263，丢分）。只有题目明说用某个样本比例时才代入它。
- 「至少」⇒ 向上取整（259.2 ⇒ 260）；由区间反推当初的 n ⇒ 取最近整数（350.1 ⇒ 350）。
- 比例关系：误差减半 ⇒ n × 4；宽度变为 1/3 ⇒ n × 9。

**④ 用区间检验说法** ★ 每年都有
- 两句话：「The claimed value … is (not) within the CI …」+「so there is sufficient / insufficient evidence to conclude …」。⚠ 必须表态，不能说「无法 100% 确定」来回避（2023 报告）。
- 两个区间重叠 ⇒ 没有充分证据说明两者不同。
- 问 "does it **prove** … / was a mistake made" ⇒ 答 **No**：不是所有区间都包含 p，不知道这个区间是否恰好没包含（2025 报告）。

**⑤ 区间宽度的影响因素**（因素 1 分 + 影响 1 分）：n 增大变窄；置信水平提高变宽；p̂ 越接近 0.5 越宽。

**⑥ 抽样偏差**
- 写法：指出来源 + 说明**哪类人更多或更少被抽中** + 结合语境；时间和地点是两个来源，要分开写（2022 报告）。
- 常见来源：地点（只在商场、图书馆门外）、时间（工作日午餐时间）、自愿回答、引导性问题、抽样框（只打手机）、方便抽样（最先印出的 200 本）。
- 改进：在整个总体范围内随机抽样（整周、全部印刷机）。

**⑦ 其他常见问法**
- k 个 90% 区间中含 p 的个数 ~ Bin(k, 0.9)；「有 3 个区间不含 p」⇔ X = k − 3。
- 二项分布的假设：写出假设 → 判断在语境中是否合理 → 给理由。
