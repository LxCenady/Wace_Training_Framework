# WACE Chemistry ATAR · Cheat Sheet（题型 + 注意事项）

**通用规则**：资料册已给的内容（周期表、E° 表、常数、溶解度规则、有色离子与卤素颜色、氨基酸结构、pH 与 ppm 公式）不必重写，但要熟悉位置 · 解释题用 collision theory，勒夏特列原理只用于预测 · 方程式写状态符号，只标参与反应的物种，并注明条件（催化剂、酸性、加热）· 每个中间值与最终值都带单位，取整放最后一步 · 不用缩写（NVR、NR 等），首次出现的缩写写全 · 不拟人（enzyme sensitive、molecules swarm、hydrophobic "hates" water）· 不用箭头表示增减，用文字描述

## 1 平衡与速率（EQ）

**① 动态平衡（EQ3）**
- 封闭体系中正逆反应速率相等，宏观性质不变；浓度不一定相等（开放体系物质会逸散，不能建立）。

**② 勒夏特列原理（EQ4）**
- 加反应物 / 移走产物 ⇒ 向右；加产物 / 移走反应物 ⇒ 向左；固体与纯液体的量不影响平衡。
- 增大压强（缩小体积）⇒ 向气体分子数少的一侧；气体分子数相等时无移动。
- 加惰性气体：恒容时各分压不变，无移动；恒压时体积增大，向气体分子数多的一侧。⚠ 必须写明恒容或恒压。
- 催化剂：无移动，正逆速率同等增大，K 不变。
- 升温 ⇒ 向吸热方向；降温相反。只有温度改变 K。

**③ 用碰撞理论解释（EQ5）**
- 加反应物后正向速率突然增大，逆向速率随产物增加而增大，直到两者再次相等。
- 有效碰撞：能量 ≥ Ea 且取向正确。
- ⚠ 勒夏特列原理只能预测，不能作为解释；解释题要写"有效碰撞"。

**④ 平衡常数 K（EQ7–8）**
- K = [生成物]^n / [反应物]^m，纯固体、纯液体不写入。反应式反写 ⇒ K 取倒数；系数乘以 n ⇒ K 取 n 次方。
- K 大 ⇒ 产物较多；K 只随温度改变。

**⑤ 能量剖面与速率图（EQ2、EQ6）**
- ΔH = Ea(正) − Ea(逆)；催化剂同时降低两个 Ea，ΔH 不变。
- 浓度-时间图：扰动时刻浓度不突变；速率-时间图：扰动时速率突跃。

**⑥ 平衡体系的颜色（EQ9）**
- CrO₄²⁻（黄）⇌ Cr₂O₇²⁻（橙）：加酸 ⇒ 橙色加深；加碱 ⇒ 变黄。
- Fe³⁺（淡棕）+ SCN⁻ ⇌ [Fe(SCN)]²⁺（血红色）。
- [Co(H₂O)₆]²⁺（粉红）⇌ [CoCl₄]²⁻（蓝）：浓盐酸或加热 ⇒ 变蓝（正向吸热）；加水 ⇒ 变粉红。

**⑦ 真实情境（EQ10）**
- 海洋酸化：CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻；H⁺ 与 CO₃²⁻ 反应，使 CaCO₃ 的生成平衡向左移，贝壳难以形成。
- 血液 pH：过度换气（CO₂ 减少）⇒ 平衡向左，pH 升高。
- ⚠ 海洋 pH 仍大于 7，并非酸性；贝壳是更难形成，不是被溶解。

## 2 酸与碱（AB）

**① 理论模型（AB1–2）**
- Arrhenius：酸在水中产生 H⁺，碱产生 OH⁻；无法解释 NH₃ 作碱。
- Brønsted–Lowry：酸为质子给体，碱为质子受体；共轭酸碱对只差一个 H⁺（HCl/Cl⁻，NH₄⁺/NH₃）。
- 两性物质：H₂O、HCO₃⁻、HSO₄⁻ 等既能给出也能接受 H⁺。
- ⚠ 强弱指电离程度，浓稀指浓度；电离（共价分子生成离子）≠ 解离（离子晶体中离子分开）。

**② 电离与 Ka（AB2）**
- Ka = [H⁺][A⁻]/[HA]；Ka 越大酸越强。强酸几乎完全电离，弱酸部分电离。
- 多元酸分步电离：H₂SO₄ 第一步完全，第二步不完全（HSO₄⁻ ⇌ H⁺ + SO₄²⁻）。
- 弱酸溶液中的主要物种：HA、H₂O、H⁺、A⁻、OH⁻；强酸溶液中几乎不含 HA。

**③ 盐的水解（AB3）**
- 强酸 + 强碱盐（NaCl）⇒ 中性；强酸 + 弱碱盐（NH₄Cl）⇒ 酸性；弱酸 + 强碱盐（CH₃COONa、Na₂CO₃）⇒ 碱性。
- 两性物质（既能给出也能接受 H⁺）：NaHCO₃ 溶液略呈碱性；NaHSO₃ 溶液呈酸性。
- ⚠ 解释时要用 [H₃O⁺] 与 [OH⁻] 的相对大小说明，不能只说"弱酸根水解"。

**④ 缓冲溶液（AB4）**
- 组成：弱酸 + 其共轭碱（CH₃COOH / CH₃COO⁻），或弱碱 + 其共轭酸（NH₃ / NH₄⁺）。强酸与强碱、或强酸与其盐都不是缓冲液。
- 加 H⁺：H⁺ + A⁻ → HA；加 OH⁻：OH⁻ + HA → A⁻ + H₂O；平衡移动抵消变化，pH 变化很小。
- 缓冲能力最强：[HA] ≈ [A⁻]，此时 pH ≈ pKa。
- ⚠ 稀释后 pH 基本不变，但缓冲容量下降。

**⑤ pH 计算（AB5）**
- pH = −log[H⁺]；25 °C 时 pOH = 14 − pH（Kw = 1.00 × 10⁻¹⁴）。
- 强碱：[OH⁻] = 碱浓度 ⇒ [H⁺] = Kw / [OH⁻]。
- 有效数字：pH 的小数位数 = [H⁺] 的有效数字位数。

**⑥ 滴定与指示剂（AB6–8）**
- 等当点（equivalence point）= 恰好反应；终点（end point）= 指示剂变色点，两者可能略有差别。
- 指示剂（资料册未给，需记）：甲基橙 红（pH < 3.1）→ 黄（pH > 4.4）；溴百里酚蓝 黄（< 6.0）→ 蓝（> 7.6）；酚酞 无色（< 8.2）→ 粉红（> 10.0）。
- 选择：指示剂变色范围落在 pH 突跃内。强酸 + 弱碱（等当点 pH < 7）用甲基橙；弱酸 + 强碱（等当点 pH > 7）用酚酞；强酸 + 强碱 两者皆可。
- ⚠ 解释指示剂选择时，要写等当点溶液中存在的离子（如 CH₃COO⁻ 水解呈碱性），不能只说"强弱酸碱"。
- 滴定管用待装溶液润洗；移液管用待移取溶液润洗；锥形瓶只用蒸馏水润洗（用待测液润洗会多加溶质，结果偏高）。
- 一级标准物质：纯度高、在空气中稳定、摩尔质量大、易溶、与被测物按计量比完全反应。例：KHC₈H₄O₄（KHP）、无水 Na₂CO₃。NaOH 与 HCl 都不是一级标准。

**⑦ 非氧化还原反应与现象（AB9）**
- 沉淀：Ag⁺ + Cl⁻ 白色（AgCl）；Ag⁺ + Br⁻ 淡黄（AgBr）；Ag⁺ + I⁻ 淡黄（AgI）；Ba²⁺ + SO₄²⁻ 白色（BaSO₄）。
- 氢氧化物：Cu(OH)₂ 蓝色；Fe(OH)₂ 绿色；Fe(OH)₃ 红褐色；Mg(OH)₂、Al(OH)₃ 白色；Al(OH)₃、Zn(OH)₂ 溶于过量 NaOH。
- 热分解：蓝色 Cu(OH)₂、绿色 CuCO₃ 受热均变黑（生成 CuO）。

## 3 氧化还原与电化学（RX）

**① 氧化数（RX1）**
- 单质 0；单原子离子 = 电荷；化合物各元素代数和 = 0。
- O 通常 −2（过氧化物 −1）；H 通常 +1（金属氢化物 −1）；F 恒为 −1；ⅠA 族 +1，ⅡA 族 +2。
- 氧化：氧化数升高（失电子）；还原：氧化数降低（得电子）；氧化剂被还原，还原剂被氧化。

**② 半反应配平（RX2）**
- 酸性条件：先配平非 H、O 原子 → 用 H₂O 配平 O → 用 H⁺ 配平 H → 用 e⁻ 配平电荷 → 乘系数使电子数相等后相加。
- 碱性条件：在两边加 OH⁻ 以中和 H⁺，H⁺ + OH⁻ → H₂O。
- 半反应乘系数时 E° 不乘。

**③ 标准电极电势（RX4）**
- E° 是强度量，资料册仅注明 25 °C（1.00 mol L⁻¹、100 kPa 为教材标准条件）；E° 越大，越易被还原（氧化能力越强）。
- E°cell = E°(还原极) − E°(氧化极)，两个半反应都写成还原形式；E°cell > 0 ⇒ 反应自发。
- 实测电压与 E° 计算值不同的原因：非标准浓度、温度、内阻、过电势。

**④ 原电池与电解池（RX5–6）**
- 口诀：An Ox（阳极氧化）、Red Cat（阴极还原），两种电池都适用。
- 原电池（自发）：阳极为负极，阴极为正极；电子从阳极经外电路到阴极；盐桥中阴离子向阳极、阳离子向阴极迁移。电子不经过电解液。
- 电解池（外加电源，非自发）：阳极接电源正极、阴极接负极；阳极仍是氧化、阴极仍是还原。
- 电池符号：阳极 | 阳极离子 || 阴极离子 | 阴极（单竖线为相界，双竖线为盐桥）。
- 电镀：镀件作阴极，镀层金属作阳极，电解液含镀层金属离子。粗铜精炼：粗铜作阳极，纯铜作阴极，Ag、Au 等沉积成阳极泥。

**⑤ 实用电池（RX7）**
- 碱性锌锰电池：一次（不可充电）；铅酸蓄电池：二次，放电时 H₂SO₄ 被消耗、溶液密度下降。
- 酸性氢氧燃料电池：负极 2H₂ → 4H⁺ + 4e⁻，正极 O₂ + 4H⁺ + 4e⁻ → 2H₂O；产物只有水，但氢气储存、安全与成本是缺点。

**⑥ 腐蚀与防护（RX8）**
- 铁为阳极：Fe → Fe²⁺ + 2e⁻；阴极 O₂ + 2H₂O + 4e⁻ → 4OH⁻；Fe²⁺ 再氧化成 Fe³⁺，形成铁锈 Fe₂O₃·xH₂O。需要水与氧气，盐加速腐蚀。
- 防护：隔绝（涂漆、油脂）；牺牲阳极（比铁活泼的 Zn、Mg，用于码头桩、船体）；外加电流阴极保护（铁接电源负极）。
- ⚠ 镀锌在镀层刮破后仍保护铁（锌是牺牲阳极）；镀锡刮破后反而加速铁腐蚀。防护要结合情境选择。

**⑦ 氧化还原现象（RX3）**
- 置换：Zn + CuSO₄ 溶液，蓝色褪去，有红色（鲑鱼红）固体析出。
- 卤素置换：Cl₂(aq) 加入 KBr(aq)，无色溶液变橙色。
- 完全燃烧：蓝色火焰，只生成 CO₂ 和 H₂O；不完全燃烧：黄色火焰，冒烟，生成 CO 或碳。

## 4 有机化学（ORG）

**① 官能团与命名（ORG1–2）**
- 后缀：烯 -ene；醇 -ol；醛 -al（链端）；酮 -one；羧酸 -oic acid；酯 烷基 + alkanoate；胺 -amine；酰胺 -amide（链端）。
- 步骤：最长含官能团碳链 → 官能团位次最小 → 取代基按字母序。
- ⚠ pentanamide（不是 pentamide）；2,3-dimethylbut-2-ene（位次要写全）；酯先写醇部分（ethyl ethanoate）。
- 结构式：全结构式要画出所有键；键必须接对原子（HC–R，不是 CH–R）；缩写式要写清官能团（–COOH）。

**② 同分异构体（ORG3）**
- 类型：碳链异构、位置异构、官能团异构（如 C₂H₆O 的乙醇与甲醚）、顺反异构。
- 顺反异构条件：双键两端的每个碳各连接两个不同的基团。⚠ 不是所有带烷基的化合物都有顺反异构。

**③ 分子间作用力与性质（ORG4）**
- 强度：氢键 > 偶极–偶极 > 色散力；分子越大，色散力累积越大，往往成为主导。
- 沸点：分子量大 ⇒ 色散力强 ⇒ 沸点高；支链多 ⇒ 沸点低；–OH、–NH₂、–COOH 可形成氢键 ⇒ 沸点高。
- 溶解：溶质与水需形成氢键或偶极作用；长烃链降低水溶性；NaCl 溶于水是离子–偶极作用。
- ⚠ 不能只写 "like dissolves like"，要指明溶质和溶剂分别形成的具体作用力，并比较强弱。

**④ 加成、氧化与酯化（ORG5–7）**
- 烯烃加成：Br₂、H₂、HX、H₂O（工业用 H₃PO₄ 催化）；溴水由橙色变无色。
- 醇被酸化重铬酸钾（橙 → 绿，生成 Cr³⁺）或酸性高锰酸钾（紫色 → 无色或淡粉色，Mn²⁺）氧化：
  - 伯醇 → 醛（边生成边蒸出）→ 羧酸（回流，过量氧化剂）；仲醇 → 酮；叔醇不反应。
  - 醛 → 羧酸，同样使重铬酸钾变绿。
- 羧酸 + 醇 ⇌ 酯 + 水（浓 H₂SO₄ 催化，加热，可逆）；碱性水解（皂化）不可逆，生成羧酸盐。
- 羧酸 + 碳酸盐：冒出气泡（CO₂）。胺因氮上孤对电子而呈碱性，与酸生成盐。

**⑤ 燃烧与鉴别（ORG6、8、9）**
- 鉴别：写出试剂 + 每种物质的现象 + 结论（溴水：烯烃褪色；酸性重铬酸钾：伯/仲醇变绿、叔醇不变；Na₂CO₃：羧酸起泡）。

## 5 聚合物、氨基酸与蛋白质（PRO）

**① 加聚物（PRO1）**
- 重复单元：双键打开，单体的两个 C 相连；括号内画出重复单元，括号外标 n，两端保留延伸键。
- ⚠ 不要在末端写 H 或基团（不要终止聚合物）。由聚合物推单体：去掉括号，恢复双键。

**② 缩聚物（PRO2）**
- 单体需两个官能团：二元醇 + 二元羧酸 ⇒ 聚酯（酯键 –COO–，如 PET）；二元胺 + 二元羧酸 ⇒ 聚酰胺（酰胺键 –CO–NH–，如尼龙 6,6）。
- 每形成一个键脱去一个小分子（H₂O，或 HCl 当用酰氯时）。
- 由聚合物推单体：酯键处断开（C–O），羰基端加 OH、氧端加 H；酰胺键处断开（C–N）同理。

**③ 塑料的结构与性质（PRO3）**
- 热塑性：线型或少量支链，分子间作用力较弱，加热软化，可回收。
- 热固性：链间交联（共价键），形成网状结构，加热不熔化，硬而耐热。
- 支链多 ⇒ 密度低、柔软（LDPE）；线型、排列紧密 ⇒ 密度高、较硬（HDPE）。
- 可降解：聚酯的酯键可被水解。⚠ 解释要说明链长、支链、交联、分子间作用力中的哪一项。

**④ 氨基酸（PRO4）**
- 通式 H₂N–CH(R)–COOH；除甘氨酸外都是手性碳。
- 中性 pH 时为两性离子 H₃N⁺–CH(R)–COO⁻；酸性时为阳离子，碱性时为阴离子。
- 侧链极性：查资料册结构后分为非极性、极性不带电、酸性（Asp、Glu）、碱性（Lys、Arg、His）。

**⑤ 肽键与多肽（PRO5）**
- 肽键 –CO–NH–：一个氨基酸的 –COOH 与另一个的 –NH₂ 缩合脱去 H₂O。
- 二肽画法：N 端（自由 NH₂）写在左，C 端（自由 COOH）写在右；序列按 N 端到 C 端书写（Gly–Ala ≠ Ala–Gly）。

**⑥ 蛋白质结构（PRO6）**
- 一级：氨基酸序列，由肽键（共价）连接。
- 二级：α-螺旋、β-折叠，靠主链 C=O 与 N–H 之间的氢键维持。
- 三级：侧链间作用：氢键；离子键（–NH₃⁺ 与 –COO⁻）；二硫键（两个半胱氨酸的 –S–S–）；色散力（非极性侧链聚集）。
- 变性：加热、强酸碱、重金属离子、有机溶剂等破坏氢键、离子键、二硫键（二级、三级结构）；肽键不断。
- 突变改变一级序列，可能改变折叠与功能。
- ⚠ 不能说"加热断开肽键"；疏水基团不应说"讨厌水"，要说非极性侧链之间的色散力。

**⑦ 酶（PRO7）**
- 蛋白质类生物催化剂：活性位点与底物形状互补，专一性强；有最适温度与 pH。
- 工业：条件温和、选择性高；局限：高温或极端 pH 时变性，成本高，难回收。
- ⚠ pH 改变活性位点的形状和电荷，使酶变性，而非"酶对 pH 敏感"。

## 6 合成与工业（SYN）

**① 合成路线（SYN1）**
- 常见转换：烯 → 醇（水合）；醇 → 醛 → 羧酸（氧化）；羧酸 + 醇 → 酯（酯化）。
- 每步写清试剂、条件、中间体与反应类型。

**② 哈柏法（SYN2）**
- N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，放热；约 450 °C，约 20 000 kPa，铁催化剂；未反应气体循环，NH₃ 冷却液化分离。
- 折中：低温 ⇒ 产率高但速率慢；高温 ⇒ 速率快但产率低；高压 ⇒ 速率和产率都提高，但设备与能耗成本增加；催化剂只提高速率。

**③ 接触法（SYN2）**
- 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，放热；V₂O₅ 催化剂，约 450 °C，100–200 kPa。
- SO₃ 用浓硫酸吸收（直接用水会产生酸雾）。

**④ 乙醇生产（SYN1、3）**
- 乙烯水合：C₂H₄(g) + H₂O(g) ⇌ C₂H₅OH(g)，H₃PO₄ 催化，约 300 °C，约 6 000–7 000 kPa；原料为石油（不可再生），反应快、可连续生产、纯度高，但能耗高。
- 发酵：C₆H₁₂O₆(aq) → 2C₂H₅OH(aq) + 2CO₂(g)，酵母酶催化，约 25–37 °C，常压，厌氧，多为间歇式；原料可再生、能耗低，但速率慢、产物仅约 12–15%，需蒸馏提纯。
- 比较路线看：原料可再生性、能耗、副产物、原子经济性。

**⑤ 肥皂与洗涤剂（SYN4）**
- 皂化：甘油三酯 + 3NaOH → 甘油 + 3 脂肪酸钠（肥皂）。
- 肥皂分子：亲水头（–COO⁻ Na⁺）+ 疏水尾（烃链）；胶束中尾部朝内包住油污，头部朝外溶于水。
- 硬水：Ca²⁺、Mg²⁺ 与肥皂阴离子生成不溶盐（浮渣）；阴离子洗涤剂的钙、镁盐可溶，去污效果不受影响。

**⑥ 生物柴油（SYN5）**
- 酯交换：甘油三酯 + 3CH₃OH ⇌ 甘油 + 3 脂肪酸甲酯；NaOH/KOH 快、便宜、产率高，但腐蚀性强且生成皂；脂肪酶条件温和、不生成皂、可重复使用（2020 年 key）。

## 7 化学计量与定量分析（QNT）

**① 换算与稀释（QNT1）**
- n = m/M；n = cV；稀释 c₁V₁ = c₂V₂（资料册未给，需记）。
- 浓度换算：g L⁻¹ ÷ 摩尔质量 ⇒ mol L⁻¹；ppm（mg/kg）≈ mg L⁻¹（稀水溶液）。
- ⚠ 写 volume、concentration、mass，不要用 amount 代替。

**② 气体（QNT6）**
- 标准状况（0.0 °C，100 kPa）摩尔体积 22.71 L mol⁻¹（资料册数值，不是 22.4 L）。
- PV = nRT：温度用 K（+273.15），压强用 kPa，体积用 L；R = 8.314 与 kPa·L 配套使用。

**③ 限量试剂与产率（QNT2–3）**
- 限量试剂 = n / 计量数 最小者；理论产量由限量试剂计算。
- 产率 = 实际产量 / 理论产量 × 100%；纯度 = 纯物质质量 / 样品质量 × 100%。

**④ 经验式与分子式（QNT5）**
- 各元素 n = m/M，除以最小值得整数比；不接近整数时乘以 2、3 等取整。
- 燃烧：n(C) = n(CO₂)，n(H) = 2n(H₂O)，O 由差减。
- 分子式 = (摩尔质量 / 经验式质量) × 经验式。

**⑤ 滴定计算（QNT4）**
- 用计量比换算：n(待测) = n(滴定剂) × 系数比；H₂SO₄ 每摩尔给出 2 mol H⁺。
- 取样比：250 mL 溶液每次移取 25.00 mL，结果乘以 10。
- 取 concordant 值（差 ≤ 0.10 mL）求平均，剔除粗测；返滴定先加过量试剂再滴定剩余量。

**⑥ 沉淀称重（QNT8）**
- 步骤：沉淀完全 → 过滤 → 用蒸馏水洗去可溶杂质 → 干燥至恒重 → 称量并换算。
- ⚠ 干燥不完全会使质量偏大；洗涤不足会使结果偏高。

**⑦ 有效数字（QNT7）**
- 乘除取最少有效数字；加减取最少小数位；pH 小数位同 [H⁺] 的有效数字。
- 中间不取整，最后取位并带单位；精确数不计入有效数字。

## 8 科学探究（INQ）

**① 设计（INQ1–3）**
- 假设：可检验，格式为 "If … then … because …"。
- 写明自变量、因变量、控制变量及控制方法；设对照组；重复测量并取平均值。
- 安全：写出危害、风险与防护措施。

**② 作图与读数（INQ4–5）**
- 坐标轴写明物理量与单位，刻度均匀；标题写 "因变量 against 自变量"。
- 用直尺画最佳拟合线，线要平滑，不要逐点连线。
- 读图要在图上画出读数线；读数要写出准确的小数位（如 4.8，而不是 5）。

**③ 误差（INQ6）**
- 随机误差：读数波动、估读误差；重复测量、取平均可减小。
- 系统误差：固定方向的偏差（如滴定管未润洗、仪器未校准、标准物质纯度不足）；重复不能消除，需校准或改进方法。
- 说明误差使结果偏高还是偏低，并解释原因。
- 读数不确定度：最小刻度的一半（50 mL 滴定管 ±0.05 mL）。

**④ 结论与观察（INQ7）**
- 结论只能由数据支持，并指出限制（样本少、误差大）；无充分证据时不写 "proves"。
- ⚠ 观察描述规范：溶液写 "无色" 或具体颜色，不写 "clear"；固体写颜色与形态，不写化学品名称；金属写 "银灰色固体"，铜为 "鲑鱼红色固体"。
- 气体写 "冒泡"，不写 "无色无味气体"（那是推断）。
- 写出反应前、中、后的全部现象（含 excess / limited）。

**⑤ 气体检验（资料册未给）**
- H₂ 爆鸣；O₂ 复燃木条；CO₂ 使石灰水浑浊；Cl₂ 湿润蓝石蕊先红后褪；NH₃ 湿润红石蕊变蓝。
