## 先记住：阅卷组反复扣分的地方

- **计算要写过程，且要有单位**：2016E-Q42(f) 的 key 注明 “No marks awarded unless accompanied by supporting working”，只写 pH 结果得 0 分。
- **“weak” 与 “dilute” 不同**：强弱指电离程度，浓稀指浓度（2023S-Q34(c) 要求用 Ka 与部分电离解释 “弱酸”）。
- **水解与缓冲的解释要写出方程式**：key 多次要求至少一个或两个方程式（2022S-Q28、2023S-Q28(a)、2024S-Q32(a)）。
- **考试报告对本主题的评价**：2022 报告把 “explaining the difference between solutions formed by two salts”（2022S-Q28，即 AB3）列为最难题之一；2023 报告把 2023S-Q26（酸碱理论的概念与方程式）列为作答最好的题之一，把 2023S-Q28（缓冲体系的定义与解释）和 2023S-Q32（分子间力与溶解）列为最难题；2022 报告称滴定计算与操作技术（2022E-Q38）对许多考生有挑战。
- **不要把 Arrhenius 与 Brønsted–Lowry 混为一谈**：前者以在水中产生 H⁺（或 H₃O⁺）定义酸，后者以质子转移定义（2023S-Q26(d)）。

## 数据册提供什么（学生在考试中可用的资料）

- Kw = 1.00 × 10⁻¹⁴（25 °C）；pH = −log₁₀[H⁺]（数据册给出）。
- 溶解性规则（AB9 中判断沉淀与否、AB9 的沉淀称重题用到）。
- 颜色表（AB9 与 AB6 中的现象描述）：Cu²⁺ 蓝、CuO 黑、CuCO₃ 绿（数据册固体表）；数据册未列 Cu(OH)₂ 的颜色，相关现象以题干或 key 为准。
- **没有** Ka 表，也**没有**指示剂表；Ka 与指示剂的变色范围由题干给出（如 2023S-Q34(c) 给出 Ka = 1.73 × 10⁻⁵；2016S-Q34(b) 与 2021S-Q28(a) 的指示剂表都在题干中）。
- Kw 随温度变化的数值由题干给出（如 2017S-Q31(d) 给出 50 °C 的 Kw = 5.48 × 10⁻¹⁴）。

## 题型 1：布朗斯特-劳里酸碱与共轭酸碱对

**识别**：「Brønsted–Lowry」「conjugate acid–base pair」「amphoteric」「circle the Brønsted–Lowry bases」「label the weak acid and its conjugate base」。

**步骤**
1. 找出质子（H⁺）的转移：给出 H⁺ 的物质是酸（质子给体），接受 H⁺ 的是碱（质子受体）。
2. 配对：酸失去 H⁺ 后成为共轭碱；碱得到 H⁺ 后成为共轭酸。
3. 两性物质（如 H₂O、HCO₃⁻、HAsO₄²⁻）既可作酸也可作碱：分别写两条方程式，各说明它作为酸或碱（2018S-Q31(bi)）。
4. 写方程式时用 ⇌，并标出每一物种的酸碱角色。
5. 解释溶液 pH（如 NH₃ 溶液碱性）时，写出 NH₃ 接受 H⁺ 的方程式，并比较 [OH⁻] 与 [H⁺]（2016S-Q31(b)）。

**得分点（key 的典型写法）**：
✓ 2016S-Q31(b)（3 分）：说明水作为酸给出质子、氨作为碱接受质子（或标出共轭酸碱）；写出 NH₃ + H₂O ⇌ NH₄⁺ + OH⁻；指出 [OH⁻] > [H⁺] 故溶液呈碱性。
✓ 2019E-Q36(a)（2 分）：正确标出两对共轭酸碱中的酸与碱（H₃O⁺ 为酸、H₂O 为共轭碱；HCO₃⁻ 为碱、H₂CO₃ 为共轭酸）。
✓ 2024S-Q29(a)（与 PRO4 合计 4 分）：两性离子的结构描述（羧酸给出 H⁺，被氨基接受，形成带正负电的偶极离子）。
✓ 2024S-Q32(b)（1 分）：NH₄⁺ 标为弱酸、NH₃ 标为共轭碱。

**易错点（考试报告）**：2023 报告把 2023S-Q26 列为作答较好的题之一，但其中的细节仍会扣分。以下易错点据 key 归纳：
- 把共轭碱的电荷写错（去掉 H⁺ 后电荷应减 1）。
- 酸与碱的角色标反（H₃O⁺ 是酸，不是碱）。
- 两性物质只写一个方程（2018S-Q31(bi) 要求两个方程式）。
- 圈选碱时漏掉其中一个 B-L 碱（2023S-Q26(c) 的 key 列出三个：H₂O、NO₂⁻、HCOO⁻，全部圈出才得满分）。

**真题**：2016M-Q10、2016M-Q11、2016S-Q31(b)、2017S-Q31(a)、2017E-Q40(f)、2018M-Q8、2018S-Q31(b)(i)、2019M-Q24、2019E-Q36(a)、2020M-Q2、2020M-Q15、2021M-Q21、2022M-Q14、2023S-Q26(b)、2023S-Q26(c)、2024M-Q3、2024S-Q29(a)、2024S-Q32(b)、2025M-Q20、2025M-Q25

## 题型 2：强弱酸碱、电离与 Ka；溶液中的物种

**识别**：「write the ionisation equation」「polyprotic / monoprotic」「Ka」「list the species present in solution」「percentage ionised」「Arrhenius vs Brønsted–Lowry」。

**步骤**
1. 区分强弱与浓稀：强弱指电离程度，浓稀指浓度。弱酸的题目要说明 “partial / incomplete ionisation”（2023S-Q34(c)）。
2. 多元酸（polyprotic）写分步电离，每步只失去一个 H⁺，且用 ⇌；第一步的产物是第二步的反应物（如 H₂PO₄⁻ 既是 H₃PO₄ 第一步电离的产物，又是第二步的反应物；2018S-Q27(a)：H₂PO₄⁻ + H₂O ⇌ HPO₄²⁻ + H₃O⁺）。
3. 逐级电离结构题（如柠檬酸，2016S-Q33(b)）：每一级画出去掉的 H⁺，负电荷必须出现在被去质子化的氧原子上。
4. 列出溶液中的主要物种：溶剂 H₂O；弱酸分子及其离子；由 H₂O 自偶电离生成的 H₃O⁺ 与 OH⁻；溶解的气体及其衍生物（如 CO₂ 溶解生成 H₂CO₃、HCO₃⁻、CO₃²⁻，见 2018S-Q27(b)）。
5. 比较酸性强弱：Ka 越大，酸越强。Ka < 1 表示反应物占优（2023S-Q34(c)）。
6. 由 pH 求 [H₃O⁺]，再求电离百分比：[H₃O⁺] = 10⁻ᵖᴴ；百分比 = 电离出的酸的物质的量 ÷ 原始酸的物质的量 × 100%（2023S-Q34(b)：2.36%）。
7. Arrhenius 与 Brønsted–Lowry：Arrhenius 酸在水中产生 H⁺；Brønsted–Lowry 酸是质子给体（2023S-Q26(d)，需写出 Arrhenius 方程式）。

**得分点（key 的典型写法）**：
✓ 2023S-Q26(a)（4 分）：monoprotic 为一个可电离的 H⁺，polyprotic 为两个或以上（2 分）；给出两条合适的方程式（2 分）。
✓ 2023S-Q34(b)（4 分）：[H₃O⁺] = 10⁻²·²³ = 5.89 × 10⁻³ mol L⁻¹；n(H₃O⁺) = n(电离的酸)；百分比 = 5.89 × 10⁻³ ÷ 0.250 × 100 = 2.36%。
✓ 2023S-Q34(c)（3 分）：弱酸发生部分（不完全）电离；(b) 的电离百分比很小；Ka < 1 说明反应物占优。
✓ 2016S-Q33(b)（3 分）：每一级电离 1 分，负电荷须在正确的氧原子上。
✓ 2018S-Q27(a)（2 分）：第二级电离方程式（允许一处次要错误，key 注明 “one minor error”）。
✓ 2018S-Q27(b)（3 分）：key 只计前三项（如 MgCO₃(s)、Mg₃(PO₄)₂(s)、H₂CO₃(aq) 等）。
✓ 2020S-Q31(a)（3 分）：依次写出 CO₂(g) + H₂O(ℓ) ⇌ H₂CO₃(aq)、H₂CO₃(aq) + H₂O(ℓ) ⇌ HCO₃⁻(aq) + H₃O⁺(aq)、HCO₃⁻(aq) + H₂O(ℓ) ⇌ CO₃²⁻(aq) + H₃O⁺(aq)（每个方框内的物种各 1 分；状态符号不强制）。
✓ 2016E-Q42(g)（6 分）：由 pH 求 [H⁺]，扣除 CO₂ 提供的部分，求 SO₂ 提供的 [H⁺]；H₂SO₃ 按完全电离计，每摩尔给 2 mol H⁺；再用 pV = nRT（T = 289.15 K，P = 97.2 kPa）求 SO₂ 的体积。

**易错点（考试报告）**：2023 报告把 2023S-Q26 列为作答较好的题（(a)、(d) 都属于本题型）。以下易错点据 key 归纳：
- 多元酸一步写成 H₃PO₄ ⇌ PO₄³⁻ + 3H⁺。
- 强酸写成可逆（如 HCl ⇌ H⁺ + Cl⁻ 用双箭头）。
- 把“浓的”当作“强的”（2023S-Q34(c) 要求明确区分）。
- 用 Ka 表示电离百分比，或用 pH 直接代替 Ka。
- 用 Arrhenius 定义时只写 “H⁺” 但不说明在水溶液中产生（key 接受 “produce H⁺ in aqueous solution”）。

**真题**：2016S-Q31(b)、2016S-Q33(b)、2016E-Q42(g)、2017M-Q1、2018M-Q3、2018M-Q18、2018S-Q27(a)、2018S-Q27(b)、2019M-Q8、2019S-Q31(c)、2019S-Q35(a)(i)、2019S-Q35(a)(ii)、2020M-Q18、2020S-Q31(a)、2021M-Q3、2021M-Q8、2022M-Q11、2022M-Q13、2023S-Q26(a)、2023S-Q26(d)、2023S-Q34(b)、2023S-Q34(c)、2024M-Q9、2024M-Q10、2024M-Q11、2024M-Q12、2025M-Q2、2025E-Q36(a)、2025E-Q36(b)

## 题型 3：盐的水解与溶液酸碱性

**识别**：「Explain why the solution is acidic / basic」「Explain why KHSO₃ gives an acidic solution while KHCO₃ gives a basic solution」「write the hydrolysis equation」。题干通常给出一种盐（如 KCN、NH₄Cl、KHCO₃、KHSO₃、Na₃PO₄）或一个等当点溶液。

**步骤**
1. 判断阳离子与阴离子的来源：强酸或强碱的离子（K⁺、Na⁺、Cl⁻、NO₃⁻）不水解，为中性离子。
2. 弱酸根（如 CH₃COO⁻、CN⁻、PO₄³⁻、ClO⁻、RCOO⁻）与水反应生成 OH⁻，溶液碱性。弱碱阳离子（如 NH₄⁺）水解生成 H₃O⁺，溶液酸性。
3. 两性离子（HCO₃⁻、HSO₃⁻、HAsO₄²⁻）：写出它的两个相互竞争的反应（一个产生 H₃O⁺，一个产生 OH⁻），比较二者的程度（K 值或 Ka、Kb 的相对大小），由占优的一方决定溶液的酸碱性（2018S-Q31(bii)；2022S-Q28）。
4. 写出方程式，并比较 [OH⁻] 与 [H₃O⁺]，得出结论。
5. 在滴定中，等当点溶液的酸碱性由盐的水解决定，因此指示剂的选择也依赖此结论（见题型 6；如 2020E-Q37(d) 中磷酸钠水解使等当点呈弱碱性，pH 约 9）。

**得分点（key 的典型写法）**：
✓ 2022S-Q28（7 分）：K⁺ 为中性、不反应；HSO₃⁻ 与 HCO₃⁻ 分别发生水解；比较两种反应的程度；指出 [OH⁻] > [H₃O⁺] 为碱性、反之为酸性；至少两条方程式。
✓ 2019S-Q27(a)（4 分）：次氯酸根水解使 OH⁻ 过量（[OH⁻] > [H⁺]）；写出方程式（反应物与产物都正确并配平，2 分）。
✓ 2019S-Q27(b)（3 分）：加入盐酸后 pH 下降；写出与次氯酸钙相关的方程式（配平）。
✓ 2017E-Q39(e)（2 分）：RCOO⁻ 为弱酸的共轭碱，与水反应接受 H⁺（水解）生成 OH⁻。
✓ 2018S-Q31(bii)（1 分）：溶液呈碱性，说明反应 1 的程度大于反应 2（或 K₁ > K₂）。
✓ 2023S-Q33(b)（5 分）：等当点时 NH₃ 水解生成 OH⁻，[OH⁻] > [H⁺]，选用 phenolphthalein，并写出 NH₃(aq) + H₂O(ℓ) ⇌ NH₄⁺(aq) + OH⁻(aq)。

**易错点（考试报告）**：2022 报告指出 “explaining the difference between solutions formed by two salts”（2022S-Q28）是该卷最难的题之一。以下易错点据 key 归纳：
- 认为 KHSO₃ 也呈碱性，或只写一个水解方程。
- 比较两个水解程度时只写 “produces OH⁻”，没有比较程度。
- 把强酸强碱盐（如 KCl、NaNO₃）误判为水解。
- 写方程式时漏掉 “⇌”，或只写水解的一边。

**真题**：2016S-Q31(a)、2017E-Q39(e)、2018S-Q27(d)、2018S-Q31(b)(ii)、2019S-Q27(a)、2019S-Q27(b)、2020E-Q37(d)、2021M-Q9、2022S-Q28、2023M-Q18、2023S-Q33(b)、2024M-Q4、2025M-Q19

## 题型 4：缓冲溶液 ★

**识别**：「buffer」「buffering capacity」「buffer equilibrium」「explain why the pH changes only slightly when a small amount of acid / base is added」。题干给出弱酸与其共轭碱的体系（如 H₂CO₃/HCO₃⁻ 血液缓冲，H₃C₆H₅O₇/H₂C₆H₅O₇⁻ 柠檬酸缓冲，CH₃COOH/CH₃COO⁻，C₆H₅COOH/C₆H₅COO⁻，HPO₄²⁻/H₂PO₄⁻，NH₄⁺/NH₃）。

**步骤**
1. 写出缓冲对的平衡方程式（用 ⇌）：HA + H₂O ⇌ H₃O⁺ + A⁻（或其逆）。
2. 加入 H⁺（强酸）：A⁻ 与 H₃O⁺ 反应，平衡向左移动，H₃O⁺ 被消耗。
3. 加入 OH⁻（强碱）：HA + OH⁻ → A⁻ + H₂O，平衡向右移动，OH⁻ 被消耗。
4. 解释 pH 变化很小：大部分加入的 H⁺ 或 OH⁻ 被缓冲对消耗，[H₃O⁺] 只有小幅变化，因此 pH 变化小（用 pH = −log[H⁺] 收尾）。
5. 对比非缓冲体系：纯水中没有足够的弱酸或弱碱与外加离子反应，加入的 H⁺ 或 OH⁻ 完全引起 pH 变化（2016S-Q32(b)）。
6. 缓冲容量：取决于两组分的绝对浓度（浓度越高，缓冲容量越大，2018S-Q29(e)）以及两组分的相对浓度（2024S-Q32(e) 的 key 只要求列出这一因素；“越接近 1:1 越好”属于补充化学知识，不在 key 中）。缓冲容量的定义：在 pH 变化不超过一个单位之前能加入的酸或碱的量（2024S-Q32(d)）。

**得分点（key 的典型写法）**：
✓ 2016S-Q32(a)（2 分）：H₂CO₃ + H₂O ⇌ H₃O⁺ + HCO₃⁻（或其逆）。
✓ 2016S-Q32(b)（4 分）：加入 HCl 使 [H₃O⁺] 增大；缓冲中有足够的 HCO₃⁻ 与之反应；平衡左移（或逆反应速率增大）使 [H₃O⁺] 回落；纯水中没有足够的 OH⁻/弱碱反应，故 pH 显著变化。
✓ 2018S-Q29(d)（4 分）：OH⁻ 与柠檬酸反应，H₂C₆H₅O₇⁻ 增加、H₃C₆H₅O₇ 减少，平衡向产生柠檬酸的方向移动，[H₃O⁺] 减小但变化很小；纯体系无弱酸可反应。
✓ 2018S-Q29(e)（3 分）：两种组分的浓度都增大，能与更多的 H⁺ 或 OH⁻ 反应，因此在 pH 明显变化前可以加入更多酸或碱。
✓ 2021S-Q28(bii)（5 分）：缓冲的定义；区域中有弱酸 C₆H₅COOH 与其共轭碱 C₆H₅COO⁻；写出方程式；加入的 OH⁻ 被苯甲酸消耗，pH 没有明显上升。
✓ 2023S-Q28(a)（3 分）：缓冲的定义（抵抗 pH 显著变化）；H₂CO₃ 与 OH⁻ 反应；HCO₃⁻ 与 H⁺ 反应。
✓ 2024S-Q32(c)（3 分）：强酸增加 [H₃O⁺]；缓冲平衡左移以抵消变化；pH 只下降一点。
✓ 2025S-Q29(b)（5 分）：写出含 OH⁻ 的方程式（CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O）；[OH⁻] 增大；平衡向消耗 OH⁻ 的方向移动；新平衡时 [H₃O⁺] 减小，但变化量很小；pH 略升（key 的第五点）。

**易错点（考试报告）**：2023 报告把 “defining and explaining a buffer system”（2023S-Q28）列为该卷最难的题之一。2024 报告把 Question 32（缓冲的应用）列为第二卷最难的题之一。以下易错点据 key 归纳：
- 把缓冲溶液写成 “pH 不变”，应为 “pH 变化很小”。
- 没有写出加入的 H⁺ 或 OH⁻ 与缓冲对的反应式。
- 只说 “buffer resists change”，不说明是哪两个物种起作用（2023S-Q28(a) 要求说明每个物种的作用）。
- 用缓冲解释纯水（纯水不是缓冲体系，2016S-Q32(b)）。
- 方程式漏掉双箭头或写错一个物种（2018S-Q29(a) 注明 “one minor error, include lack of double arrow”）。
- 把缓冲容量与 pH 混为一谈，或只说“浓度高”而不说明是哪两种组分。

**真题**：2016S-Q32(a)、2016S-Q32(b)、2018S-Q29(a)、2018S-Q29(b)、2018S-Q29(d)、2018S-Q29(e)、2019E-Q36(d)、2019E-Q36(e)、2020S-Q30(b)、2021S-Q28(b)(ii)、2022M-Q5、2023S-Q28(a)、2023S-Q28(b)、2024S-Q32(a)、2024S-Q32(c)、2024S-Q32(d)、2024S-Q32(e)、2025S-Q29(a)、2025S-Q29(b)

## 题型 5：pH、Kw 与强酸强碱计算 ★

**识别**：「Calculate the pH」「Determine the pH of the final solution」「calculate the concentration of the hydroxide ion」「calculate the H⁺(aq) and OH⁻(aq) concentrations of pure water at …」。题干给出 Kw 随温度变化的数值，或给出两种溶液混合的体积与浓度。

**步骤**
1. 由 n = cV 求 H⁺ 或 OH⁻ 的物质的量（mL 换算为 L；Ca(OH)₂ 与 Ba(OH)₂ 每摩尔提供 2 mol OH⁻，2019S-Q32、2024S-Q34 的 key 都计入此因子）。
2. 按 1:1 中和比较 n(H⁺) 与 n(OH⁻)，确定过量或限量物质（2019S-Q32 的 key：H⁺ 为限量试剂）。
3. 若 OH⁻ 过量：c(OH⁻) = n(过量)/V（总体积）；[H⁺] = Kw/[OH⁻]；pH = −log[H⁺]。若 H⁺ 过量：c(H⁺) = n(过量)/V；pH = −log[H⁺]。
4. 纯水：[H⁺] = [OH⁻] = √Kw，与温度有关。pH 的数值随温度降低而升高，但纯水仍为中性（2017S-Q31(d)–(e)）。
5. 由 pH 求 [H⁺] = 10⁻ᵖᴴ，由 [H⁺] 求 [OH⁻] = Kw/[H⁺]。

**得分点（key 的典型写法）**：
✓ 2024S-Q34（8 分）：n(H⁺) 与 n(OH⁻) 各 1 分（OH⁻ 乘 2）；确定 OH⁻ 过量；n(OH⁻)过量 = 0.00762 mol；c = 0.08659 mol L⁻¹；由 Kw 求 [H⁺]；pH = 12.9。
✓ 2019S-Q32（9 分）：n(H⁺)、n(OH⁻)（乘 2）、限量试剂判断、过量物质、[OH⁻]、[H⁺]、pH = 12.1。
✓ 2017S-Q31(d)（2 分）：由 50 °C 的 Kw = 5.48 × 10⁻¹⁴ 求 [H⁺] = √Kw，pH = 6.63。
✓ 2017S-Q31(e)（2 分）：纯水中 [H⁺] = [OH⁻]，因此在 50 °C 呈中性，并说明理由。
✓ 2021S-Q29(b)（2 分）：[H⁺] = [OH⁻] = √(5.13 × 10⁻¹⁵) = 7.16 × 10⁻⁸ mol L⁻¹。
✓ 2016E-Q42(f)（6 分）：各步计算都要写出，最后判断是否为酸雨；没有过程不得分。

## 题型 6：指示剂与终点

**识别**：「Select the most suitable indicator from the table」「Identify the most appropriate indicator for this titration and justify your choice」「Would the calculated concentration be too large or too small?」。题干通常给出指示剂及其变色 pH 范围（或颜色变化）。

**步骤**
1. 确定等当点的 pH：强酸与强碱约为 7；弱酸与强碱（生成弱碱性盐）为碱性，约 9；由盐的水解决定（题型 3）。
2. 找出变色范围覆盖或最接近等当点 pH 的指示剂。
3. 写出选择理由：指示剂的终点（颜色变化点）应尽量接近等当点（2021S-Q28(a)）。
4. 说明颜色变化：酸性一侧到碱性一侧的颜色（如 phenolphthalein 无色 → 粉红，methyl orange 红 → 黄）。
5. 若指示剂的终点偏离等当点，判断滴定读数偏大或偏小，并判断计算浓度的变化（2019S-Q35(b)）。
6. 多元酸的等当点数目取决于酸：H₂SO₃ 有两个（2019S-Q35(b) 的情境）；H₃PO₄ 有三个，第三个等当点的 pH 超出酚酞的变色范围（2018S-Q27(d) 的 key 提及）。若指示剂只在第一等当点变色，则只滴到第一终点，key 接受“偏小”，或附“已达第一等当点、需修正计算”理由时的“不变”。

**得分点（key 的典型写法）**：
✓ 2016S-Q34(b)（4 分）：选 Bromocresol Green（变色范围 3.8–5.4，覆盖约 pH 4.8 的等当点）；说明其他指示剂在等当点之前或之后变色，会导致系统误差。
✓ 2018S-Q27(d)（5 分）：key 为 phenolphthalein。理由需包括五个有效得分点及一个方程式：等当点时溶液中有 PO₄³⁻（3OH⁻ + H₃PO₄ → PO₄³⁻ + 3H₂O）；PO₄³⁻ 水解生成 OH⁻（PO₄³⁻ + H₂O ⇌ HPO₄²⁻ + OH⁻）；等当点呈弱碱性（pH 约 9）；指示剂的变色 pH 与等当点 pH 接近；Na⁺ 为中性离子，不影响 pH。缺少水解方程式时最多 4 分。甲基橙也可接受，但须以第一等当点（pH 约 4.7）为依据并附方程式。
✓ 2020E-Q37(d)（5 分）：选 phenolphthalein；写出 OH⁻ + H₃PO₄ → PO₄³⁻ + H₂O 或磷酸根水解的方程式；等当点 pH 约 9，与指示剂变色点接近。key 注明：没有水解或反应方程式的，最多 4 分。
✓ 2021S-Q28(a)（3 分）：等当点 pH 约 9，cresolphthalein（pH 8.2–9.8）是唯一在此 pH 变色的指示剂。
✓ 2023S-Q33(b)（5 分）：选 phenolphthalein；等当点 [OH⁻] > [H⁺]；指示剂在碱性范围变色；写出 NH₃ 水解方程式。
✓ 2017E-Q37(d)（4 分）：key 同时列出 bromothymol blue 与 phenolphthalein；理由是等当点 pH = 7（强酸强碱），这两个指示剂的变色点接近 7。注意：phenolphthalein 的变色范围为 8.3–10.0，与 7 相距较远。key 接受两者，作答时应以变色范围与等当点的接近程度说明理由，而不能只凭名称。

**易错点（考试报告）**：2022 报告称滴定计算与操作技术（2022E-Q38）对许多考生有挑战（2022E-Q38(c) 的指示剂选择属于本题型）。以下易错点据 key 归纳：
- 只选颜色变化明显的指示剂，不比较变色范围与等当点。
- 把等当点（equivalence point）与终点（end point）混为一谈，没有说明指示剂变色点应接近等当点。

## 题型 7：滴定操作与器材

**步骤**
1. 器材冲洗的规则：滴定管用待装溶液冲洗（标准液或待测液，取决于装入的是哪一种）；锥形瓶用蒸馏水冲洗（不能用待测液冲洗，否则增加待测物的量）；移液管用待吸取的溶液冲洗（以保证吸取的物质的量准确）。容量瓶用蒸馏水冲洗（2019E-Q39(b)）。

✓ 2021E-Q35(a)（2 分）：任意两个相关性质。

## 题型 8：滴定曲线

**识别**：「Label the equivalence point on the titration curve using an arrow and record the pH」「circle the region on the titration curve where buffering occurs」「give two reasons … making reference to the titration curve」。

**步骤**
1. 读出起始 pH，判断酸或碱的强弱（起点 pH 与浓度相关）。

**得分点（key 的典型写法）**：

✓ 2021S-Q28(bi)（1 分）：圈出曲线上的缓冲平坦区域。
