## 题型 1：合成路线、工业反应与条件

**识别**：题干要求「design / complete a synthesis route」「use equations to show how … can be produced」「write an equation for the fermentation / hydration process and state the conditions」「combine these equations to produce an overall equation」。

**步骤**
1. 列出起始物与目标产物，逐步写出：反应物 → 产物、试剂或催化剂、条件、反应类型（hydration、oxidation、esterification、fermentation 等）。
2. 工业反应要写全条件：催化剂（H⁺，如 H₃PO₄、H₂SO₄；或酶，如 zymase、lipase）、温度、压强、相态（水以 H₂O(g) 参与）。
3. 方程式用 condensed structures；配平；需要时在箭头上方注明催化剂。
4. 多步合成时，若题目要求总方程式，把各步中间产物消去，写出总反应的反应物与产物，再配平。
5. 选择起始物时，注意每一步的可行性：如乙烯水合得乙醇，戊醛或戊-1-醇氧化得戊酸，乙醇与戊酸酯化得 ethyl pentanoate。

**得分点（key 的典型写法）**：每一步的反应物与产物正确（2021E-Q39(a) 的 key：乙烯水合一步 4 分，为反应物、产物、酸催化剂与 H₂O(g) 各 1 分；生物柴油一步 4 分，为反应物、产物、配平与脂肪酶各 1 分）；乙烯水合时水为气态 H₂O(g) 并指明酸催化剂（2021E-Q39(a)）；发酵的产物需包括 CO₂（2022S-Q33(a)：2 C₂H₅OH + 2 CO₂，配平，酵母或 zymase 为催化剂，温度或 pH 或压强任选其一）；水合的条件（温度 300 °C 或约 6000–7000 kPa 或水为气态，任选其一，2022S-Q33(a)）；2019S-Q29(a) 合并两个方程式得到总方程式，产物、反应物与配平各 1 分；2018S-Q30(c) 第 3 步由 (B) 合成 (C) 的两种试剂：酸化的重铬酸盐或高锰酸盐（或硫酸加其中之一），key 任选两个写法之一。

**易错点（考试报告）**
- 2020S-Q33（ethyl pentanoate）的 key 要求学生在两个反应容器中分别完成乙醇合成与戊酸合成，再酯化。报告称此题平均 39.53%，为该卷最难题，许多考生没有作答。
- 发酵方程式漏写 CO₂（2022S-Q33(a) 与 2023E-Q39(aii) 的 key 都要求正确的产物与配平）。
- 乙烯水合中漏写催化剂或水的相态（2021E-Q39(a) 的 key 要求 H₂O(g)）。
- 2023E-Q39(aii) 题干要求使用 condensed structures，写作答时应按题干的表示方式书写。

**真题**：2016S-Q30(a)、2016S-Q30(b)、2018S-Q30(c)、2019S-Q29(a)、2020S-Q33、2021E-Q39(a)、2022S-Q33(a)、2023E-Q39(aii)

## 题型 2：工业条件：速率与产率的折中

**识别**：题干要求「state the conditions that would optimise the rate / yield」「state a compromise」「explain the effect on rate and yield」「justify the temperature and pressure」「explain why excess water increases the rate and yield」；题干常给出一个工业过程（哈柏法、接触法、水合、生物柴油、soap 生产等）。

**步骤**（对应本主题的约定：一段解释同时覆盖速率与产率）
1. **写出热效应与气体摩尔数变化**：正反应是放热还是吸热；气体反应物与产物的物质的量之和谁大。
2. **速率（碰撞理论）**：
   - 温度升高 → 分子平均动能增大 → 碰撞频率增加，能量达到或超过活化能（Eₐ）的碰撞比例增加 → 速率增大；
   - 压强增大（气体）→ 单位体积内粒子数增加 → 碰撞频率增加 → 速率增大；
   - 催化剂降低 Eₐ，提供另一条反应路径，有效碰撞比例增加；它同等加速正、逆反应，不改变平衡位置。
3. **产率（勒夏特列原理）**：
   - 放热反应：降低温度有利于正向；吸热反应：升高温度有利于正向；
   - 气体分子数减少的方向：增大压强有利于正向；
   - 增加反应物浓度或移出产物有利于正向。
4. **折中**：速率与产率对温度的要求通常相反，因此选取中等温度；压强受设备与成本的限制；催化剂不改变产率，但可使所需的温度与压强降低，改善经济性。
5. **写出结论**：说明最终选取的条件，并说明它是速率与产率之间的折中。

**得分点（key 的典型写法）**：
- 2017S-Q30(a)：速率的条件（高温、高压、催化剂，至少写两项）与产率的条件（低温、高压、移出产物，至少写两项）。
- 2017S-Q30(b)（6 分）：指出一个需要折中的条件（温度），分别解释其对速率（碰撞理论）与产率（平衡）的影响，并说明折中的理由（共 6 分：指出折中条件 1 分；速率 1–2 分；产率 1–2 分；说明折中理由 1 分）。
- 2018E-Q38(a)（7 分）：温度段（高温快、放热低温利于产率，因此取中等温度，约 300–400 °C）；压强段（高压同时加快速率并增加产率）；经济段（高温高压成本高，催化剂可使用较低条件）。
- 2021E-Q38（12 分）：速率（6 分）：温度提高平均动能与有效碰撞比例；催化剂降低 Eₐ 且同等加速正逆反应；高压增加粒子数密度。平衡（3 分）：仅针对第二步，高温不利于产率（吸热逆向），高压有利于正向（气体分子数减少）。折中（2 分）：温度的折中，以及压强受成本与安全限制。
- 2023E-Q35(a)（8 分）：纯用碰撞理论解释催化剂（1–2 分）、温度（1–3 分）与压强（1–3 分）。此题不需要平衡的论述。
- 2023E-Q39(bii)（5 分）：高压同时增加速率与产率（气体分子数减少的方向）；高温增加速率，且吸热反应有利于产物，但适中的温度兼顾经济与安全。
- 2024E-Q36(a)（6 分）：速率（高温、催化剂、浓度增加）；产率（吸热反应中高温有利于正向，增加反应物浓度，移出产物）。
- 2025E-Q37(b)（3 分）：过量水增加碰撞频率，加快正向速率；增加水使平衡向正向移动，提高产率。

**易错点（考试报告）**
- 只写速率，不写产率；或只写产率，不写速率。本题型的 key 几乎都要求两者都有。
- 把催化剂说成能提高产率。2021E-Q39(e) 与 2021E-Q38 的 key 都明确：催化剂同等加速正逆反应，不改变平衡位置，产率不变。
- 说"高压增加产率"却不说明原因。正确的理由是气体分子数减少的方向有利于平衡正向移动。
- 速率的解释只写"高温使反应更快"，不写"能量达到或超过 Eₐ 的碰撞比例增加"。2023E-Q35(a) 与 2021E-Q38 的 key 都要求这一点。
- 2021 报告：2021E-Q38 平均 35.5%，为该卷的挑战性题。2024 报告：2024E-Q36(a) 的 "outline and justify" 为最难小题。
- 2019E-Q37(e) 预测肥皂生产的最佳条件（高温、高浓度 NaOH、搅拌或移出产物），搅拌只增加表面积与速率，不影响产率；移出产物才影响产率。

**真题**：2016E-Q39(b)、2017S-Q30(a)、2017S-Q30(b)、2018E-Q38(a)、2019E-Q37(e)、2019S-Q29(b)、2021E-Q38、2023E-Q35(a)、2023E-Q39(bii)、2024E-Q36(a)、2025E-Q37(b)

## 题型 3：绿色化学与工艺评价

**识别**：题干要求「which process is preferred / more common」「explain why X is a greener process」「state reasons why fermentation is more common than hydration」「which catalyst is industrially preferred」。

**步骤**
1. 确定评价的维度：原料是否可再生、能耗（温度与压强）、废物与副产物、设备成本、安全性、催化剂能否重复使用、对环境的影响。
2. 每一条理由都采用对比句式："A uses … whereas B uses …"。
3. 理由须具体，不只写"cheaper"或"better"。
4. 选择催化剂时，列出它的优点（如避免生成皂、能耗低、可重复使用、温度低、毒性小），任选三项。

**得分点（key 的典型写法）**：
- 2020E-Q40(g)（2 分）：从两个不同角度对比生物柴油与化石燃料柴油，如可再生原料 vs 化石燃料需要数百万年形成；生产不需要高温与昂贵复杂的设备，碳足迹较低。
- 2023E-Q39(c)（3 分）：任选三项：发酵所需能量更低；成本更低；更"绿"；使用可再生原料（糖），而乙烯水合使用石化原料。
- 2020E-Q40(f)（3 分，与 PRO7 合并）：工业上更倾向使用脂肪酶（lipase），任选三项理由（见 PRO7）。

**易错点（考试报告）**
- 只写 "greener" 或 "cheaper"，不指出对比的依据。
- 把"可再生"与"便宜"混为一谈。
- 报告未对本题型单独评语，证据较少（仅 3 个 part）。

**真题**：2020E-Q40(f)、2020E-Q40(g)、2023E-Q39(c)

## 题型 4：肥皂与洗涤剂 ★

**识别**：题干出现「saponification」「soap」「detergent」「micelle」「hard water」「scum」「carboxylate」「sulfonate」；或要求画出肥皂结构、标注胶束图、写出皂化或沉淀方程式。

**步骤**
1. **皂化（saponification）**：三酸甘油酯 + 3 NaOH → 甘油 + 3 个 RCOO⁻Na⁺（肥皂）。写方程式时反应物与产物都要写全，甘油是产物之一。
2. **肥皂结构**：长的烃链（非极性尾，疏水）+ 羧酸根离子头（COO⁻，亲水，带电）。画结构时两部分都要标注。
3. **去污原理（胶束，micelle）**：离子头朝外，接触水（离子-偶极力）；烃链朝内，包裹油脂（色散力）；胶束悬浮油污，搅拌后被带走。
4. **水分子的定向**：水分子的 H 指向 COO⁻ 一端（离子-偶极力）。
5. **硬水**：Ca²⁺、Mg²⁺ 与 RCOO⁻ 生成不溶的钙（镁）盐，即浮渣（scum）；失去的表面活性离子不能形成胶束，清洁作用下降。
6. **合成洗涤剂**：头部为磺酸根（–SO₃⁻），其钙盐可溶，因此在硬水中仍有效。
7. **比较肥皂与洗涤剂**：相同点是都有长的非极性烃链与离子头；不同点是头部分别为羧酸根与磺酸根。

**得分点（key 的典型写法）**：
- 皂化方程式：反应物 NaOH、三酸甘油酯，产物 甘油 与 钠盐，配平（2024E-Q37(ai)：缺少的反应物（NaOH）与产物（硬脂酸钠）共 1–2 分，配平 1 分，共 3 分）。
- 2017E-Q39(d)：皂化的 4 种产物结构各 1 分（3 个肥皂结构与甘油）。
- 2017E-Q39(ai)（5 分）：补全 烃链（加入 CH₃ 端基）；标注 COO⁻（Na⁺、Li⁺、K⁺ 任一）；标注长烃链尾为非极性（疏水）；标注离子头为亲水、带电；画出水分子，H 指向 COO⁻。
- 2019E-Q37(a)（7 分）：尾部与油脂之间为色散力；头部与水之间为离子-偶极力；胶束悬浮油污，可被搅拌带走；画出标注清楚的图（尾–油脂、头–水两种相互作用）。
- 2024S-Q31(b)：胶束图中 W（位于胶束外）、X（位于胶束内）、Y（位于胶束内，色散力发生的位置：烃链之间或烃链与油污之间）、Z（指示亲水头基）各 1 分，共 4 分。
- 2022E-Q36(c)（3 分）：硬水中肥皂的清洁作用减弱，洗涤剂仍有效；硬水含 Ca²⁺ 或 Mg²⁺；肥皂的钙盐不溶，洗涤剂的钙盐可溶。
- 2019E-Q37(b)（4 分）：洗涤剂不与硬水中的离子形成沉淀；肥皂形成沉淀（浮渣）后，可形成胶束的离子减少；方程式的产物与反应物正确，配平（碳链长度超过 12 个碳，key 写法 n > 12）。
- 2025E-Q35(c)（4 分）：浮渣是表面活性离子与 Ca²⁺ 的沉淀；沉淀使可用的表面活性离子减少，因此需要更多肥皂；方程式正确。
- 2025E-Q35(e)（3 分）：洗涤剂的磺酸根钙盐可溶，不沉淀，因此水中 Ca²⁺ 浓度更高。

**易错点（考试报告）**
- 把胶束画成头部朝内、尾部朝外；2024S-Q31(b) 与 2025E-Q35(b) 都要求标注正确的朝向。
- 把皂的尾部画成离子、头部画成非极性。
- 把硬水的问题说成"肥皂与水反应"，而不是"肥皂与 Ca²⁺ 或 Mg²⁺ 沉淀"。
- 2025E-Q35(a) 由 caprylic acid 与 NaOH 生成皂，这是羧酸的中和反应（RCOOH + NaOH → RCOO⁻Na⁺ + H₂O），与三酸甘油酯的皂化不同。key 要求反应物中的 NaOH 与产物中的水都要写出。
- 报告：2024 报告把 2024S-Q31（soap 与 detergent 的结构异同及胶束图）列为肥皂类考点，但该报告点名的最难题为 Q28（溶解性）与 Q30（海洋酸化），不属于本文件。

**真题**：2017E-Q39(ai)、2017E-Q39(b)、2017E-Q39(d)、2019E-Q37(a)、2019E-Q37(b)、2019E-Q37(d)、2020E-Q40(ei)、2022E-Q36(a)、2022E-Q36(b)、2022E-Q36(c)、2024E-Q37(ai)、2024S-Q31(a)、2024S-Q31(b)、2025E-Q35(a)、2025E-Q35(b)、2025E-Q35(c)、2025E-Q35(e)

## 题型 5：生物柴油与酯交换

**识别**：题干出现「transesterification」「biodiesel」「triglyceride + ethanol / methanol」「base-catalysed vs lipase-catalysed」；或要求写出生物柴油的方程式，或比较两种催化方法。

**步骤**
1. **写方程式**：甘油三酯 + 3 ROH（甲醇或乙醇）⇌ 3 个脂肪酸烷基酯（生物柴油）+ 甘油。催化剂写在箭头上方（碱，如 NaOH；或脂肪酶 lipase）。
2. **产物检查**：甘油必须作为产物列出；生物柴油写成 R–COOR′ 的形式（烷基酯，如 methyl 或 ethyl ester）。
3. **比较催化方法**：碱催化（NaOH）与游离脂肪酸反应生成皂，降低产率与纯度；腐蚀性强，需要高温，并增加后续纯化的成本。脂肪酶催化温和，不生成皂，产物纯度高，易与甘油分离，可生物降解。
4. **对比句式**："The lipase-catalysed method … whereas the base-catalysed method …"。

**得分点（key 的典型写法）**：
- 2020E-Q40(a)（3 分）：甘油作为产物；生物柴油的结构正确；方程式配平。
- 2024E-Q37(aii)（4 分）：反应物（甲醇或乙醇）与产物（methyl 或 ethyl stearate）各 1–2 分；催化剂（碱，NaOH）写在平衡箭头旁；配平。
- 2016S-Q28(b)（3 分）：每一点 1 分，最多 3 分；必须明确指出是哪一种催化方法，每一点都是对比。典型的对比点包括：脂肪酶法产率更高（不产生皂）；纯度更高；更安全（不需要腐蚀性强碱，无高温风险）；环境影响小（脂肪酶可生物降解）；总成本更低（纯化甘油更简单）。
- 2021E-Q39(a)（8 分，与题型 1 合并）：脂肪酶为催化剂，写在箭头上方；反应物与产物正确；配平。

**易错点（考试报告）**
- 漏写甘油作为产物，只写三个酯。
- 催化剂与方法不对应：脂肪酶（lipase）写的是 NaOH，或把 NaOH 当作酶。2024E-Q37(aii) 的 key 要求在平衡箭头旁写出碱催化剂 NaOH（碱催化法的写法），与题干中的脂肪酶法区分开。
- 只写"lipase is cheaper"等无依据的比较，不指出与碱催化方法的具体差异。
- 2016S-Q28(b) 的评分要求每一点都指明是哪一种方法，否则不计分。

**真题**：2016S-Q28(b)、2020E-Q40(a)、2021E-Q39(a)、2024E-Q37(aii)
