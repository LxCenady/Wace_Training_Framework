## 先记住：阅卷组反复扣分的地方

- **解释必须同时说明“方向”和“原因”**：只写 shift to the right 不得满分，key 要求用碰撞理论或正逆速率说明为什么（EQ4 与 EQ5 的区别见题型 4、题型 5）。
- **题目要求 rate 时要写正反应速率还是逆反应速率**：key 分开计分（2017S-Q28、2022S-Q26、2024S-Q26）。
- **温度才改变 K**：浓度、压强、体积、催化剂都不改变 K（2016E-Q41(b) 的 key 为 No change in K）。
- **考试报告对本主题的专门点评很少**：报告多为整节综述。2022 报告称第 26 题（预测平衡移动的结果）是第二卷作答最好的题之一；2024 报告把第 30 题（用方程式解释海洋酸化）列为第二卷最难的题之一。因此下文各题型的“易错点”以 key 的扣分点为主，报告原文只在有据可查时引用。

## 题型 1：碰撞理论解释反应速率 ★

**识别**：「Explain the effect of … on the rate … by applying collision theory」「Use collision theory to explain …」「Support your explanation with a labelled diagram」。常见情境：温度（Boltzmann 图）、浓度、反应物粉末的表面积（2022E-Q35(b)）、催化剂（2024E-Q37(b)）、反应进程中反应物减少（2019S-Q34(b)）。

**步骤**
1. 先写结论：速率增大或减小，以及是哪一种速率（正反应或总反应）。
2. 按影响因素对应一条因果链：
   - 浓度或压强增大：单位体积粒子数增加，碰撞频率增大。
   - 温度升高：平均动能增大，能量 ≥ Eₐ 的粒子比例增大（有效碰撞比例增大），同时粒子运动加快，碰撞频率增大。
   - 催化剂：提供活化能 Eₐ 更低的反应途径，能量 ≥ Eₐ 的碰撞比例增大。
   - 表面积增大：反应物可接触面积增大，碰撞频率增大。
3. 温度题必须分两条原因写（有效碰撞比例 + 碰撞频率），不能只写 “more collisions”。
4. 需要图时，在 Boltzmann 分布图上标出 Eₐ 和温度变化后的曲线（升温后曲线右移且峰变低宽），并标注坐标轴。
5. 解释图形形状时，把原因与斜率或平台对应起来：浓度高则初始斜率陡；反应物消耗后速率下降，曲线趋于平台。

**得分点（key 的典型写法）**：
✓ 平均动能 / 能量高于 Eₐ 的粒子比例（2018E-Q37(a) 第一点）
✓ 有效碰撞比例增大（第二、三点）
✓ 碰撞频率增大，因此总速率增大（第四、五点）
✓ 标注清楚的 Boltzmann 图（2018E-Q37(a) 的图占 2 分）
✓ 2018E-Q37(c)：浓度增大 → 单位体积粒子数增加 → 碰撞频率增大 → 速率增大，斜率更陡，并以反应更快完成解释平台。
✓ 2019S-Q34(b)（6 分）：速率由 CO₂ 体积变化率表示；浓度下降与表面积减小都降低碰撞频率；4 分钟后反应物耗尽，曲线平台。

**易错点（考试报告）**：考试报告对碰撞理论题没有逐题点评。2021 报告称第 37 题整题（18 分，平均 39.5%）可区分考生，计算需要非标准方法；该均值是整题的，不是 (aii)（3 分）单独的均值。以下易错点据 key 归纳：
- 只写 “more collisions” 而不说明是有效碰撞（能量 ≥ Eₐ）。
- 温度题只写碰撞频率，漏掉平均动能与能量分布。
- 催化剂题只写 “faster”，没有说明 Eₐ 降低。
- Boltzmann 图没有标 Eₐ，或图中曲线方向画错。

**真题**：2016M-Q2、2016E-Q39(c)、2017M-Q6、2017M-Q7、2017M-Q13、2018E-Q37(a)、2018E-Q37(c)、2019S-Q34(b)、2020M-Q7、2020S-Q34(b)、2021E-Q37(a)(ii)、2022M-Q7、2022E-Q35(b)、2024M-Q15、2024E-Q37(b)、2025E-Q38(b)

## 题型 2：能量剖面图

**识别**：「sketch an energy profile diagram」「label the activation energy and change in enthalpy」「indicate by a dashed line the change if an inhibitor …」。也可能要求从给定图中读出 ΔH 与 Eₐ，或判断反应吸放热。

**步骤**
1. 画坐标轴：纵轴写 Energy / Enthalpy (H)（带 kJ 单位，2021S-Q32(b) key 要求写出 y 轴单位），横轴写 Reaction pathway / Reaction progress。
2. 反应物水平线在左，产物水平线在右。放热反应产物低于反应物（ΔH 为负）；吸热相反。
3. 峰顶为活化配合物（过渡态）。Eₐ = 峰顶能量 − 反应物能量，并在图上标出。
4. 标注 ΔH（反应物与产物能量差）；注意量级：Eₐ 远小于 |ΔH| 的情形要按比例画（如 2017S-Q33(a) 的爆炸类反应，以及 2019S-Q27(c) 中 “pool chlorine” 与 “pool acid” 的反应，key 要求 Eₐ 相对于 ΔH 很小）。
5. 催化剂 / 抑制剂：催化剂使峰值降低（Eₐ 减小）；抑制剂使峰值升高，ΔH 不变（2017S-Q33(b)）。

**得分点（key 的典型写法）**：
✓ 坐标轴与标签（2019S-Q27(c)、2021S-Q32(b)）
✓ 反应物、产物位置正确（2017S-Q33(a)：产物能量低于反应物）
✓ Eₐ 与 ΔH 均标出（2022E-Q35(a)：Eₐ 与 ΔH 正确标注）
✓ 量级与符号正确：2021S-Q32(b) 的峰值约 600 kJ，ΔH 约 −92 kJ；2019S-Q27(c) 要求 ΔH 为负且相对较大，Eₐ 很小
✓ 抑制剂题（2017S-Q33(b)）：虚线峰值升高，反应物与产物能量不变

**易错点（考试报告）**：证据中没有针对能量剖面图的专门报告点评。key 反复扣分的点：
- 缺少坐标轴标签或 y 轴单位（2021S-Q32(b)）。
- 只标 Eₐ 不标 ΔH，或 ΔH 漏掉负号。
- 吸热与放热画反（产物高于反应物却标为放热）。
- 2022E-Q35(a) 的 key 要求 Eₐ 与 ΔH 的量级合理，不能画成与反应物差不多高。

**真题**：2016M-Q8、2016E-Q41(f)、2017S-Q33(a)、2017S-Q33(b)、2018M-Q19、2019S-Q27(c)、2020M-Q8、2021S-Q32(b)、2022E-Q35(a)、2023M-Q21、2025M-Q13

## 题型 3：动态平衡的特征与开放/封闭体系

**识别**：「State / describe the characteristics of a dynamic equilibrium」「State three inferences …」，常伴同位素标记（如 ¹⁵N 示踪）或颜色、浓度数据。

**步骤**
1. 动态平衡要写两点：宏观性质（颜色、浓度、压强）不再随时间变化；微观上正、逆反应仍在进行，且二者速率相等。
2. 同位素示踪证据：标记原子出现在反应物与产物中 → 正逆反应都在进行；标记比例保持恒定 → 已建立新平衡，速率相等（2025S-Q30(a)）。
3. 动态平衡不要求各物种浓度相等，只要求正逆速率相等（目录定义：浓度不一定相等）。
4. 若题目问开放/封闭体系：开放体系与外界交换物质，封闭体系不交换物质；在证据中，此点仅在 catalogue 定义中出现，没有对应的 key，作答时只写定义性说明。

**得分点（key 的典型写法）**：
✓ 2025S-Q30(a)（3 分）：一，正反应与逆反应都在发生（动态平衡）；二，注入的 ¹⁵N 氮气有一部分转化为氨；三，比例恒定说明新平衡已建立，正逆速率相等。key 注明：必须明确写出 ¹⁵N，否则不得满分。
✓ 2018E-Q38(c)(i)（1 分）：T₁ 时的变化可以是“体系已达平衡”、加催化剂或“无变化”中的任一项（key 接受多种答案）。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。key 反复要求的点：
- 把动态平衡说成“反应停止”或“浓度相等”。
- 三个推断之间互相重复（如两条都说“正逆反应同时进行”），只能得一分。

**真题**：2018E-Q38(c)(i)、2019M-Q2、2020M-Q12、2020M-Q16、2022M-Q3、2024M-Q13、2024M-Q14、2025S-Q30(a)

## 题型 4：勒夏特列原理预测平衡移动 ★

**识别**：「Predict the effect of …」「Use Le Châtelier's Principle to predict …」「circle increase / decrease / no effect」，以及以表格形式给出多种扰动，要求预测 shift、rate、colour（2022S-Q26、2024S-Q26）。

**步骤**
1. 写出平衡方程式，标出 ΔH 符号、物态（固体与纯液体不计入）、两侧气体计量数。
2. 判断扰动类型：
   - 加入或移走某物质：向削弱其变化的方向移动（移走产物 → 向右）。
   - 改变体积（总压）：看两侧气体计量数，体积减小 → 向气体分子数少的一侧移动（2025S-Q30(b)）；体积增大则相反（2018E-Q38(b) 中体积增大使甲烷产率下降）。
   - 改变温度：吸热方向受升温促进（2017S-Q28(b)、2020S-Q34(a)）。
   - 加入催化剂：不移动平衡，不改变产率，但正逆速率同时增大（2018E-Q38(b) 的 key 为 no effect）。
   - 加入惰性气体：恒容时不改变平衡，恒压时需看体积变化（证据中无对应题，作答时应说明前提）。
3. 写出 shift 方向、目标物种的量或浓度的变化，题目要求时写出 rate（正反应速率还是逆反应速率相对原来的变化）。
4. 颜色题：根据数据册颜色表，说明颜色变深还是变浅，并把它与该物种的浓度变化联系起来（2022S-Q26 的 key：加少量 FeCl₃ 使平衡右移、溶液更深红；加热使平衡左移、溶液变为更多棕或橙色；加水与加浓 Na₃PO₄ 使平衡左移、溶液呈很浅的棕色）。

**得分点（key 的典型写法）**：
✓ 2022S-Q26（12 分）：按三列分别给分（移动方向、正反应速率、颜色），每列对应四个变化，每列 4 分。
✓ 2024S-Q26（9 分）：三列各 3 分，对应三个变化。
✓ 2018E-Q38(b)（5 分）：催化剂无影响；体积增大 → 甲烷产率下降；升温 → 下降；移走甲烷 → 上升；降低 CO₂ 分压 → 下降。
✓ 2016E-Q39(c)（2 分）：加压时速率增大、产率增大。
✓ 2017S-Q28(a)（6 分）：盐酸加入后 pH 下降、正反应速率增大；加 Pb(NO₃)₂ 后两者都下降；加水后速率下降、pH 上升。
✓ 2025S-Q30(b)（4 分）：减小体积使 ¹⁵N 在氮气中的量下降、在氨中的量上升，并说明向气体分子数少的方向移动。

**易错点（考试报告）**：2022 报告称第 26 题（预测平衡变化的结果）是第二卷作答最好的题之一，说明此类题的常规步骤掌握较好。以下易错点据 key 归纳：
- 只写 shift 不写 rate（2022S-Q26、2024S-Q26 按列计分）。
- 把催化剂写成“使平衡向右”。
- 把温度的作用与 K 的变化混在一起（见题型 8）。
- 体积变化题中用“浓度增大”代替“压强增大”，忽略气体计量数。

**真题**：2016M-Q1、2016M-Q4、2016E-Q39(c)、2016E-Q41(e)、2017M-Q12、2017S-Q28(a)、2017S-Q28(b)、2018M-Q22、2018S-Q32、2018E-Q38(b)、2018E-Q38(c)(iii)、2019M-Q3、2019S-Q31(c)、2019E-Q36(d)、2019E-Q36(f)、2020M-Q24、2020S-Q29(b)、2020S-Q29(c)、2020S-Q31(c)、2020S-Q34(a)、2020E-Q40(d)、2021M-Q23、2021M-Q24、2021M-Q25、2021S-Q29(a)、2021S-Q32(d)、2022M-Q8、2022M-Q25、2022S-Q26、2023S-Q28(b)、2024M-Q1、2024S-Q26、2024S-Q30(a)、2024S-Q30(b)、2025M-Q4、2025S-Q30(b)

## 题型 5：用碰撞理论/正逆速率解释平衡移动 ★

**识别**：「Use collision theory to explain the change in concentrations …」「Explain why the equilibrium shifts …」「Justify your answer using collision theory」。题干通常先给出一个扰动（移走物质、加入 OH⁻、减小体积）。

**步骤**
1. 写出扰动，并指出哪一个速率先发生变化，原因是碰撞频率的改变。
2. 写出正逆反应速率的相对大小（“the rate of the reverse reaction is greater than the forward reaction”），并说明另一速率在开始时不受影响。
3. 写出平衡向哪个方向移动，直到正逆速率再次相等，形成新平衡。
4. 说明新平衡下有关物种浓度的变化（相对于原平衡增大或减小）。

示例结构（据 2020S-Q29(b) 与 2021S-Q32(c) 的 key 整理）：移走 X → X 的碰撞频率下降 → 与 X 相关的速率下降 → 另一方向的速率更大 → 平衡向 X 生成的方向移动，直到速率相等。

**得分点（key 的典型写法）**：
✓ 2020S-Q29(b)（5 分）：CH₄ 减少 → 碰撞频率下降 → 正反应速率下降 → 逆反应速率更大 → 平衡左移。
✓ 2021S-Q32(c)（5 分）：移走 NH₃ 瞬间 → 逆反应速率下降 → 正反应速率更快 → NH₃ 增加，H₂ 与 N₂ 减少 → 新平衡。
✓ 2025S-Q29(b)（5 分）：写出含 OH⁻ 的方程式（如 CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O）；OH⁻ 增加；正反应速率减小（或逆反应速率增大）；新平衡时 [H₃O⁺] 下降。
✓ 2025S-Q32(c)（4 分）：题干平衡式为 2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O，正反应指 CrO₄²⁻ 生成 Cr₂O₇²⁻。OH⁻ 降低 H⁺ 浓度 → 碰撞频率下降 → 正反应速率相对逆反应下降 → 新平衡时 [CrO₄²⁻] 升高，[Cr₂O₇²⁻] 下降。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。key 反复扣分的点：
- 只写 “the rate decreases”，没有指明是正反应还是逆反应。
- 漏掉“另一速率在开始时不变”这一步，因果链不完整。
- 写 “the equilibrium shifts” 但不写碰撞理论或正逆速率的比较。
- 2025S-Q29(b) 要求写出含 OH⁻ 的平衡方程式；没有方程式不能得全分。

**真题**：2016E-Q39(d)、2017S-Q28(a)、2017S-Q28(b)、2018M-Q21、2019E-Q36(g)、2020S-Q29(b)、2021S-Q32(c)、2022S-Q26、2024S-Q26、2025M-Q4、2025M-Q11、2025S-Q29(b)、2025S-Q32(c)

## 题型 6：浓度/速率-时间图

**识别**：「On the axes below, sketch the change in concentration …」「draw the forward and reverse rates …」「show on the graph the effect of …」。扰动可以是温度、体积、加入或移走物质。

**步骤**
1. 先画扰动前的平衡段：正、逆速率相等，浓度为水平线。
2. 判断变化类型：
   - 改变体积或加入、移走物质：浓度或速率在扰动瞬间发生不连续变化（突变）。
   - 反应过程中的物质浓度：从扰动时刻开始渐变，不能跳变。
   - 温度升高：速率的起始斜率变陡，曲线更早进入平台（2019S-Q34(c)；该题是 CO₂ 体积随时间的变化，并非可逆平衡，key 只看斜率与平台的变化）。
3. 计量比决定幅度：按方程式的系数画变化量之比（2016E-Q41(d) 中 O₂ 与 N₂ 的变化比为 2:1；2025S-Q32(a) 中 Cr₂O₇²⁻ 减少的速率约为 CrO₄²⁻ 增加速率的一半）。
4. 新平衡的水平段在同一时刻开始（2025S-Q32(a) 的 key 要求两条曲线同时稳定）。
5. 速率图中，正逆速率曲线在平衡点相交；扰动后两线分开，再次相交并水平延伸（2016E-Q41(ci)）。

**得分点（key 的典型写法）**：
✓ 2016E-Q41(ci)（3 分）：正逆曲线形状与方向正确；两线在 A 点相交；A 到 B 为直线。
✓ 2016E-Q41(d)（5 分）：N₂(g)、O₂(g) 的曲线形状正确；NO₂(g) 从零开始；比例 2:1；E₁ 到 E₂ 为水平线。

## 题型 7：平衡常数表达式

**识别**：「Write the equilibrium expression for …」「Write the equilibrium constant expression for …」「K = …」，也可能要求由 K 表达式反推平衡方程式。

**步骤**
1. 先写配平的平衡方程式，标明物态（水溶液用 aq，气体用 g，液体用 ℓ）。
2. K = （生成物浓度幂之积）÷（反应物浓度幂之积），幂次等于计量数。
3. 不写入固体与纯液体：水的自偶电离写作 K = [H₃O⁺][OH⁻]（2017S-Q31(b)），水本身不出现。
4. 气体用分压或浓度时，题干或 key 允许两种形式，但同一题中要统一。
5. 写出 K = 符号，并保持括号与指数清楚。

**得分点（key 的典型写法）**：
✓ 2016E-Q41(a)（2 分）：结构正确（生成物 ÷ 反应物）且指数正确；指数写错或缺失一处扣 1 分（key 注明 “one superscript incorrect or missing”）。
✓ 2019E-Q36(b)（2 分）：1 分为写出 “K =”，1 分为浓度表达式的结构正确。
✓ 2020S-Q29(a)（2 分）：一处次要错误扣 1 分（key 注明 “one minor error is 1 mark only”）。
✓ 2023S-Q34(a)（2 分）：以 K = [CH₃(CH)₄COO⁻][H₃O⁺]/[CH₃(CH)₄COOH] 的结构给分。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。key 反复扣分的点：
- 漏写 K =。
- 指数漏写或写错（一处即扣 1 分）。
- 把水或纯固体写入表达式（2017S-Q31(b) 的 key 只接受 [H₃O⁺][OH⁻] 或 [H⁺][OH⁻]）。
- 把 pH 或 pKa 的数值写进表达式。

## 题型 8：K 的大小与温度对 K 的影响

**识别**：「What does the value of K indicate about …」「predict the effect of an increase in temperature on the value of K」「what happens to K after the pressure is lowered」。

**步骤**
1. K 大 → 生成物占优，平衡位置偏右；K 小 → 反应物占优（2016E-Q41(f) 的 key：K 小，反应物占优，活化能大）。
2. 温度变化对 K 的影响：先由 ΔH 符号与 Le Châtelier 判断移动方向，再判断 K 增大或减小。吸热反应升温时 K 增大（如水的自偶电离，2017S-Q31(c) 表中 K 随温度升高而增大）；放热反应升温时 K 减小（2020S-Q29(c)）。
3. 浓度、压强、体积、催化剂改变时，平衡移动但 K 不变（2016E-Q41(b)：减压后 K 不变）。
4. 解释时写出“温度 → 移动方向 → 生成物或反应物的量变化 → K 的数值变化”。

**得分点（key 的典型写法）**：
✓ 2020S-Q29(c)（4 分）：K 减小（1 分）；由图可知升温时 H₂ 的物质的量减少（1 分）；[H₂S] 与 [CH₄] 增加、[H₂] 减少、逆反应被促进中任意两点（2 分）。
✓ 2016E-Q41(b)（1 分）：No change in K。
✓ 2017S-Q31(c)（1 分）：Kw 很小，说明只有极少量的产物存在于平衡中，体系主要以分子形式的水存在（key 接受其他合理答案）。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。key 反复扣分的点：
- 把 K 的变化归因于浓度或压强（只有温度改变 K）。
- 只说 “shift to the left”，不写 K 的数值变化。
- 把“K 增大”误写成“反应物增加”。

**真题**：2016M-Q3、2016E-Q41(b)、2016E-Q41(f)、2017S-Q31(c)、2018M-Q2、2020S-Q29(c)、2021M-Q20、2022M-Q6、2023M-Q17、2025M-Q3

## 题型 9：平衡体系的可观察现象

## 题型 10：真实情境中的平衡

**识别**：「explain what will happen in the blood when …」「use the equations to predict what might happen to ocean pH …」「Use Le Châtelier's Principle and the sequence of equations …」。常见情境：海洋酸化（CO₂ 溶解 → H₂CO₃ → HCO₃⁻ → CaCO₃ 溶解）、血液缓冲（CO₂ 与 HCO₃⁻）、肺部呼吸与 pH。

**步骤**
1. 按题目给出的方程式顺序逐个推理：外部改变 → 第一个平衡移动 → 中间物种变化 → 下一个平衡移动 → 最终 [H₃O⁺] 或 pH 的变化。
2. 每一步写明向左或向右，并用 Le Châtelier 或碰撞理论给出理由。
3. 结论回到情境：pH 下降或上升；CaCO₃ 的生成增加或减少。
4. 若要求写出两个后果，两个后果必须不同且合理（2020S-Q31(b) 的 key 只要求两个不同的合理后果）。
5. 注意次级效应：如 2024S-Q30(a) 的 key 指出，HCO₃⁻ 增加可能使方程式 3 左移，但 [H₃O⁺] 仍总体增加，结论不变。

**得分点（key 的典型写法）**：
✓ 2018S-Q32（4 分）：CO₂(aq) 增加 → 方程式 2 右移 → [CO₃²⁻] 下降 → 方程式 3 左移 → CaCO₃ 的生成减少。
✓ 2023S-Q28(b)（5 分）：CO₂ 增加 → H₂CO₃ 增加（写出方程式）→ 缓冲平衡右移 → [H₃O⁺] 增加 → 血液 pH 略降。
✓ 2024S-Q30(a)（4 分）：CO₂ 溶解增加 → 方程式 1 右移；H₂CO₃ 增加 → 方程式 2 右移；HCO₃⁻ 增加 → 方程式 3 右移；[H⁺] 增加，pH 下降。
✓ 2024S-Q30(b)（2 分）：[H⁺] 增加 → 方程式 4 右移 → CaCO₃ 被消耗，可用量减少。
✓ 2020S-Q31(c)（4 分）：若放弃京都议定书 → CO₂ 排放增加 → 溶解增加 → 正反应被促进 → [H₃O⁺] 增加 → 海洋 pH 进一步下降。
