## 先记住：阅卷组反复扣分的地方

- **每一步单独计分**：key 把 n(物质的量)、计量比、n、m/c/V 等逐行给分，只写最终数字很难拿到分。每一行都要写出数值和单位。
- **有效数字与单位是单独的分**（题型 7）：多份 key 在最终答案上单列一分，如 "correct to two significant figures"、"mark for 3 sig figs"。
- **先算后判断**：题干要求判断、比较或评价时（题型 2、3、7），结论必须由计算数字支撑，只写结论不计分。
- **★ 标记规则**：按 INDEX 分值排在前约四分之一的模式为 ★，QNT 共 8 个模式，取前两名：题型 1（298 分）与题型 3（151 分）。
- **报告备注的局限**：笔记中的 REPORT 字段有些是从其他小题复制来的泛泛句子（如 "proved to be effective in discriminating…"），本文只采用明确与本小题相关的备注。

## 题型 1：物质的量、质量、浓度换算与稀释 ★

**识别**：题干出现 mass、molar mass、concentration、volume of solution、dilute、g L⁻¹、mol L⁻¹、tonne 等词，或给出 M、m、c、V 中的若干量求另一个量。这是 QNT 中出现最多的基础计算，滴定、产率、气体等综合题的前几步通常也属于它。

**步骤**（每一步单独写一行，写出数值与单位）
1. 写出摩尔质量 M：题干给出则照用；否则用周期表原子量自行求和（数据手册不提供 M）。
2. 求 n：固体或纯物质用 n = m ÷ M；溶液用 n = c × V，V 必须是 L。
3. 单位换算单独写出：mL → L（÷ 1000）、tonne → g（× 10⁶）、mg → g（÷ 1000）、kg → g（× 1000）。
4. 按反应方程式的计量比换算到目标物质，例如 n(SO₂) = 8 × n(Fe₉Ni₉S₈)（2016E-Q39(a) 的计量比）。
5. 稀释题：溶质的 n 在稀释前后不变，可用 n = c × V 求出原溶液的 n，再除以新的体积求新浓度。
6. 最后换算到题目要求的量与单位（g、g L⁻¹、mol L⁻¹），有效数字见题型 7。

**得分点（key 的典型写法）**：
- 质量转物质的量单独计分，且要求 M 取值准确（2016E-Q39(a) 的 key 把"准确的 M 与计算"单列一分）。
- 体积或浓度换算（mL → L）计分（2016E-Q42(a) 中 n(Na₂CO₃) = c × 0.0164 那一行）。
- 计量比单独计分（2016E-Q39(a) 的 1 : 8 比例行，2017E-Q36(a) 的 Sb₂S₃ : Sb 比例行）。
- 最终数值与单位各计 1 分。

**易错**：
- 忘记 mL → L：2016E-Q42(a) 与 2016E-Q42(c) 的 key 都在 n = c × V 或 c = n ÷ V 中单独写出 mL → L 的换算。
- 单位链条断开：2018E-Q36(c) 先算出 mg 量（698 506 000 mg），再换成 g（698 506 g），之后才算 n；跳过 mg → g 会让后面的数字错三个数量级。
- tonne 换算：2024E-Q40(a) 先把 2245 tonne 换成 2.245 × 10⁹ g，再算 n(Ni)。
- 稀释后的体积：2016E-Q42(f) 中 100 mL 样品稀释到 250 mL，key 先算 250 mL 中的 n(H⁺)，再除以原样品的 0.100 L，漏掉这一步就得不到原样品的浓度。

**真题**：2016M-Q9、2016E-Q39(a)、2016E-Q42(a)、2016E-Q42(f)、2017S-Q29(a)、2017S-Q29(b)、2017S-Q33(c)、2017E-Q36(a)、2017E-Q36(b)、2017E-Q37(b)、2017E-Q37(c)、2018S-Q29(b)、2018E-Q35、2018E-Q36(c)、2018E-Q40(a)、2018E-Q40(c)、2019S-Q30(b)、2019S-Q32、2019E-Q38(d)、2019E-Q39(c)、2019E-Q40(a)、2019E-Q40(b)、2019E-Q40(d)、2020E-Q39(a)、2020E-Q39(b)、2022E-Q34、2022E-Q35(c)、2022E-Q37(f)、2022E-Q38(a)、2023E-Q35(b)、2023E-Q36(b)、2023E-Q37(a)、2023E-Q37(b)、2023E-Q38(a)、2023E-Q38(b)、2024S-Q34、2024E-Q36(c)、2024E-Q38(a)、2024E-Q38(b)、2024E-Q40(a)、2024E-Q40(b)、2024E-Q40(c)、2025E-Q35(d)、2025E-Q36(a)、2025E-Q36(b)、2025E-Q37(a)、2025E-Q38(d)、2025E-Q39、2025E-Q40(d)

## 题型 2：限量试剂与理论产量

**识别**：题干出现 limiting reagent、in excess、sufficient、enough、would … dissolve completely、remaining 等词，或要求判断加入的试剂是否足量。

**步骤**
1. 写出配平的反应方程式，读出计量比（H⁺ : OH⁻ = 1 : 1；每摩尔 Ca(OH)₂ 或 Ba(OH)₂ 提供 2 mol OH⁻）。
2. 分别算出两种反应物的 n，逐行写出。
3. 比较：用计量比把一种反应物的 n 换算成另一种所需的量，或比较 n ÷ 化学计量数；比值较小者为限量试剂。
4. 写出判断理由（指出哪种物质的 n 或比值较小，并说明它决定了反应的上限）。
5. 按限量试剂算产物或剩余量：剩余量 = 初始 n − 反应掉的 n；求浓度时用混合后的总体积。

**得分点（key 的典型写法）**：
- 方程式或计量比单独 1 分（2017S-Q29(a) 要求写出计量比）。
- 两个 n 各 1 分。
- 判断结论与理由计分：key 要求结论附带解释性陈述，只写结论不得分；2024E-Q40(c) 的限量判断（比较两个 n 并给出理由）为 1–3 分，其余为 n 的计算与 NO 的物质的量。
- 剩余量或后续量（2017S-Q29(b) 3 分：剩余 n、总体积、浓度各 1 分）。
- 足量判断（2019E-Q40(b)、2020E-Q39(c)）：要把"需要的 n"与"加入的 n"并列写出，再比较。

**易错**：
- 忘记 Ca(OH)₂ 或 Ba(OH)₂ 含两个 OH⁻：2019S-Q32 与 2024S-Q34 的 key 都写成 n(OH⁻) = 2 × c × V。
- 比较方向错：2021E-Q37(c) 应比较所需 Mn（= ½ × n(LiCoO₂)）与实际 Mn，而不是比较 LiCoO₂ 与 Mn 的质量。
- 剩余浓度的分母：2017S-Q29(b) 用混合后总体积 0.0445 L，不是某一种溶液的体积。
- 中和题中限量试剂与剩余物：2019S-Q32 先确定 H⁺ 为限量，再用剩余 OH⁻ 求 pH（12.1）。
- 2023E-Q38(a)：key 依据 1 : 2 : 1 的计量比判定 Cl₂ 为限量，其余两种反应物都足量，然后用 n(Fe(OH)₃) = 2 × n(Cl₂) 求产量。
- 2018E-Q37(d) 是概念题：盐酸过量的原因是使全部 Ga₂O₃ 反应、提高产率，不需要计算。

**真题**：2017S-Q29(a)、2017S-Q29(b)、2018E-Q37(d)、2019S-Q32、2019E-Q40(a)、2019E-Q40(b)、2020E-Q39(c)、2021E-Q37(c)、2023E-Q38(a)、2024S-Q34、2024E-Q40(c)

## 题型 3：产率、纯度与百分含量 ★

**识别**：题干出现 percentage yield、efficiency、purity、% by mass、impure、contains x% by mass、assuming the reactions go to completion，或给出"某步效率/产率"。

**步骤**
1. 先算理论量：完全反应时的 n 或 m，按计量比换算。
2. 给出实际量时：百分产率 = 实际产量 ÷ 理论产量 × 100%。
3. 给出效率 e%：若要求原料量，则原料量 = 理论所需量 × 100 ÷ e；若已知实际得到量，则理论量 = 实际量 × 100 ÷ e。方向由题意决定，不要机械地乘以 e%。
4. 纯度或质量分数：纯物质质量 ÷ 样品质量 × 100%；样品质量与题目规定的量（整片、整瓶、250 mL 溶液）不一致时，按放大倍数换算。
5. 若题目要求判断说法是否属实，写出计算值、比较基准与结论（格式见题型 7）。

**得分点（key 的典型写法）**：
- 理论量（n 或 m）1 分。
- 效率或产率换算 1 分（2022E-Q35(c) 的 key 用 100 ÷ 89.5 的形式体现效率）。
- 纯度或含量 1 分（2018E-Q40(c) 与 2020E-Q37(c) 的 key 都先算样品中的纯物质，再换算为百分比）。
- 带单位的最终答案 1 分。
- 例：2018E-Q40(a) 4 分，n(阿司匹林) = n(水杨酸) → 理论质量 → 85.5%；2024E-Q40(b) 4 分，理论 n(Ni(CO)₄) = n(Ni) → 67.6%；2025E-Q35(d) 6 分，由钙离子损失推出羧酸根，再算 7.32%。

**易错**：
- 效率方向反了：2022E-Q35(c) 要求的是"需要多少氧化铁"，key 用 ÷ 0.895（即 × 100/89.5），不是 × 0.895。
- 样品与溶液体积不匹配：2018E-Q40(c) 中 3.55 g 样品配成 250 mL，取 20.00 mL 滴定，放大倍数为 250 ÷ 20；2020E-Q37(c) 配成 250.0 mL、取 10.00 mL，放大 25 倍。
- 纯度基准：2024E-Q40(a) 先由 95.7% 纯度算出纯 Ni 质量，再换算 NiO；不能直接把 2245 tonne 当作纯 Ni。
- 百分比分母用错：2024E-Q40(b) 的分母是理论产量（1.516 × 10⁹ g），不是实际产量。
- 声称是否属实的题（2022S-Q31(b)）：key 先算"应吸水量"（3.97 g × 180 = 715 g）再乘以 97.4% 得 696 g，与实测 691 g 比较，结论是 claim not true；比较的两个数必须是同一基准。

**真题**：2016E-Q39(a)、2017S-Q33(c)、2017E-Q36(a)、2017E-Q37(c)、2018E-Q35、2018E-Q40(a)、2018E-Q40(c)、2019S-Q30(b)、2019E-Q38(d)、2019E-Q40(d)、2020E-Q37(c)、2020E-Q39(b)、2021E-Q37(d)、2022S-Q31(b)、2022E-Q34、2022E-Q35(c)、2022E-Q37(f)、2023E-Q35(b)、2024E-Q40(a)、2024E-Q40(b)、2024E-Q40(c)、2025E-Q35(d)、2025E-Q37(a)、2025E-Q40(d)

## 题型 4：滴定计算

**识别**：题干出现 titration、titre、burette readings、aliquot、average titre、standardised、back titration、neutralise、indicator，或给出滴定数据求浓度、质量或百分含量。

**步骤**
1. 由读数求 titre：titre = 终读数 − 初读数，逐行列出。
2. 判断一致性：一致的滴定值（concordant titres）常用标准是相差不超过 0.10 mL；明显偏离的离群值（粗测 rough、终点判断错误）剔除后取算术平均，保留到 0.01 mL。
3. 写出滴定反应的计量比（HCl : NaOH = 1 : 1；Na₂CO₃ : HCl = 1 : 2；H₃PO₄ : NaOH = 1 : 3；nicotine : CH₃COOH = 1 : 2 等）。
4. n(标准液) = c × V，V 用 L，取平均体积。
5. n(待测 aliquot) = n(标准液) × 计量比。
6. 放大到原溶液或原样品：× （总体积 ÷ 取样体积），例如 250.0 ÷ 25.00 = 10。
7. 换算成题目要求的浓度、质量或百分含量。
8. 返滴定：先算加入的过量试剂的总 n，再用标准液滴定剩余量，n(反应掉的) = n(总量) − n(剩余)。

**得分点（key 的典型写法）**：
- 平均 titre 1 分或 2 分（需剔除离群值；2024E-Q36(b) 的 key 注明：只完成表格最多 1 分，包含离群值的平均只给部分分）。
- n(标准液) 1 分。
- 计量比 1 分。
- 放大倍数 1 分。
- 最终浓度、质量或百分含量及单位 1 分。

**易错**：
- 离群值的处理：2025E-Q38(d) 的 key 剔除 18.85 mL，取 17.42、17.59、17.55 的平均 17.52 mL；这三个值相差 0.17 mL，超过常用的 0.10 mL 参考标准（key 本身也未完全满足该标准，故以 key 的做法为准）。学生应写明剔除的理由，不能只写"取平均"。
- 2020E-Q37(a)：粗测值 21.10 mL 不参与平均，19.40 mL 偏离其余约 0.7 mL，key 取 20.05、20.15、20.10 的平均 20.10 mL。
- 2020E-Q37(c)：key 的主解法为 3 NaOH : 1 H₃PO₄，得 19.1%（3 位有效数字）；注记中给出 2 : 1 的另一解法，得 28.7%，并说明该处理超出课程要求，学生不需要掌握。
- 2019E-Q39(a)：key 示例表的读数为 19.47、19.44、20.34、19.39 mL。20.34 mL 偏离最大，key 的平均 0.01943 L（19.43 mL）与去掉 20.34 后三个值的平均一致。
- 2024E-Q36(b)：把离群值计入平均得 13.81 mL（key 的 "includes outlier" 行），剔除后为 13.74 mL；计入离群值只能拿部分分。
- 2016E-Q42(f) 逆推原样品：稀释与取样两次放大，n(H⁺) × 10 再除以原样品体积 0.100 L。
- 返滴定（2024E-Q36(c)）：n(OH⁻)反应 = n(OH⁻)加入 − n(H⁺)滴定；两个 n 都要写出。此题中 5 片的总 n 要再除以 5，才得到单片的 n（见题型 1 的单位与比例换算）。
- **官方 key 已知问题（2024E-Q36(c)）**：key 正文按 OH⁻ : 阿司匹林 = 1 : 1 计算，得 305 mg/片；key 的注记写道"若采用 2:1 比例，m = 152 mg"。两种结果相差一倍，key 内部不一致。阿司匹林含一个羧基；若同时计入酯基水解消耗的 OH⁻，比例可能为 2 : 1。学生作答时应写明采用的计量比及依据。

**真题**：2016E-Q42(a)、2016E-Q42(c)、2016E-Q42(e)、2016E-Q42(f)、2017E-Q37(c)、2018M-Q13、2018E-Q40(c)、2019E-Q39(a)、2019E-Q39(c)、2020E-Q37(a)、2020E-Q37(b)、2020E-Q37(c)、2021E-Q35(c)、2021E-Q36(a)、2022E-Q34、2022E-Q38(a)、2023E-Q36(b)、2024E-Q36(b)、2024E-Q36(c)、2024E-Q38(b)、2025E-Q38(d)

## 题型 5：经验式与分子式

**识别**：题干出现 empirical formula、molecular formula、combusted、produced … of carbon dioxide and water、% by mass、molar mass、determine the formula。

**步骤**（每种元素单独一行，最后一行为比值）
1. C：n(C) = n(CO₂) = m(CO₂) ÷ 44.01；m(C) = n × 12.01。
2. H：n(H) = 2 × n(H₂O)；m(H) = n × 1.008。
3. N：由中和用酸的 n(H⁺) 得 n(N)（如 2024E-Q38(a) 中 n(N) = n(H⁺)），或由 NO₂ 的质量得（2016E-Q38(c) 用 NO₂，M = 46.01）。
4. S 与卤素：S 由 n(H₂SO₄) 得（2020E-Q38(a)）；卤素由沉淀质量换算（如 n(I) = 2 × n(PbI₂)，2018E-Q35）。
5. O：若样品质量已知，O 由差减求得：m(O) = 样品质量 − Σ m(其他元素)，再 n(O) = m ÷ 16.00。
6. 比值：每个 n ÷ 最小的 n。若得到 1.5、2.5 等半整数，乘以 2 使其成为整数（2024E-Q38(a)：O 比值为 2.5，乘 2 后得 C₂₁H₂₈N₂O₅）。
7. 分子式：由 n(样品) = PV ÷ RT（kPa、L、K）得 M = m ÷ n；再求 M ÷ 经验式量的整数倍，乘以经验式（2017E-Q38(c)、2021E-Q36(b)）。

**得分点（key 的典型写法）**：
- 每个元素的 n 或 m 各计分（2016E-Q38(c) 9 分的 key 逐元素给分）。
- 比值与经验式 1–2 分（2021E-Q36(a) 的 "Mole ratio" 行与最终经验式）。
- 分子式的倍数关系（2017E-Q38(c) 的 "MFM / EFM × EF" 行）。

**易错**：
- 比值为半整数时不乘 2：2024E-Q38(a) 中 10.5 与 2.5 都要乘以 2。
- H 忘记 × 2：n(H) = 2 × n(H₂O)，2016E-Q38(c) 的 key 把这一行单列。
- 氮的来源：2016E-Q38(c) 由 NO₂ 得 n(N)，2021E-Q36(a) 由氨的回滴定得 n(N)；两者不能混用。
- 差减法的单位：样品的 O 由差减时，各质量要统一为 g。
- 比值取整：2022E-Q34 的比值（如 4.25 ÷ 0.328 ≈ 13）是接近整数的结果，要说明为何取整。
- 分子式的整数倍：2017E-Q38(b) 得到 M ≈ 194 g mol⁻¹，与经验式量 97.1 之比约为 2；2017E-Q38(c) 的 key 据此写出分子式，倍数要明确写出。

**真题**：2016E-Q38(c)、2017E-Q38(a)、2017E-Q38(c)、2018E-Q35、2019S-Q30(b)、2020E-Q38(a)、2020E-Q38(b)、2021E-Q36(a)、2021E-Q36(b)、2022E-Q34、2023E-Q37(a)、2023E-Q37(b)、2024E-Q38(a)、2025E-Q39

## 题型 6：气体计算

**识别**：题干出现 gas、vapourised、occupy … L、at … kPa and … °C、STP、volume of … at … °C and … kPa，或用气体数据求挥发性化合物的摩尔质量。

**步骤**
1. 统一单位：压强用 kPa；体积用 L（mL ÷ 1000）；温度用 K，K = °C + 273.15（16.0 °C 为 289.15 K）。
2. 非标况：n = PV ÷ RT，R = 8.314（kPa · L · K⁻¹ · mol⁻¹，与数据手册的 J K⁻¹ mol⁻¹ 等价）。
3. 标况（STP，0.0 °C、100.0 kPa）：n = V ÷ 22.71。数据手册的 STP 压强为 100.0 kPa，不是 101.3 kPa。
4. 由 n 求所需量：V = nRT ÷ P（2016E-Q39(a)），M = m ÷ n（2017E-Q38(b)），或用于求分子式（2021E-Q36(b)）。
5. 有效数字按题型 7 修约。

**得分点（key 的典型写法）**：正确温度换算（K）；n 的表达式与数值；最终体积、摩尔质量或分子式及单位。与其他模式合并时各步分别计分：2016E-Q39(a) 的 7 分中，理想气体方程与温度换算各有一行。

**易错**：
- °C 忘记换算：2016E-Q39(a) 的 key 明确把温度换算计入得分（300.0 °C → 573.15 K）。
- 把 100 kPa 的 STP 当成 101.3 kPa：22.71 L 是 100.0 kPa、0.0 °C 下的摩尔体积。
- 体积单位：2017E-Q38(b) 的 100.0 mL 需先换算为 0.100 L。
- 2024E-Q40(c)：NO 的体积 = n(NO) × 22.71 = 2.57 L；n(NO) 要先由 HNO₃ 的限量计算得到（与题型 2 联动）。
- 2023E-Q37(b)：150 °C 换算为 423.15 K，n = (1.42 × 205) ÷ (8.314 × 423.15)。
- 2020E-Q38(b)：637 mL 换算为 0.637 L，40 °C 换算为 313.15 K，key 得 n = 0.0367 mol。

## 题型 7：有效数字与单位

**识别**：题干出现 appropriate number of significant figures、correct to …、give your answer to …、express in g L⁻¹、reading to the appropriate accuracy、to 2 decimal places。

**步骤**
1. 找出题干数据中有效数字最少的一个（如 2.2 tonne 为 2 位，5.0 L 为 2 位，105 kPa 为 3 位）。若题目单独指定，以题目为准。
2. 中间结果保留 3 位以上，不取整；只在最终答案修约。
3. 按 key 的修约方式对照（同一题型的 key 之间并不完全统一）：2016E-Q39(a) 按 2 位（2.8 × 10⁵ L）；2017E-Q36(b) 按 3 位（4.67 × 10⁶ L）；2019E-Q40(a) 按 2 位（1.4 g L⁻¹，key 注明两位有效数字）；2020E-Q37(c) 按 3 位（19.1%）；2021E-Q37(d) 按 3 位（6.74%）；2022E-Q35(c) 按 3 位（1.07 × 10⁶ g）；2023E-Q35(b) 按 4 位（7.621 × 10⁸ L）；2018E-Q36(c) 要求 4 位（6.792 × 10⁵ g，数据 0.5310 与 0.09100 为 4 位）。
4. 读数：仪器读数要读到合理精度（2017S-Q34(ci)：电压计读数要求保留两位小数，约 1.09 V）。
5. 单位：数值后写出单位，换算到题目要求的单位（g、g L⁻¹、mol L⁻¹、L、kPa）；百分数写 %。
6. pH：小数位按 key 的样式写（2019S-Q32 得 12.1，2024S-Q34 得 12.9，2016E-Q42(f) 得 5.20）。key 之间不统一，以题干和报告要求为准。

**得分点（key 的典型写法）**：有效数字单独计 1 分（2016E-Q39(a)、2017E-Q36(b)、2018E-Q36(c)、2022E-Q35(c) 均有单独一行）；单位正确（如 g L⁻¹，2019E-Q40(a)）。

**易错**：
- 过早取整：2016E-Q42(f) 中 pH 由 6.30 × 10⁻⁶ 得 5.20，若先把 [H⁺] 取成 6.3 × 10⁻⁶ 的两位数，末位会受影响。
- 有效数字与数据不符：电压读数写成 1.1 V，不满足两位小数的要求（2017S-Q34(ci)）。
- 单位链条：tonne、kg、g、mg 混用时数值会错误，有效数字再正确也得不到分（2018E-Q36(c)）。
- 修约要求不统一：多份 key 的修约方式并不一致，应按题目明确的要求作答。

**真题**：2016E-Q39(a)、2017S-Q34(c)(i)、2017E-Q36(b)、2018E-Q36(c)、2019E-Q40(a)、2020E-Q37(c)、2021E-Q37(d)、2022E-Q35(c)、2023E-Q35(b)、2025E-Q37(a)

## 题型 8：沉淀称重分析

**识别**：题干出现 precipitate、filter、wash、dry、weigh、gravimetric、excess silver nitrate（或其他沉淀剂），要求通过称量沉淀测定某离子的质量。

**步骤**（按 key 的顺序）
1. 加入过量沉淀剂（如 AgNO₃）使待测离子（Cl⁻）完全沉淀。
2. 过滤，分离沉淀。
3. 洗涤沉淀，除去可溶杂质。
4. 干燥沉淀至恒重。
5. 称量沉淀，由沉淀质量换算待测离子的质量（n(AgCl) = n(Cl⁻)）。
6. 写出沉淀反应方程式：Ag⁺(aq) + Cl⁻(aq) → AgCl(s)。

**得分点（key 的典型写法）**：2019S-Q30(a) 共 6 分，包括加入过量沉淀剂的描述（1–2 分）、过滤、洗涤、干燥、称量各 1 分，以及沉淀反应方程式 1 分。

**易错**：不写"过量"；只写称量而不写干燥至恒重；漏写方程式；直接把沉淀质量当作待测离子质量。
（证据说明：本模式只有 1 个小题，依据薄弱。）

**真题**：2019S-Q30(a)
