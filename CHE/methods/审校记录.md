# CHE 解题思路 审校记录

**审校方式**：八份讲义由三个写作子代理（Haiku 5.5）依据 `evidence/che/notes/` 的证据包（各题型对应真题的题干、评分 key 给分行、考试报告点评）起草；随后两个独立审校子代理（Haiku 5.5，未参与写作）对照原卷、marking key（文字缺失处渲染原图）、考试报告与数据手册逐条核对并直接改正。两轮共改正 86 处（高 13、中 39、低 34），各题型的「真题」列表与 `tools/parttags_CHE.txt` 逐条一致。

**已知的官方材料问题（讲义中均已中性注明）**：2019E-Q40/Q41 的 key 题头分值与卷面不一致；2019E-Q36(e)–(g) 的 key 为版权占位图；2023E-Q39 题干称乙烯水合为吸热反应（实为放热，key 两种都接受）；2023E-Q37(d) 的 key 与马氏规则的一般预测不一致；2024E-Q36(c) 的 key 正文按 1:1、注记按 2:1；2025E-Q39 的 key 有排印错误。

## 审校 A（01–04）

审校范围：`01_Equilibrium`、`02_Acids_Bases`、`03_Redox_Electrochemistry`、`04_Organic_Structure` 四个文件（可改动范围内）。
审校依据：`evidence/che/label_input/<年份>.json`（stem、key_text、分值）；key 页面用 pymupdf 按 `key_regions` 渲染并读取；考试报告 `CHE/papers/<年份>_CHE_ExamReport.pdf`；数据册 `CHE/papers/2025_CHE_DataBooklet.pdf`；标签 `tools/parttags_CHE.txt`。
页码：key 与报告页码均为 0 起算（与证据 JSON 一致）。严重度：高 = 化学或 key 事实错误，或与 key 相反；中 = key 得分点缺失、考试报告归属错误、数据册归属错误；低 = 表述精确度或补充说明。
