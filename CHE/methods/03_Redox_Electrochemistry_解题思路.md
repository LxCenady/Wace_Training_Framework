## 先记住：阅卷组反复扣分的地方

- **半反应必须“物种对、配平对”两项都要**：key 对每个半反应分别计分（物种正确 1 分，配平正确 1 分）。
- **总反应要真正消去电子**：两个半反应的电子数相等后再相加（2017S-Q27 的 key 中写作 “× 2”）。
- **观察要写颜色和状态**：2020S-Q27、2023S-Q30、2024S-Q27 等题的 key 都要求写出起始与终止的颜色以及气体、固体的状态。
- **电极名称与电子流向**：阳极、阴极、正负极、电子与离子的流向必须同时说清楚（2019S-Q31(a) 的 key 要求两种离子的迁移方向都要标出）。
- **考试报告对本主题的点评**：2021 报告称铁的腐蚀题（2021S-Q31）“answered well, with a mean of 70.4%”，属于稳定得分区；2023 报告称 Question 37（含 2023E-Q37(e)(i) 的离子方程式）“answered well in this section”。两段报告都是整节综述，证据中无更细的题型评价。

## 数据册提供什么（学生在考试中可用的资料）

- **标准电极电势表**（Standard Reduction Potentials at 25 °C，数据册第 8 页）：给出一系列还原半反应及其 E°（从 F₂ 的 +2.89 V 开始，按数值递减排列，直至 K⁺ 的半反应）。学生需要从中取出两个半反应。
- 颜色表：Cu(s) 为鲑鱼粉色（salmon pink）、Cu²⁺ 蓝、Fe²⁺ 浅绿、Fe³⁺ 浅棕、Cr³⁺ 深绿、MnO₄⁻ 紫、Cr₂O₇²⁻ 橙、CrO₄²⁻ 黄、Cl₂(g) 黄绿色（greenish-yellow）、Br₂(ℓ) 红、I₂(s) 灰、I₂(g) 紫；NO₂(g) 为棕色。数据册不列 Br₂(aq)、I₂(aq) 的颜色，水溶液中的橙色与棕色以 key 为准（如 2023S-Q30(c)、2024S-Q27(b)）。
- 溶解性规则：用于判断沉淀（如 Ag⁺ + Cl⁻ → AgCl(s)）。
- 数据册**没有**电解或电池的示意图；装置图通常由题干给出。
- 本次只逐项核对了 2025 版的 E° 表（其中包含 Cr、Mg、Zn、Fe、Cu、Pb、Al、Li 等金属的半反应）；其他版次只抽查了 Kw 与 Ka 的情况。

## 题型 1：氧化数与氧化剂/还原剂

**识别**：「What is the oxidation number of … in …」「identify the atom that is oxidised and the atom that is reduced」「identify the species increasing in oxidation number」「use oxidation numbers to show that this is a redox reaction」「complete the table …」。

**步骤**
1. 运用氧化数规则：单质为 0；单原子离子等于其电荷；化合物中 H 通常为 +1、O 通常为 −2（H₂O₂ 中 O 为 −1）；化合物中各原子的氧化数之和等于电荷。
2. 先算出要求的原子（而不是整个化合物）在反应前后的氧化数。例如 Ca(OCl)₂ 中 Cl 为 +1，HCl 中 Cl 为 −1（2019S-Q28(a)）。
3. 氧化数升高 → 被氧化 → 该物质为还原剂；氧化数降低 → 被还原 → 该物质为氧化剂。
4. 用一个表格或一句话写出：哪一原子被氧化，哪一原子被还原，哪一物种是氧化剂，哪一物种是还原剂。

**得分点（key 的典型写法）**：
✓ 2019S-Q28(a)（2 分）：Ca(OCl)₂ 中 Cl 为 +1；HCl 中 Cl 为 −1。
✓ 2020S-Q30(a)（2 分）：被氧化的原子为 S；被还原的原子为 H。
✓ 2021S-Q31(b)（2 分）：Fe 的氧化数由 +2 升至 +3；O 的氧化数由 0 降至 −2。
✓ 2024S-Q33(a)（3 分）：增加氧化数的物种（SO₂ 中的硫）；氧化数最高的物种（SO₄²⁻ 中的硫）；氧化剂（ClO₃⁻ 中的氯）。
✓ 2025E-Q40(b)（3 分）：每一步中 Se 的初始与终止氧化数，以及该步是氧化还原哪一种（如 −2 → +6，氧化）。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。以下易错点据 key 归纳：
- 写出化合物而不是题目要求的原子。
- 把 H₂O₂ 中的 O 写成 −2，或漏掉氧化数的正负号（须写 +1、−1）。
- 把“被氧化的物质”与“还原剂”混淆（还原剂被氧化）。
- 2021S-Q31(b) 要求 “show that this reaction is a redox reaction”，必须同时写出两个原子的氧化数变化，只写一个不能得满分。

**真题**：2016M-Q13、2016M-Q14、2017M-Q2、2018M-Q7、2019M-Q17、2019S-Q28(a)、2019S-Q28(b)、2020M-Q1、2020M-Q3、2020S-Q30(a)、2021M-Q1、2021S-Q31(b)、2022M-Q2、2023M-Q4、2023M-Q5、2024M-Q2、2024S-Q33(a)、2025M-Q16、2025E-Q38(c)(ii)、2025E-Q40(b)

## 题型 2：半反应与氧化还原方程配平 ★

**识别**：「Write balanced half-equations for the oxidation and reduction reactions and a balanced overall redox equation」「state symbols are not required」「Write the balanced equation for the reaction …」。常见情境：MnO₄⁻ 或 Cr₂O₇²⁻ 氧化醇或醛；卤素与 SO₂；乳酸根离子与硫酸根（2025S-Q33）；燃料电池反应；电解精炼中的电极反应。

**步骤**
1. 标出氧化数变化，确定被氧化与被还原的原子，并写出两个半反应的反应物与产物（物种正确）。
2. 平衡半反应：
   - 先平衡除 O 与 H 以外的原子；
   - 用 H₂O 平衡 O；
   - 用 H⁺ 平衡 H（酸性条件），若题目给出碱性条件则用 OH⁻ 与 H₂O；
   - 用 e⁻ 平衡电荷。
3. 使两个半反应的电子数相等（乘以系数），然后相加。
4. 消去两边共同的 e⁻、H₂O、H⁺（或 OH⁻），检查原子与电荷守恒。
5. 题目给定“酸性条件”时，总反应中不能出现 OH⁻。

**得分点（key 的典型写法）**：
✓ 2024S-Q33(b)（5 分）：还原半反应 MnO₄⁻(aq) + 8H⁺(aq) + 5e⁻ → Mn²⁺(aq) + 4H₂O(ℓ)（物种与配平各 1 分）；氧化半反应 CH₃OH(ℓ) + H₂O(ℓ) → HCOOH(aq) + 4H⁺(aq) + 4e⁻（物种与配平各 1 分）；总反应 5CH₃OH(ℓ) + 4MnO₄⁻(aq) + 12H⁺(aq) → 5HCOOH(aq) + 4Mn²⁺(aq) + 11H₂O(ℓ)（物种与配平各 1 分）。
✓ 2025S-Q33（6 分）：乳酸根氧化半反应 C₃H₅O₃⁻ + 2H₂O → C₂H₃O₂⁻ + HCO₃⁻ + 5H⁺ + 4e⁻（乘 2 后正确）；硫酸根还原半反应 SO₄²⁻ + 10H⁺ + 8e⁻ → H₂S + 4H₂O；总反应 2C₃H₅O₃⁻ + SO₄²⁻ → 2C₂H₃O₂⁻ + 2HCO₃⁻ + H₂S。
✓ 2017S-Q27（6 分）：氧化半反应 SCN⁻ + 4H₂O → SO₄²⁻ + HCN + 7H⁺ + 6e⁻；还原半反应 4e⁻ + IO₃⁻ + 6H⁺ + Cl⁻ → ICl + 3H₂O；总反应（key 允许不写过程，但示例中半反应须先乘以系数 ×2、×3 再相加）。
✓ 2016S-Q27(b)（3 分）：有机产物 戊酸（pentanoic acid）（1 分）与配平的离子方程式（2 分）：Cr₂O₇²⁻ + 3C₅H₁₀O + 8H⁺ → 2Cr³⁺ + 3C₅H₁₀O₂ + 4H₂O。
✓ 2021S-Q31(a)（4 分）：氧化半反应 Fe(s) → Fe²⁺(aq) + 2e⁻；还原半反应 O₂(g) + 4H⁺(aq) + 4e⁻ → 2H₂O(ℓ)；总反应 2Fe(s) + O₂(g) + 4H⁺(aq) → 2Fe²⁺(aq) + 2H₂O(ℓ)。
✓ 2024E-Q39(d)（2 分）：阳极 Pb → Pb²⁺ + 2e⁻；阴极 Cr³⁺ + 3e⁻ → Cr。

**易错点（考试报告）**：2023 报告称 Question 37 “was answered well in this section”，其中包括 2023E-Q37(e)(i) 的离子方程式（RX2 与 ORG6，3 分）。以下易错点据 key 归纳：
- 两个半反应的电子数不等就直接相加（须先乘系数，如 2017S-Q27 中 “× 2”）。
- 酸性条件下用 OH⁻ 或在半反应中用错 H₂O、H⁺ 的位置。
- 电子写在错误的一侧（氧化半反应的 e⁻ 在产物侧，还原半反应的 e⁻ 在反应物侧）。
- 总反应中漏掉 H⁺ 或 H₂O 的消去，导致物种不一致。
- 2021S-Q31(a) 的 key 同时接受两种总反应形式（H⁺ 形式与 OH⁻/H₂O 形式），须与自己写的半反应一致，不能一半用 H⁺、一半用 OH⁻。
- 2019E-Q40 的 key 标注 22 分，与题干小题分值一致（a 9、b 4、c 3、d 6，合计 22）。2019E-Q40(c) 为本题型的一个小题（Fe²⁺ 被 H₂O₂ 氧化的总方程式，3 分：反应物、产物、配平各 1 分）。

**真题**：2016S-Q27(b)、2016E-Q40(a)、2016E-Q40(b)、2017S-Q26(a)(ii)、2017S-Q27、2017S-Q34(a)、2018S-Q28(a)、2018S-Q28(b)、2018S-Q30(d)、2019S-Q28(b)、2019E-Q40(c)、2020E-Q36(c)、2021S-Q27(b)、2021S-Q30(b)、2021S-Q31(a)、2022E-Q37(a)、2023E-Q37(e)(i)、2024S-Q33(b)、2024E-Q39(d)、2025M-Q14、2025M-Q15、2025S-Q33、2025E-Q40(c)

## 题型 3：氧化还原反应方程式与现象 ★

**识别**：「Write balanced equations for any reactions occurring between the following substances and describe the observation(s)」「if there is no reaction, write ‘no reaction’」「describe the contents of the test tubes once any reactions are complete」「combustion of octane in limited oxygen」。常见情境：金属与酸，金属与金属盐溶液，卤素置换（Cl₂、Br₂、I₂），金属与卤素气体，不完全燃烧。

**步骤**
1. 判断是否发生反应：用标准电极电势（题型 4）或金属活泼性（较活泼的金属置换较不活泼的离子）；不反应时按题目要求写 ‘no reaction’ 与 ‘no visible reaction’（2020S-Q27 的写法）。
2. 写出方程式：正确的反应物与产物，配平，并带状态符号（固体 s、液体 ℓ、气体 g、溶液 aq）。
3. 描述现象（起始 → 终止）：
   - 金属溶解、固体消失；
   - 产生无色无味气泡（effervescence）；
   - 溶液颜色变化（用数据册颜色表：Fe²⁺ 浅绿、Cu²⁺ 蓝、Br₂(aq) 橙、I₂(aq) 棕、Cl₂ 黄绿色）；
   - 生成的固体颜色（Cu 鲑鱼粉色、Ni 或 Ag 等）。
4. 不完全燃烧：除 CO₂ 外，还会有碳黑（black solid / soot）或无色 CO，并释放热量、火焰呈橙色（2025S-Q26(b)）。

**得分点（key 的典型写法）**：
✓ 2024S-Q27(a)（4 分）：Mg(s) + 2H⁺(aq) → Mg²⁺(aq) + H₂(g)（物种与配平各 1 分）；观察：灰色固体加入无色溶液，产生气泡，固体溶解消失。
✓ 2024S-Q27(b)（4 分）：Br₂(ℓ) + 2I⁻(aq) → 2Br⁻(aq) + I₂(s) 或 I₂(aq)（物种与配平各 1 分）；观察：红色液体加入无色溶液，形成灰色沉淀或棕色溶液。
✓ 2024S-Q27(c)（4 分）：2Al(s) + 3Ni²⁺(aq) → 2Al³⁺(aq) + 3Ni(s)；观察：灰色固体加入绿色溶液，形成黑色或银色沉淀，溶液颜色变浅。
✓ 2023S-Q30(a)（4 分）：Fe(s) + Cu²⁺(aq) → Cu(s) + Fe²⁺(aq)；观察：起始为灰色铁屑与蓝色溶液；终止时生成鲑鱼粉色固体，溶液褪色变为浅绿色（key 要求起始与终止的颜色都写出）。
✓ 2023S-Q30(c)（4 分）：2Br⁻(aq) + Cl₂(g) → Br₂(aq) + 2Cl⁻(aq)；观察：黄绿色气体通入无色溶液，形成橙色溶液。
✓ 2025S-Q26(a)（5 分）：Cu(s) + Cl₂(g) → CuCl₂(s)（物种、配平、状态符号）；观察：鲑鱼粉色固体与黄绿色气体，表面形成绿色固体，黄绿色气体褪色。
✓ 2025S-Q26(b)（5 分）：2C₈H₁₈(g) + 17O₂(g) → 16CO(g) + 18H₂O(g)；观察：放热、火焰（橙色）；以及黑色固体（碳烟）或无色气体混合（任选一项，须与方程式一致）。只写 CO₂ 与 H₂O 的方程式时，key 最多给 4 分。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。以下易错点据 key 归纳：
- 颜色用错：数据册中 Cl₂(g) 为黄绿色、Br₂(ℓ) 为红色、I₂(s) 为灰色、I₂(g) 为紫色；水溶液的橙色与棕色以 key 为准（如 2023S-Q30(c) 的橙色溶液、2024S-Q27(b) 的棕色溶液）。
- 方程式漏写状态符号，或 I₂ 的状态符号与题目要求不符。
- 写出 CuCl 或其他错误化学式，即使配平也只能得部分分。
- 只写 “colour change” 而不写起始与终止的颜色。
- 不完全燃烧的产物漏掉碳烟或 CO，只写 CO₂。

**真题**：2017S-Q26(a)(i)、2017S-Q26(c)(i)、2017S-Q26(c)(ii)、2019M-Q10、2019M-Q12、2019S-Q26(a)、2020S-Q27、2021M-Q19、2022M-Q22、2022E-Q37(e)、2023S-Q30(a)、2023S-Q30(c)、2024S-Q27(a)、2024S-Q27(b)、2024S-Q27(c)、2025S-Q26(a)、2025S-Q26(b)

## 题型 4：标准电极电势：反应倾向与电池电压

**识别**：「calculate the EMF / potential difference of the cell」「predict whether the reaction will occur spontaneously」「identify the most suitable sacrificial anode using standard reduction potentials」「explain why the measured voltage is lower than the calculated value」「explain why water is not used as the solvent」。

**步骤**
1. 从 E° 表中找出两个半反应：较正的 E° 为还原（阴极），较负的 E° 为氧化（阳极，把它的半反应写反）。
2. E°(cell) = E°(还原, 较正) − E°(还原, 较负)，即 E°(cell) = E°(阴极) + E°(阳极 氧化)。注意每个半反应的 E° 符号。
3. E°(cell) > 0 → 反应自发；E°(cell) < 0 → 不自发，需要外加电压（2024S-Q33(c) 的 key：−1.38 V，不自发）。
4. 选择最强氧化剂：E° 最正的还原半反应中的氧化态物种；最强还原剂：E° 最负的还原半反应中的还原态物种。
5. 若要选择牺牲阳极，选 E° 比铁更负（更易氧化）的金属，如 Zn、Mg、Cr、Mn、Al，并要求与铁电连接（2021S-Q31(d)、2023S-Q27(c)）。
6. 实测电压低于计算值的原因：非标准条件（浓度、压强、温度）、内阻（internal resistance）、超电压（overvoltage）、杂质引起的副反应。
7. 不用水作锂电池的溶剂，因为 Li 的 E° 为 −3.04 V，会与水反应放出 H₂，并放出能量，有爆炸的危险（2025S-Q27(c)）。

**得分点（key 的典型写法）**：
✓ 2017E-Q37(h)（1 分）：1.23 + 0 = 1.23 V（酸性条件）；或 0.4 + 0.83 = 1.23 V（碱性条件）。
✓ 2017S-Q34(c)(ii)（3 分）：由铜的 +0.34 V 与电压表读数推出未知金属的 E°，约为 −0.76 V；参考数据册，Cr（−0.74 V）与 Zn（−0.76 V）都接近；key 以“未知金属生成无色和/或 +2 价离子”为理由选出 Zn，Cr 的常见离子为 +3 价，不符合。
✓ 2020E-Q36(d)（2 分）：电池电压 +2.70 V（须带单位 V）。
✓ 2021S-Q30(c)（2 分）：任意两点，如气体压强高于标准压强、温度不在 25 °C、产生的电能部分转化为热、组件电阻导致的电压降。
✓ 2021S-Q31(d)（2 分）：选出 E° 比铁更负的金属（如 Zn），并说明它的 E° 比铁更负。
✓ 2023S-Q27(c)（4 分）：牺牲阳极比被保护的金属更活泼；金属可为 Zn、Mg、Cr、Mn、Al 之一；两种金属须电连接；阳极的 E° 比铁更负。
✓ 2024S-Q33(c)（4 分）：选 E° 表中的一个物种（key 举例：F⁻(aq)、PbSO₄(s) 或 Cl₂(g)）；写出电压计算（如 +1.51 V − 2.89 V = −1.38 V）；说明电压为负，反应不自发。
✓ 2024E-Q39(e)（2 分）：任意两点，如浓度与温度不处于标准条件、超电压、杂质、内阻（key 注明）。
✓ 2025S-Q27(c)（2 分）：锂与水反应放出 H₂，产生压力或放热导致爆炸的危险（任一项）。

**易错点（考试报告）**：考试报告没有对本题型的专门点评。以下易错点据 key 归纳：
- 把 E°(cell) 写成 E°(还原) − E°(氧化)，或把氧化的半反应 E° 符号写错。
- 计算结果没有单位（须写 V）。
- 实测电压偏差的原因写成 “temperature” 之类的笼统词，没有写出具体影响。
- 选牺牲阳极时选了 E° 比铁更正的金属（如 Cu、Ag、Sn）。
- 2024S-Q33(c) 中忘记说明电压为负、反应不自发。

## 题型 6：电解池与电解应用

**识别**：「electrolytic cell」「an external power supply」「electroplating」「purify copper by electrolysis」「anode mud」「explain why the reaction is non-spontaneous」「label the diagram with the anode, cathode, cation and anion flow and electron flow」。

**步骤**
1. 外加电源驱动非自发反应：阳极（接电源正极）发生氧化，阴极（接电源负极）发生还原。电解池中阳极为正极，阴极为负极（与原电池相反）。
2. 电解精炼铜：粗铜（含 Zn、Fe、Ag、Au 等杂质）为阳极，Cu → Cu²⁺ + 2e⁻；电解质为 CuSO₄(aq)；纯铜为阴极，Cu²⁺ + 2e⁻ → Cu。
3. 杂质去向：比铜活泼的金属（如 Zn、Fe）在阳极溶解但不在阴极析出，留在溶液中；比铜不活泼的金属（Ag、Au）不溶解，沉积在阳极下方，形成阳极泥（anode mud）。
4. 电镀：待镀件作阴极，电解液含镀层金属的离子。2024E-Q39(c) 的装置中，阴极为待镀件（镀 Cr），阳极为 Pb，key 的阳极半反应为 Pb → Pb²⁺ + 2e⁻，阴极半反应为 Cr³⁺ + 3e⁻ → Cr（见题型 2）。
5. 画图：标出阴阳极与电源正负极，电子从阳极经外电路流向电源正极，再从电源负极流向阴极；阳离子移向阴极，阴离子移向阳极。

## 题型 7：实用电池与燃料电池

**识别**：「state whether the battery is primary, secondary or a fuel cell, and justify」「write the half-equation at the positively charged electrode during charging」「list two advantages / disadvantages of fuel cells」「explain the function of the electrolyte」「why is a fuel cell more environmentally friendly」。

**步骤**
1. 分类：一次电池（不可充电，如干电池）；二次电池（可充电，如铅酸电池、锂离子电池）；燃料电池（反应物由外部持续供给，电极本身不消耗）。
2. 充电时，正极（外接电源的正极）发生氧化；放电时正极发生还原。写出题目要求的那一极的半反应（2025S-Q27(b)：正极为 LiCoO₂(s) → CoO₂(s) + Li⁺ + e⁻）。
3. 氢氧燃料电池（酸性条件）：阳极 H₂ → 2H⁺ + 2e⁻，阴极 O₂ + 4H⁺ + 4e⁻ → 2H₂O，总反应 2H₂ + O₂ → 2H₂O（2021S-Q30(b)）。

5. 优点（燃料电池相对一次、二次电池）：反应物连续供给，可持续工作；无记忆效应；电极不消耗；效率高；电压稳定（2017E-Q37(e)）。

## 题型 8：铁的腐蚀与防护

**识别**：「explain why the steel pole rusts below ground but not above ground」「write the equations for the rusting process」「what is a sacrificial anode」「choose a metal for a sacrificial anode using standard reduction potentials」「explain how painting / oiling protects the iron」「chrome plating」。

**步骤**
1. 腐蚀的电化学过程：阳极 Fe(s) → Fe²⁺(aq) + 2e⁻；阴极 O₂(g) + 2H₂O(ℓ) + 4e⁻ → 4OH⁻(aq)（中性或碱性）或 O₂ + 4H⁺ + 4e⁻ → 2H₂O（酸性）。
2. 后续反应：Fe²⁺ 继续被氧化为 Fe³⁺，并生成氢氧化物与 Fe₂O₃·xH₂O（铁锈）；这一步中铁的氧化数由 +2 升至 +3，氧的氧化数由 0 降至 −2（2021S-Q31(b)）。
3. 地下与地上的差异：地下的土壤提供水和离子（电解质），铁的不同部位可以分别作为阳极和阴极，铁本身传导电子；土壤也可能是酸性的（2024E-Q39(a) 的 key 列出这几点，任选两点）。
4. 防护方法：
   - 隔绝（涂漆、涂油或涂脂）：形成屏障，阻止水与氧气接触铁；屏障不完整时仍会锈蚀。
   - 牺牲阳极：与铁电连接的、比铁更活泼（E° 更负）的金属，优先被氧化，保护铁（作为阴极）。
   - 镀层分两类：(1) 屏障型镀层（如锡、镍）比铁更不活泼，靠阻隔水与氧气起作用；镀层破损后，铁与镀层电连接而成为阳极，锈蚀反而加快。(2) 牺牲型镀层（如锌）比铁活泼，破损后先被腐蚀。铬镀层的防护多来自表面致密氧化膜（钝化），这属于补充化学知识，不在 key 中；Cr 本身比铁更活泼（见题型 4）。
5. 牺牲阳极的定义：比被保护金属更容易被氧化、与之电连接的金属，它优先被腐蚀（2021S-Q31(c)）。

**得分点（key 的典型写法）**：
✓ 2021S-Q31(a)（4 分）：氧化与还原半反应（物种与配平）；总反应 2Fe + O₂ + 4H⁺ → 2Fe²⁺ + 2H₂O，或 2Fe + O₂ + 2H₂O → 2Fe(OH)₂（任一种，物种与配平各 1 分）。
✓ 2021S-Q31(b)（2 分）：Fe 的氧化数由 +2 升至 +3；O 的氧化数由 0 降至 −2。
✓ 2021S-Q31(c)（1 分）：牺牲阳极是比被保护金属更易被氧化、并与之电连接的金属。
✓ 2021S-Q31(d)（2 分）：选出 Zn、Mg、Cr、Mn 或 Al 之一（比铁更负）；说明其 E° 比铁更负（更易氧化）。
✓ 2023S-Q27(b)（3 分）：涂油或涂脂；形成屏障；阻止水和氧气接触铁。
✓ 2023S-Q27(c)（4 分）：阳极比被保护金属（阴极）更活泼；金属为 Zn、Mg、Cr、Mn、Al 之一；两种金属须电连接；阳极 E° 比铁更负。
✓ 2024E-Q39(a)（5 分）：任意两点，如氧化与还原可在不同位置发生、铁作为电子导体、土壤可能为酸性（参考方程式 1、2、3）；另可答差异充气（地上氧气充足、地下水分保留）等 key 的“任一项”。需引用至少一个方程式。
✓ 2024E-Q39(b)(i)（2 分）：涂漆形成屏障，阻止水与氧气；屏障不完整（所以仍会锈蚀）。
✓ 2024E-Q39(b)(ii)（3 分）：导线作为导体连接铁与第二种金属；第二种金属应优先被氧化；由于方法失败，第二种金属的活泼性不高于铁（如比铁不活泼，或 E° 更正）。

- 总反应的 OH⁻ 与 H⁺ 形式混用。

**真题**：2017M-Q9、2021S-Q31(a)、2021S-Q31(c)、2021S-Q31(d)、2023S-Q27(b)、2023S-Q27(c)、2024E-Q39(a)、2024E-Q39(b)(i)、2024E-Q39(b)(ii)、2025M-Q7、2025M-Q9
