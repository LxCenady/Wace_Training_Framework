## 题型 1：双向频数表与边际量 ★

**识别**：给出两个分类变量的交叉表，要求补全行列合计、缺失格，或者补全百分比表（complete the two-way table / percentaged table）。

**步骤**
1. 行合计 = 该行各格相加；列合计同理；右下角总数应与两个方向的合计一致，用来核对。
2. 缺失格：由合计倒推（合计减去已知格）。
3. 百分比表先判断方向：按解释变量的分组取百分比，使解释变量每一组的百分比合计为 100%。解释变量在行则用行百分比（每行合计 100），在列则用列百分比（每列合计 100）。key 对行百分比或列百分比的判定正是这一判断（2021F-Q4(c)、2023F-Q1(c)(i)、2024F-Q2(c)(i) 等）。已逐题核对解释变量：2017F-Q5(b) 与 2022F-Q3(b) 的 key 写明年龄为解释变量，年龄放在行，key 用行百分比；2021F-Q4 与 2023F-Q1 的响应变量分别是意见与类别，故年龄为解释变量，key 同样用行百分比；2024F-Q2(b)(i) 的 key 写明购买价格先于投诉设定，为解释变量，价格放在列，key 用列百分比。五张百分比表的 key 判定均与此一致。
4. 每个百分比 = 格频数 ÷ 所在分组合计 × 100。计算器保留足够位数，按题目要求取一位小数或整数。

**得分点（key 的典型写法）**：正确的格数按阶梯给分（至少 2 或 3 个正确、全部正确）；选对行或列百分比本身有分；题目说 show how 时写出分子、分母和计算（2017F-Q5(c)(i)、2022F-Q3(c)(i)）。

**易错**：行列方向选错，整张表的百分比失去意义；分母用了总数而不是分组合计；忘记题目要求的小数位数。

**真题**：2016A-Q11(a)、2016F-Q6(a)、2017F-Q5(a)、2017F-Q5(c)(i)、2017F-Q5(c)(ii)、2018A-Q10(a)、2020F-Q1(b)、2021F-Q4(a)、2021F-Q4(c)、2022F-Q3(a)、2022F-Q3(c)(i)、2022F-Q3(c)(ii)、2023F-Q1(a)、2023F-Q1(c)(i)、2024F-Q2(a)、2024F-Q2(c)(i)、2025F-Q2(a)、2025F-Q2(b)(i)、2025F-Q2(b)(ii)、2025F-Q2(c)（共 20 个子题）。

## 题型 2：分类变量关联的比较描述

**识别**：要求比较两组的百分比，并说明关联（compare the percentages / describe the association / comment）。

**步骤**
1. 取同一解释变量各组的响应百分比（若题目给的是频数，先化为百分比）。
2. 比较：哪一组比例更高或更低，差距多少。
3. 语境化：把类别名称和变量含义写进结论，说清楚方向。
4. 若题目说 comment on，给出「有无关联」与方向两方面。

**得分点**：正确算出所需百分比（2016F-Q6(b)）；陈述关联的方向（2016F-Q6(c)(i)–(iii) 每个比较各 1 分）；用百分比差异来描述（2020F-Q1(c) 的 key 要求引用 (b) 中的百分比差异）。

**易错**：只说「有关联」，不说方向；比较的是频数而不是比例；比较的两组不对应（2016F-Q6(c)(iii) 比较的是 A 与 B、C 合并的部分）。

**真题**：2016F-Q6(b)、2016F-Q6(c)(i)、2016F-Q6(c)(ii)、2016F-Q6(c)(iii)、2017F-Q5(d)、2020F-Q1(c)、2021F-Q4(d)、2022F-Q3(d)、2023F-Q1(c)(ii)、2024F-Q2(c)(ii)、2025F-Q2(d)(i)、2025F-Q2(d)(ii)（共 12 个子题）。

## 题型 3：散点图与数值关联特征

**识别**：要求在散点图上描点、标注坐标轴，或者描述两个数值变量的关系（direction、form、strength）。

**步骤**
1. 作图：先看刻度（读刻度是反复出现的失分点，2017、2022 报告），按题目指定的轴描点，两轴都要标注变量名。
2. 描述关联时按三个要素写：方向（正或负）、形态（线性或非线性）、强弱。
3. 形态明显弯曲时，直接指出是非线性（2017A-Q12(d)）。

**得分点**：每个正确描的点各有分（2018A-Q15(a)：两个点各 1 分；2020F-Q4(a)：至少 3 点、全部点；2017A-Q12(a)：2 点、3 点）；坐标轴标注（2016A-Q8(b)）；描述同时给出强弱和形态（2018F-Q3(a)）。

**易错**：未标注轴；刻度读错；只说「正相关」而不说强弱；把弯曲关系误说成线性。

**真题**：2016A-Q8(b)、2016A-Q8(c)、2017A-Q12(a)、2017A-Q12(b)、2017A-Q12(d)、2018A-Q15(a)、2018F-Q3(a)、2020F-Q4(a)、2021A-Q9(b)、2022A-Q11(a)、2022A-Q11(c)、2023A-Q7(b)、2023A-Q7(d)、2024A-Q11(b)、2025A-Q9(b)（共 15 个子题）。

## 题型 4：相关系数的计算与解释 ★

**识别**：题目用 calculate、state、describe、explain 等命令词，要求计算或写出 r、描述方向与强度，或解释 r 的意义。

**步骤**
1. 用计算器的两变量统计模式输入全部数据，读出 r（同时可读出回归方程和 r²）。
2. 符号：r 与最小二乘直线的斜率同号。若只给出 r²，r = ±√r²，符号由斜率决定（2024A-Q11(a)：key 要求同时求出 r² 与 r，并接受负值）。
3. 描述：方向（正或负）+ 强弱（用题目给的 r 数值）+ 线性（linear）。本卷证据中，r ≈ −0.6 的 key 写作 moderate（2020F-Q4(b)）；r = 0.814、0.97 写作 strong（2023A-Q7(d)、2017A-Q9(a)(iv)）。
4. 解释题（in context）：说出两个变量的名称，并说明 r 只描述线性关联的强弱和方向。

**得分点**：r 的数值（单独 1 分，如 2021A-Q9(e)(i)）；方向与强弱各 1 分（2021A-Q9(e)(iii)、2022A-Q11(d)）；解释题要同时提到两个变量（2022A-Q13(b)）。

**易错**：把 r² 当作 r；丢掉负号（2023A-Q10(g) 要求解释为什么 r 为负，需说明平方根与斜率的关系）；把 r 说成「导致」（见题型 9）；2017A-Q12(c) 这类「选出最可能的 r」题要同时看图像的方向和离散程度。

**真题**：2016A-Q8(c)、2016A-Q8(f)(i)、2017A-Q9(a)(iv)、2017A-Q12(c)、2018A-Q15(b)(i)、2018A-Q15(b)(ii)、2020A-Q10(a)、2020F-Q4(b)、2021A-Q9(e)(i)、2021A-Q9(e)(ii)、2021A-Q9(e)(iii)、2021F-Q7(d)、2022A-Q11(b)、2022A-Q11(d)、2022A-Q13(b)、2023A-Q10(a)、2023A-Q10(g)、2023A-Q10(h)、2024A-Q11(a)、2024A-Q11(c)、2025A-Q9(c)、2025A-Q9(g)、2025F-Q5(f)（共 23 个子题；其中 2023A-Q10(h) 与 2025A-Q9(g) 的内容分别归入题型 8 和题型 16）。

## 题型 5：最小二乘回归线与残差检查 ★

**识别**：要求求最小二乘方程（determine），或在散点图上画最小二乘线（draw）。

**步骤**
1. 计算器做线性回归，读出截距和斜率。
2. 方程格式：用题目给的变量（例如题目用 w、v 时就写 w 与 v；2023 报告要求这一点）。按题目要求取位数（如 one decimal place，2016A-Q8(d)(i)）。
3. 画线：取 x 的两个值（通常取数据范围的两端）算出 y，描两点后用直尺连线。key 检查：线经过的近似点（如 2022A-Q11(c) 的 (28, 29)）和斜率方向是否正确。
4. 若同一题还要求 r，两者都写（2018A-Q15(b)(i)、2023A-Q10(a)）。

**得分点**：方程的斜率与截距各有分（2016A-Q8(d)(i)）；画线的两点正确并标明（2016A-Q8(d)(ii)）；画线时经过近似点且斜率正确（2022A-Q11(c)、2023A-Q7(c)）。

**易错**：截距与斜率写反；变量名不用题目给的；画线只描一点或没有标明用来画线的两点；直线没用直尺。

**真题**：2016A-Q8(d)(i)、2016A-Q8(d)(ii)、2017A-Q9(a)(i)、2018A-Q15(b)(i)、2020A-Q10(b)、2021A-Q9(c)、2021A-Q9(g)(ii)、2022A-Q11(b)、2022A-Q11(c)、2023A-Q7(c)、2023A-Q10(a)、2023A-Q10(f)、2024A-Q11(d)、2024A-Q11(i)、2025A-Q9(c)、2025A-Q9(d)、2025F-Q5(c)（共 17 个子题）。

## 题型 6：回归斜率与截距的语境解释

**识别**：要求解释斜率（gradient）或截距，或说明截距为什么没有实际意义。

**步骤**
1. 斜率：x 每增加 1 个单位（写明单位），y 平均增加（为正）或减少（为负）斜率的绝对值，并写出两个变量的名称与单位。
2. 截距：x = 0 时的预测值。若 x = 0 在语境中不现实或超出范围，说明截距没有实际意义（2024A-Q11(f)）。
3. 说法统一写成平均变化或预测值，不写成确定的变化。

**得分点**：方向（增加或减少）与数值、单位各有分（2018F-Q3(c)(i)：方向 1 分，数值与单位 1 分；2024A-Q11(e)：减少 0.38 kg 的写法）；两个变量都要出现（2016A-Q8(d)(iii)、2021A-Q9(d)）。

**易错**：斜率为负时写成 increase（2024A-Q11(e) 的 key 要求写 decrease）；漏写单位；只写「每增加一个单位」而不说明 x 的单位（2020A-Q10(c) 要求 per 1 cm 的表述）。

**真题**：2016A-Q8(d)(iii)、2017A-Q9(a)(iii)、2018A-Q15(b)(iii)、2018F-Q3(c)(i)、2020A-Q10(c)、2021A-Q9(d)、2022A-Q13(a)、2023A-Q10(b)、2023A-Q10(i)、2024A-Q11(e)、2024A-Q11(f)、2025A-Q9(e)（共 12 个子题）。

## 题型 7：决定系数与解释变异

**识别**：要求计算决定系数 r²，或问变异中有多大比例可以被解释、多大比例未被解释。

**步骤**
1. r² = r 的平方；写成百分数时乘以 100%。
2. 2. 解释：说明约 x% 的 y 的变异可由 x 的线性关系解释，其余为未解释部分，并说明语境中的变量名。
3. 反向题：已知未解释比例时，r² = 1 − 未解释比例，再由 r² 求 r（符号看斜率，见题型 4）。例如 2024A-Q11(a)：由「51% 无法解释」得到 r² 对应的数值，再求 r。
4. 已知 r 求 r²，或已知解释比例求 r（2018F-Q3(b)）。

**得分点**：r² 或百分比正确（如 2016A-Q8(e) 的计算与解释各有分）；语境中的解释（2020F-Q4(d)、2023A-Q7(e)）；未解释比例（2020A-Q10(f) 的 key 单独计分）。

**易错**：把百分比与小数混用；把「解释」与「未解释」混淆；只写数值不写语境；求 r 时忘记符号。

**真题**：2016A-Q8(e)、2017A-Q9(a)(v)、2018A-Q15(b)(iv)、2018F-Q3(b)、2020A-Q10(f)、2020F-Q4(c)、2020F-Q4(d)、2021A-Q9(f)、2022A-Q11(e)、2023A-Q7(e)、2024A-Q11(a)、2025A-Q9(i)（共 12 个子题）。

## 题型 8：线性模型预测与外推判断 ★

**识别**：要求预测（predict）、用方程估计、评论预测的有效性，或问预测是否可靠。也包括反向题：已知预测值求原始变量（2023A-Q10(e)）。

**步骤**
1. 代入：把题目给的 x 代入回归方程。注意变量编码，如 n = 25 代表某一年（2025F-Q5(a)）。
2. 判断范围：x 在观测数据范围内为 interpolation，范围外为 extrapolation。
3. 结合 r 的强弱：范围内且 r 强，预测可靠（2016A-Q8(f)(i)、2022A-Q13(c)(ii)、2025F-Q5(b)）；范围外，预测不可靠（2018F-Q3(c)(ii)、2020A-Q10(g)(ii)、2022A-Q11(g)(ii)、2024A-Q11(h)）。
4. 有多个预测变量时，选 r 最强者作为预测依据，并说明理由（2023A-Q10(h)）。
5. 预测值与表中的实际值不同：用残差或模型的不完美解释（2025A-Q9(f)(ii)）。
6. 解释外推为什么没有意义，通常要结合语境（2021A-Q9(h)、2025A-Q9(f)(iii)）。

**得分点**：代入的计算正确（每个预测值 1 分）；结论是有效或无效，加上理由，理由包括范围判断（interpolation 或 extrapolation）和 r 的强弱（2020F-Q4(f)：r 为中等强度时，结论写成可能不有效）。

**易错**：判断范围时用了 r 而不是 x 的取值；只写不有效而不写外推（extrapolation）；在 r 只是中等时仍写成可靠；代入时没有统一变量编码。

**真题**：2016A-Q8(f)(i)、2016A-Q8(f)(ii)、2017A-Q9(a)(ii)、2018A-Q15(d)、2018F-Q3(c)(ii)、2020A-Q10(g)(i)、2020A-Q10(g)(ii)、2020F-Q4(e)、2020F-Q4(f)、2021A-Q9(g)(i)、2021A-Q9(h)、2022A-Q11(g)(i)、2022A-Q11(g)(ii)、2022A-Q13(c)(i)、2022A-Q13(c)(ii)、2023A-Q10(e)、2023A-Q10(h)、2024A-Q11(g)、2024A-Q11(h)、2025A-Q9(f)(i)、2025A-Q9(f)(ii)、2025A-Q9(f)(iii)、2025F-Q5(a)、2025F-Q5(b)（共 24 个子题）。

## 题型 9：关联、因果与混杂解释

**识别**：要求判断某个陈述是否正确、给出非因果解释、指出其他因素，或判断是否有证据支持因果。

**步骤**
1. 核心观点：观察到的关联，即使 r 很强，也不能单独证明因果。
2. 常见的非因果解释：第三个变量（混杂因素）同时影响两个变量；因果方向反过来；巧合。
3. 对“X 导致 Y”这类因果陈述：说明统计关联不等于因果，并给出一个可能的其他因素（2022A-Q11(f)）。
4. 对异常点：给出实际中的可能解释（2022A-Q13(f)）。

**得分点**：判断陈述不成立（2017A-Q12(e)、2021A-Q9(i)、2023A-Q10(j)）；理由写出「可能有其他因素」（2020F-Q4(g)）；给出具体的非因果解释（2018F-Q3(d)）。

**易错**：因为 r 强就说因果；理由过于笼统，没有结合语境说出具体因素；2 分题只写相关不等于因果，没有说明语境。

**真题**：2017A-Q12(e)、2018F-Q3(d)、2020F-Q4(g)、2021A-Q9(i)、2022A-Q11(f)、2022A-Q13(f)、2022A-Q13(g)、2023A-Q10(j)、2025A-Q9(h)（共 9 个子题）。

## 题型 11：解释变量与响应变量识别

**识别**：要求识别解释变量（explanatory）或响应变量（response），或说明某个看法为什么不正确。

**步骤**：先读题目的研究问题（如「用 … 解释 …」「预测 …」）。解释变量是用来解释或预测的变量，响应变量是被解释或被预测的结果。若题目涉及时间先后或变量是人为设定的（如价格由商家定），需要说明理由（2024F-Q2(b)(i)）。

**得分点**：变量名与题干一致；用于百分比表时，解释变量决定百分比的方向（见题型 1）。

**易错**：两者倒置；只写 age 而不写完整的变量名；忽略题目给出的因果方向。

**真题**：2016A-Q8(a)、2017F-Q5(b)、2020F-Q1(a)、2021A-Q9(a)、2021F-Q4(b)、2022F-Q3(b)、2023A-Q7(a)、2023F-Q1(b)、2024F-Q2(b)(i)、2024F-Q2(b)(ii)、2025A-Q9(a)（共 11 个子题，每个 1 分）。

## 题型 12：多分类数据表中的率值筛选与比较

**识别**：要求找出哪个州、年龄组或性别的率最高，或把某一类的率与其他类比较。表格维度多，要求检索最大或最小的率。

**步骤**
1. 在多维表中先确定比较的基准（如某一维度的合计），再计算或读取各格的百分率。
2. 逐个维度检索（性别、年龄、州），每一层都确定。
3. 比较时用率，不用人数（2018A-Q10(b)：先取分子，再算各州的百分比）。
4. “几乎最低”或“唯一的例外”这类说法要对照其余组逐一核对（2016A-Q11(d)）。

**得分点**：每个维度的正确类别各 1 分（2016A-Q11(b) 有三个维度）；比较结论指出例外（2016A-Q11(d)）；比较两州的百分比差异（2018A-Q10(b)）。

**易错**：比较人数而不是率；漏掉比较的基准组。

**真题**：2016A-Q11(b)、2016A-Q11(c)、2016A-Q11(d)、2018A-Q10(b)、2018A-Q10(c)、2018A-Q10(d)（共 6 个子题，2 道题）。（待复核（标注）：2018A-Q10(c) 要求描述两类车型销量数量的关联，key 只给 1 分，结论是乘用车销量始终多于运动型车，不涉及百分率。目录规定题目明确讨论关联时另标 BIV2，该子题只带 BIV12；是否补标 BIV2 待标注复核，本笔记未改标签。）

## 题型 14：残差计算

**识别**：要求计算残差，或求缺失的残差。

**步骤**
1. 残差定义：残差 = 观测值 − 预测值（与 catalogue 的定义一致）。
2. 预测值 = 把解释变量的取值代入最小二乘方程。
3. 检查符号：残差为负，说明观测值低于预测值（2020A-Q10(h) 的 key 要求说明「低于预测」）。
4. 残差可以直接用于画残差图（题型 15）。

**得分点**：每个残差各 1 分（2017A-Q9(b)(i) 的 C 与 D 各 1 分；2024A-Q11(j) 的 key 依次给第一个缺失残差、第二个缺失残差和作图）；解释残差的含义时说明实际值相对预测值的高低（2020A-Q10(h)）。

**易错**：残差的方向写反（预测减观测）；代入方程时变量用错；解释残差只说高或低而不说明相对于预测值。

**真题**：2017A-Q9(b)(i)、2018A-Q15(c)(i)、2020A-Q10(d)、2020A-Q10(h)、2021F-Q7(a)、2022A-Q13(d)、2023A-Q10(c)、2024A-Q11(j)、2025F-Q5(d)（共 9 个子题）。

## 题型 15：残差图绘制

**识别**：要求在图上描出残差，或补全残差图。

**步骤**
1. 横轴为题目指定的解释变量（如年龄、价格、年份、残差对应的 x），纵轴为残差。
2. 画出零线（残差 = 0）作为参照。
3. 按刻度描点，负的残差画在零线下方。读刻度时要仔细（2017、2022 报告）。

**得分点**：每个残差点正确（2021F-Q7(b)：两个残差各 1 分；2022A-Q13(d)：至少一个、至少三个、全部点）；残差是由前一题算出的值（2025F-Q5(d) 要先算预测值再算残差）。

**易错**：横轴选错；负残差画在零线上方；刻度读错。

**真题**：2017A-Q9(b)(ii)、2018A-Q15(c)(i)、2020A-Q10(d)、2021F-Q7(b)、2022A-Q13(d)、2023A-Q10(c)、2024A-Q11(j)、2025F-Q5(d)（共 8 个子题）。

## 题型 16：用残差图诊断线性模型

**识别**：要求用残差图判断线性模型是否合适，问哪一特征说明模型合适，或论证最小二乘线是否是好的模型。

**步骤**
1. 看残差是否有系统模式：残差随机分布在零线两侧、没有明显趋势，线性模型合适（2020A-Q10(e)）。
2. 残差呈曲线、漏斗形或有明显的趋势，线性模型不合适（2017A-Q9(b)(iii)、2025F-Q5(e)）。
3. 结论要有依据：写出残差的模式本身，而不只是给结论。
4. 与 r 配合时，r 的数值要和残差模式一起考虑（2021F-Q7(c) 的 key 给出了模式不合适的理由）。

**得分点**：结论正确（合适或不合适）；依据正确（写出没有模式或有模式）。

**易错**：只写不合适而不写残差模式；用 r 的大小代替残差图的依据（2021F-Q7(d) 的 key 把 r 的大小作为另一个依据，两者要分开写）。

**真题**：2017A-Q9(b)(iii)、2018A-Q15(c)(ii)、2020A-Q10(e)、2021F-Q7(c)、2022A-Q13(e)、2023A-Q10(d)、2025A-Q9(g)、2025F-Q5(e)（共 8 个子题）。
