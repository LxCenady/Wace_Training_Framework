## 题型 1：等差数列递推生成

**识别**：题目描述「每期增加（或减少）固定量」，要求写出递推关系（recursive rule）或由递推规则算出前几项。

**步骤**
1. 确认是等差：相邻两项之差是同一常数 d。
2. 递推式：T_{n+1} = T_n + d（减少时 d 为负数），同时写出初值（按题目的下标，T_0 或 T_1）。
3. 逐项计算：从初值出发，用递推式向后算。

**得分点**：d 的数值和符号各有分；初值与下标一致（2024F-Q1(a)(i) 的 key 分别给「公差」和「T_0」）；递推式写完整（2021F-Q6(a)、2023F-Q3(a)）；逐项计算正确（2016F-Q4(b)(i) 的 key 分别给第 2 项和第 3 项）。

**易错**：下标从 0 还是从 1 与题目不一致；d 的符号写反；只写递推式而漏掉初值。

**真题**：2016F-Q4(b)(i)、2017F-Q1(a)、2021F-Q6(a)、2022F-Q2(a)(i)、2023F-Q3(a)、2024F-Q1(a)(i)、2025A-Q6(a)、2025F-Q1(a)（共 8 个子题）。

## 题型 2：等差数列通项与项数预测 ★

**识别**：要求推导第 n 项的规则（deduce a rule for the nth term），判断是哪一项，或问何时首次达到某个值、需要多少周或年。

**步骤**
1. 由公差 d 和第一项（或截距）写出通项：常用形式为 T_n = dn + c，或 T_n = a + (n − 1)d（与题目下标匹配）。key 的典型写法是说明斜率（gradient）为 d、纵截距（vertical intercept）为 c（2017F-Q1(b)(i)）。
2. 令 T_n 等于题目给的阈值，解出 n。
3. 取整：题目问「第一个小于…的项」时，取满足条件的最小整数 n（2017F-Q1(b)(ii) 的 key 给出的是第 171 项，过程是先解不等式再取整）。问「何时」时同理取整数期。
4. 单位统一：每日变化换算为每周（×7）（2017A-Q10(f)）。
5. 分段：如果中途增量改变（如公司从某月起加薪），分两段计算，第二段从变化点的项开始重新递推（2023F-Q3(c)、(d)）。

**得分点**：通项的两个系数各有分（2020A-Q7(b)：常数项与 n 的系数）；求项数与项值（2017F-Q1(b)(ii) 分三步：不等式、项数、项值）；结论写成完整语句，写明经过了多少年（2022F-Q2(c)）。

**易错**：项数四舍五入而不是取整进一；把「第 n 项」与「第 n 周」或起始点混淆（例如第 12 个月与第 11 项）；分段后仍然用原来的公差。

**真题**：2016F-Q4(c)、2017A-Q10(f)、2017F-Q1(b)(i)、2017F-Q1(b)(ii)、2020A-Q7(a)、2020A-Q7(b)、2020A-Q7(c)、2021F-Q1(a)、2021F-Q1(b)、2021F-Q1(c)、2021F-Q6(d)、2022F-Q2(a)(ii)、2022F-Q2(b)、2022F-Q2(c)、2023F-Q3(b)、2023F-Q3(c)、2023F-Q3(d)、2024F-Q1(a)(ii)、2024F-Q1(b)、2024F-Q1(c)、2024F-Q1(d)、2025F-Q1(c)、2025F-Q1(d)（共 23 个子题）。

## 题型 3：等差模型表格与离散图像

**识别**：要求把前若干项填入表格，或把前若干项画成离散点（display the first terms / complete the table）。证据中只有 2 个子题，本节从简。

**步骤**：按递推或通项算出前几项，填表；作图时只描点、不连线（数列是离散的），标注坐标轴和刻度。

**得分点**：至少两个点正确、全部点正确（2017F-Q1(a)）；表格全部正确（2025F-Q1(b)）；坐标轴标注清楚。

**易错**：把离散点连成直线或曲线；刻度读错（2017、2022 报告）。

**真题**：2017F-Q1(a)、2025F-Q1(b)（共 2 个子题）。

## 题型 4：等比数列递推生成

**识别**：题目描述「每期乘以固定比例」或「每期减少（增长）x%」，要求写出递推关系或逐项计算。

**步骤**
1. 公比 r：减少 x% 时 r = 1 − x%，增长 x% 时 r = 1 + x%（如减少 14% 对应 0.86）。
2. 递推式：T_{n+1} = r·T_n，同时写出初值（按题目下标）。
3. 由数据求 r：相邻两项之比（2021A-Q11(b)(i) 的 key 要求先算出比值）。
4. 取整：题目要求取整（如 nearest dollar，2016A-Q7(a)）时，按要求取整；中间步骤不要过早取整。

**得分点**：递推式与初值各有分（2016F-Q4(a)(i)、2018F-Q7(a)：公比、递减的几何递推式、初值分别给分）；由数据求比值（2021A-Q11(b)(i)）；题目指定的起点要写清楚（2023A-Q13(c) 的 key 单独给 T_0 一分）。

**易错**：把减少率直接当作公比（写成 0.14 而不是 0.86）；把递推的初值取在错误的时刻；忘记题目要求的取整。

**真题**：2016A-Q7(a)、2016F-Q4(a)(i)、2016F-Q4(b)(ii)、2018F-Q7(a)、2020A-Q8(a)、2021A-Q11(b)(i)、2022A-Q9(b)、2023A-Q13(c)（共 8 个子题）。

注：2016F-Q4(b)(ii) 给出的是 T_{n+1} = 1.5T_n 与 T_2 的值，要求前三项，因此需要从已知项反推前一项（T_n = T_{n+1} ÷ 公比）。

## 题型 5：等比数列通项与增长衰减预测 ★

**识别**：给出固定比例的增长或衰减，要求通项、某一时刻的值、何时达到某个阈值，或者解释增长率。证据中有 39 个子题，是本主题最常见的题型。

**思路与步骤**
1. 通项：T_n = a·r^n（或 a·r^(n−1)，按题目下标）。系数 a 是初值，底数 r 是公比（key 分别给分，2016A-Q7(c)、2024A-Q7(c)）。
2. 由公比求年化或期间的变化率：r = 0.85 表示每期减少 15%，平均变化率为 1 − r（2016A-Q7(b)；2018A-Q14(b) 先由终值比求出比值，再化为百分数）。
3. 求某一期的值：代入通项，按题目要求取整（2016A-Q7(d)：取到最接近的美元）。
4. 求 n（何时首次达到某一值）：解指数方程（计算器的 solve 或对数），再取满足条件的最小整数期，并写出结论（2016A-Q7(e)：key 要求写明在第 5 年末出售；2017A-Q10(c)：在第 6 周；2023A-Q13(e)：首次低于 5000 的时刻）。
5. 分段增长率：前一段与后一段用不同的 r，逐段计算，第二段从第一段末的值起算（2017A-Q10(d)；2023A-Q13(a)(i) 的 key 写出逐年乘以不同的因子）。
6. 平均增长率：先按平均变化率算出一段时间后的值，再列方程求后一段的 r（2021A-Q12(c)：key 依次给三分：用平均率算出第 6 年末的值、列方程、求出 r）。
7. 精确形式：题目要求 exact 或分数时，保留分数形式（2016F-Q4(a)(ii) 要求以分数作答；2018F-Q7(c) 要求给出精确值并写出化简过程）。
8. 离散对象取整：人数、鱼数等要取整数（2022A-Q17(b)：key 要求取整数值）。
9. 反推系数：给出较多数据时，用两项之比求 r，再写出 T_n（2021F-Q6(b)）。

**得分点**：通项的系数和底数各 1 分（2016A-Q7(c)）；求值后按题目要求取整（2016A-Q7(d)）；结论语句写明何时（2016A-Q7(e)）；分段时逐段写出（2017A-Q10(d) 分三步：8 周后的值、新增长率的方程、总周数）；题目要求证明时，每个化简步骤都要写出（2018F-Q7(c)）。

**易错**：r 与 1 − r 混淆（用 0.15 代替 0.85，或反过来）；指数的起点（n 从 0 还是 1）与题目不一致；n 用四舍五入而不是取整进一；分段后第二段用错起始值；最后忘了取整或没有按题目的精确要求作答。

**注意**：2022A-Q9(a) 要求解释「1200 × (0.86)^n 为什么是 n 周后的人口」，key 接受的论证包括：14% 减少等于原来的 86%，且 1200 为初始人口；同时另有一种替代论证：若 0.86 对应的是按年的变化，式子就不是周数的表达式。（已核对：题干写的是「每年减少 14%」，key 的主解却按每周减少处理（r = 0.86，初值 1200）；替代解指出，若按年变化，该式表示的是 n 年后的人口，而非 n 周。）

**真题**：2016A-Q7(b)、2016A-Q7(c)、2016A-Q7(d)、2016A-Q7(e)、2016F-Q4(a)(ii)、2017A-Q10(a)、2017A-Q10(b)、2017A-Q10(c)、2017A-Q10(d)、2017A-Q10(e)、2018A-Q14(b)、2018F-Q7(b)、2018F-Q7(c)、2020A-Q8(b)、2020A-Q8(c)、2021A-Q11(a)(i)、2021A-Q11(a)(ii)、2021A-Q11(b)(ii)、2021A-Q12(a)、2021A-Q12(b)、2021A-Q12(c)、2021F-Q6(b)、2022A-Q9(a)、2022A-Q9(c)、2022A-Q17(a)、2022A-Q17(b)、2022A-Q17(c)、2023A-Q13(a)(i)、2023A-Q13(a)(ii)、2023A-Q13(b)、2023A-Q13(d)、2023A-Q13(e)、2024A-Q7(a)、2024A-Q7(b)、2024A-Q7(c)、2024A-Q7(d)、2024A-Q7(f)(i)、2025A-Q6(c)、2025A-Q6(d)（共 39 个子题）。

## 题型 6：一阶线性递推逐项计算与呈现

**识别**：递推式形如 T_{n+1} = aT_n + b（既有乘数又有固定加减量），要求逐项计算、列表或作图（display / graph the values）。

**步骤**
1. 确定 a、b 与初值 T_0。
2. 从初值逐项代入，注意题目问的是「第几周开始时」，它对应的项的下标要核对。
3. 作图时按题目指定的间隔取点（如每 5 年取一点，从 n = 5 开始），描点后看趋势。
4. 由三个连续项反求 a、b：代入 T_{n+1} = aT_n + b 得到两个方程，联立解出（同题型 8 的 2025A-Q6(f)）。

**得分点**：逐项数值正确（2025F-Q1(e)(i)；2018A-Q9(b) 见下方注）；作图时点正确并覆盖题目指定的所有点（2017A-Q16(b)：至少两个点，全部点）；参数 c 或 k 的值（2018A-Q9(d)(i)）。

**易错**：下标错位（例如把「第五周开始时」对应到错误的项）；作图时横轴间隔不是题目要求的间隔。

**真题**：2017A-Q16(b)、2018A-Q9(b)、2018A-Q9(d)(i)、2018A-Q9(d)(ii)、2024A-Q7(e)、2025F-Q1(e)(i)（共 6 个子题）。（2024A-Q7(e) 的 b = 100，见题型 8。）

**注（2018A-Q9(b)）**：题干递推式 M_{n+1} = 0.9(M_n − 12) + 15，M_1 = 50，逐项计算第五周为 47.249，取整约 47。key 自己的计算表也列出 47.249，但文字答案写 48，与表格不符。本笔记以 47 为准，key 的 48 记入审校记录。

## 题型 7：递推长期趋势与稳定值

**识别**：题目问长期行为、稳定状态（steady state）、长期会不会耗尽，或是否可持续。

**步骤**
1. 稳定值 S 满足 S = aS + b，所以 S = b ÷ (1 − a)。使用前要确认 |a| < 1，否则数列不收敛。
2. 维持稳定所需：每期取出或补充的量等于在稳定值下增长的量（2020A-Q8(d) 与 2018A-Q9(e) 都是这类题）。
3. 判断「会不会耗尽」或「能否达到某个水平」：比较稳定值与题目给的阈值（2024A-Q7(f)(ii)、2025F-Q1(e)(ii)）。
4. 结论要写出稳定值的数字，并和题目条件对照，不能只写「会」或「不会」。

**得分点**：列出稳定态方程（2017A-Q16(d)，key 要求写出稳态方程）；求得稳定值并取到最接近的整数（2017A-Q16(d)）；判断维持所需的取出量时，向下取整（2020A-Q8(d)：key 要求对鱼数取整，且取整的方向是向下）；2022A-Q9(d) 写出稳定的数量（2400 只企鹅）；2024A-Q7(f)(ii) 比较稳定值与 8.5 百万的目标。

**易错**：稳态方程写错（把 T_n 与 T_{n+1} 写成不同的未知量，或忘记把 b 带入）；不检验收敛性；取整的方向错误。

**真题**：2017A-Q16(c)、2017A-Q16(d)、2018A-Q9(c)、2018A-Q9(e)、2020A-Q8(d)、2022A-Q9(d)、2024A-Q7(f)(ii)、2025F-Q1(e)(ii)（共 8 个子题）。

**2018A-Q9(c) 已核对**：(c) 沿用题干开头给出的模型 M_{n+1} = 0.9(M_n − 12) + 15，稳态 M = 0.9(M − 12) + 15，解得 M = 42，key 的 42 正确。N_{n+1} = 0.8(N_n − 12) + 15 的稳态解为 27，出现在 (d)(ii)，key 写 27 也正确。两个模型不能混用：问 (c) 时用的是 M 的模型（0.9），不是 N 的模型（0.8）。

## 题型 8：递推关系建立与情境分析

**识别**：情境题给出「每期的变化规律」，要求建立递推模型（write a recursive rule for …）、解释其中的系数（interpret the coefficient）、或比较两个方案（explain which program …）。

**步骤**
1. 把每期的变化拆成两部分：比例变化（乘数，保留比例 = 1 − 损失率，或 1 + 增长率）和固定增减（加或减一个常数）。
2. 写出 T_{n+1} = aT_n + b，并写出初值 T_0（题目给出的时刻）。
3. 解释系数：a 表示每期保留的比例，b 表示每期固定增加的数量，要结合题目语境写出（2017A-Q16(a)(i)、2024A-Q7(f)(i)；后者在标签中只带 SEQ5，见审校记录）。
4. 分析：列出迭代值或作图，看趋势；比较方案时给出理由（2021F-Q6(c) 要求说明为什么选择某一方案）。
5. 由给出的数据反求 a、b：取三个连续项，列出两个方程（2025A-Q6(f)）。

**得分点**：a、b 各 1 分（2024A-Q7(e)）；解释系数时同时说明「每期」和变化的内容（2024A-Q7(f)(i)）；2017A-Q16(a)(ii) 单独要求写出 b 的值。

**易错**：把保留率（a）与衰减率（1 − a）混淆；b 的单位与 T 的单位不一致；做方案比较时只给结论，没有理由。

**2024A-Q7(e) 已核对**：key 为 a = 0.986、b = 100。a 由衰减率从 3% 变为 1.4% 得到（1 − 1.4% = 0.986）。T 的单位是千人，题干「每周新增 100 000 人」对应 b = 100（千人），单位与 T 一致。

**真题**：2017A-Q16(a)(i)、2017A-Q16(a)(ii)、2017A-Q16(b)、2017A-Q16(c)、2017A-Q16(d)、2018A-Q9(a)、2018A-Q9(e)、2020A-Q8(d)、2021F-Q6(c)、2023A-Q13(c)、2024A-Q7(e)、2025A-Q6(f)（共 12 个子题）。

## 题型 9：数列部分和与累计总量

**识别**：累计距离、最大高度、谁先到达等问题，需要把前若干项累加。证据中只有 3 个子题（2 道题）。

**步骤**
1. 累计总量 = 前 n 项之和。等差：S_n = n(T_1 + T_n) ÷ 2；等比：S_n = T_1(1 − r^n) ÷ (1 − r)。也可用计算器的求和或表格功能核对。
2. 如有初始高度或初始量，先求和再加上初始量（2020A-Q7(d)：key 要求先对若干项求和，再加上初始的 60）。
3. 比较两人或两个方案的累计量时，分别求出各自达到目标的日期，再比较（2025A-Q6(e)：key 分别给出两人的到达日，再给出结论并说明理由）。

**得分点**：求和的式子正确（2020A-Q7(d) 分两步：求和、加上初始量）；每人的到达日各有分（2025A-Q6(e)）；结论要有理由。

**易错**：项数差 1（只加到第 n − 1 项）；漏掉初始量；比较时只写结论没有给出每人的日期。

**真题**：2020A-Q7(d)、2025A-Q6(b)、2025A-Q6(e)（共 3 个子题）。
