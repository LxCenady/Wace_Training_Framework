## 题型 1：复利投资或贷款递推建模

**识别**：题干给出按年利率复利计息的账户或贷款，要求写出递推式，或求逐期余额。常见表述是每期末存入或还款，并要求写出 recursive rule。

**步骤**
1. 求每期利率：每期利率 = 年利率 ÷ 每年计息次数（如按季度计息，每期利率 = 年利率 ÷ 4）。
2. 写出递推式：只计利息时 Aₙ₊₁ = (1 + r)Aₙ；如有每期存入或还款 d，则 Aₙ₊₁ = (1 + r)Aₙ ± d。
3. 写出初值 A₀（本金或当前余额），递推式与初值要分开写。
4. 需要具体数值时，逐期代入计算，或用题型 3 的复利公式直接求。

**得分点（key 的典型写法）**：递推式的两部分各计一分，即乘数（1 + r 或其等价形式）和初值（2018A-Q8(a)(ii)、2020A-Q12(a)(ii)）；每期利率要按题目的计息频率取正确（2025A-Q8(b) 要求用季度利率）。

**易错**：直接用年利率作每期利率；有每期存款的题目漏掉 ± d 项；2020A-Q12(b) 的还款是每年末发生，写递推式时要和时间点对齐。

**真题**：2018A-Q8(a)(ii)、2018A-Q16(d)、2018A-Q16(e)、2020A-Q12(a)(i)、2020A-Q12(a)(ii)、2020A-Q12(b)、2024A-Q10(a)(i)、2024A-Q10(a)(ii)、2025A-Q8(b)

## 题型 2：有效年利率与计息频率比较

**识别**：题目涉及有效年利率（effective annual rate），给出不同计息频率（月、季、半年、日）的方案，要求比较或判断。

**步骤**
1. 对每个方案计算有效年利率 EAR = (1 + j/m)ᵐ − 1，其中 j 为名义年利率，m 为每年计息次数；按日计息时 m 取 365。
2. 同一本金比较时，投资取 EAR 较高者，贷款取 EAR 较低者。
3. 要求反推名义利率时，把目标 EAR 代入同一公式再解。
4. 结论要明确指出选哪个方案，并写出两个 EAR 的数值作为依据。

**得分点（key 的典型写法）**：正确代入名义利率与计息次数（2016A-Q13(b)，按日计息的题目要用 365 次）；两个 EAR 都算出（2022A-Q8(a)、2024A-Q10(d)）；结论与数据一致（2024A-Q10(d) 的结论要和较高的 EAR 对应）；2020A-Q9(e) 类题目要算出有效利率后判断题干的说法是否成立。

**易错**：不换算直接比较名义利率；把按日计息的 m 写成 360 或 12；百分数换成小数时漏掉除以 100；2018A-Q8(b) 要求说明计息频率改变后，达到同一终值所需的名义利率如何变化，只写结论不写计算会失分。2017F-Q4(a)（借款选择计息期）的理由要基于：同一名义利率下计息越频繁，有效利率越高，借款成本越高。

**真题**：2016A-Q12(a)、2016A-Q13(b)、2016A-Q16(b)(i)、2016A-Q16(b)(ii)、2016A-Q16(b)(iii)、2017A-Q8(a)（待复核）、2017A-Q8(b)、2017F-Q4(a)、2018A-Q8(b)、2018A-Q16(a)、2018A-Q16(b)、2018A-Q16(c)、2020A-Q9(b)、2020A-Q9(e)、2021A-Q10(a)、2022A-Q8(a)、2024A-Q10(d)、2024A-Q13(f)

## 题型 3：复利现值、终值与期限求解

**识别**：题目问投资一段时间后的价值、翻倍所需时间、或达到某目标所需的时间；利率与计息期可能不一致，需要换算。

**步骤**
1. 统一单位：每期利率 = 年利率 ÷ 每年计息次数；期数 N = 年数 × 每年计息次数，结果最后再换回题目要求的单位（年或月）。
2. 终值公式 FV = PV(1 + r)ᴺ；求期数时 N = ln(FV ÷ PV) ÷ ln(1 + r)，或用计算器输入 PV、FV、I、P/Y、C/Y 解 N。
3. 翻倍问题取 FV = 2PV。

**得分点（key 的典型写法）**：利率与期数分别计分（2016A-Q13(a)(ii) 把正确利率和正确时间拆开给分）；终值计算正确（2016A-Q13(a)(i)）。

**易错**：计息是按月而期数却用年数；用年利率代入月度计息的公式；把终值与利息混淆，题目问投资价值时写的是终值总额，不是利息。

**真题**：2016A-Q13(a)(i)、2016A-Q13(a)(ii)、2017F-Q4(b)、2017F-Q4(c)、2018A-Q8(a)(i)、2018A-Q8(b)、2025A-Q8(a)

## 题型 4：递减余额贷款递推 ★

**识别**：借款本金按期计息，并按固定金额还款；题目问第 n 次还款后的余额、要求完成还款表（期初余额、利息、还款、期末余额），或写出递推式。

**步骤**
1. 求每期利率 r、每期还款额 R，初值 T₀ 为借款本金（或题目指定的余额）。
2. 递推式：Tₙ₊₁ = (1 + r)Tₙ − R。若题目写成 Tₙ₊₁ = aTₙ − b 的形式，则 a = 1 + r，b = R。
3. 逐期代入求余额；或用题型 8 的求解器，输入 N、I、PV、PMT，求 FV（即余额）。
4. 有一次性还款时：先求该时刻的余额，再从中扣除一次性还款作为新的 PV，然后用剩余期数求最终余额（2022A-Q16(b)）。
5. 利率或还款额改变时，从变化时的余额开始，按新的递推式继续计算（2024A-Q6(d)）。

**得分点（key 的典型写法）**：递推式和初值分开计分（2017A-Q14(a)(i)、2018A-Q14(a)(i)）；还款表每一列都要正确（2021A-Q10(b) 分别给期初余额与还款、利息、期末余额；2016A-Q12(b) 要求表中 A 为第 6 个月的利息 219.91、B 为期末余额 14 380.32）；第 n 次之后的余额（2022A-Q16(a)）；一次性还款后用新的 PV 计算（2022A-Q16(b)）。

**易错**：利息用年利率计算；漏掉 T₀，或把 T₀ 写成第一次还款后的余额（2021A-Q10(c) 要求说明第 0 期的取值）；一次性还款后仍用旧的 PV。2016A-Q12(e) 的情境说明：若每期还款不超过当期利息，余额不会减少，永远还不清。

**真题**：2016A-Q12(b)、2016A-Q12(e)、2017A-Q14(a)(i)、2017A-Q14(a)(ii)、2017A-Q14(b)、2018A-Q14(a)(i)、2020A-Q11(b)(i)、2020A-Q11(b)(ii)、2020A-Q12(c)(i)、2021A-Q10(b)、2021A-Q10(c)、2022A-Q16(a)、2022A-Q16(b)、2023A-Q9(b)、2023A-Q9(c)(i)、2023A-Q9(c)(iii)、2023A-Q9(g)、2024A-Q6(a)(i)、2024A-Q6(a)(ii)、2024A-Q6(d)

## 题型 5：还款额、利率与清偿时间关系

**识别**：题目问还清贷款需要多少个月或多少年、还款额改变后需要多久，或要求在指定期限内还清时每期应还多少；也可能是比较两种还款方案。

**步骤**
1. 清偿期数用求解器：PV = 借款额，PMT = 每期还款（与 PV 异号），FV = 0，求 N。N 通常不是整数，取整方式见题型 6。
2. 要在指定期限内还清，反求 PMT：PV、FV = 0、N、I 已知，求 PMT。按题目要求的精度取值，2016A-Q12(f) 的 key 按向上取整到分计分。
3. 比较方案：分别求出各方案的期数、余额或总还款额，说明哪个更好并给出差额（2018A-Q14(c)、2020A-Q11(c)）。
4. 若每期还款不超过当期利息，余额不会下降，永远还不清（2016A-Q12(e)）。

**得分点（key 的典型写法）**：PMT 正确并按要求取整（2016A-Q12(f)）；期数正确（2021A-Q10(d)、2023A-Q9(d)、2024A-Q6(c)(i)、2025A-Q8(f)(i)）；方案比较时写出各自的余额或总额，并给出差额（2020A-Q11(c)）；选择方案的理由要成立（2018A-Q14(c)）。

**易错**：期数的单位（题问月数却写成年数）；分次还款的好处要说清楚是减少利息的道理（2020A-Q11(a)）；忽略末期不足一整期的还款（归入题型 6）。

**真题**：2016A-Q12(c)、2016A-Q12(e)、2016A-Q12(f)、2017A-Q14(c)、2018A-Q14(a)(ii)、2018A-Q14(c)、2020A-Q11(a)、2020A-Q11(c)、2020A-Q12(c)(ii)、2021A-Q10(d)、2023A-Q9(a)、2023A-Q9(d)、2023A-Q9(g)、2024A-Q6(c)(i)、2024A-Q6(d)、2025A-Q8(f)(i)

## 题型 6：贷款总利息与末期调整还款

**识别**：题目问总还款额、总利息、最后一次还款额，或总成本（含首付）。最后一次还款通常与其他期不同。

**步骤**
1. 找出完整期数 N（取整部分），用递推或求解器求第 N 次还款之后的余额 Tₙ。
2. 第 N + 1 期的利息 = r × Tₙ；末期还款 = Tₙ + 这一期的利息。
3. 总还款 = N × 每期还款 + 末期还款；总利息 = 总还款 − 借款本金。若题目问总成本，再加上首付。
4. 对于期数取整的题目，先算全额期数的情况，再比较多一期的情况，最后确定总额（2025A-Q8(f)(ii)）。

**得分点（key 的典型写法）**：通常分为三个得分点，即第 N 次之后的余额、第 N + 1 期的利息、总额（2016A-Q12(d)、2020A-Q12(c)(iii)）；末期还款正确（2017A-Q14(d)）；总成本要包括首付（2017A-Q14(e)）；完整期数用对（2022A-Q15(b)(iv)）。

**易错**：末期还款写成普通还款额；总利息与总还款混淆；忘记首付；2022A-Q15(b)(iii)、(iv) 的 key 注记：若用 6.1 ÷ 1200 代替取整后的 0.00508，末期还款为 5161.09（而非 4858.42），总利息也随之改变，所以中间的利率与余额要保留足够位数。

**真题**：2016A-Q12(d)、2017A-Q14(d)、2017A-Q14(e)、2018A-Q14(c)、2020A-Q12(c)(iii)、2021A-Q10(e)、2022A-Q15(b)(iii)、2022A-Q15(b)(iv)、2023A-Q9(c)(ii)、2023A-Q9(e)、2023A-Q9(f)、2023A-Q9(g)、2024A-Q6(c)(ii)、2024A-Q6(d)、2025A-Q8(f)(ii)

## 题型 7：年金递推与余额变化 ★

**识别**：一笔本金每期提取固定金额（退休金、奖学金、假期费用等），题目问提取后的余额、能维持多少年、或每期最多能提取多少。

**步骤**
1. 统一利率的期：若复利按月而提取按年，先把复利换算成对应的有效年利率（2025A-Q12(a)(ii) 的 key 先求有效年利率，再写递推式）。
2. 初值 T₀ 为初始本金；递推式 Tₙ₊₁ = (1 + r)Tₙ − P，P 为每期提取额。
3. 题目要求提取后的余额时，取提取之后的那一刻的值。
4. 求可维持的年数：用求解器输入 PV、PMT、I、FV = 0，得到小数形式的 N，再取整（2016A-Q16(a)(ii)）。
5. 不让本金减少的最大提取额等于每期利息，即 P = r × PV（2016A-Q16(a)(iii)：先算出 6% 的利息，再说明本金不会减少）。

**得分点（key 的典型写法）**：增长率正确（2016A-Q16(a)(i)）；提取额正确；T₀ 定义正确（2016A-Q16(a)(i) 把增长率、提取额、T₀ 分开计分）；余额类问题按初始余额与所求时刻的余额分别计分（2016A-Q16(b)(ii)）；最大提取额按要求取整到百（2016A-Q16(b)(iii)）；2025A-Q12(a)(ii) 要先写出有效年利率，再写出递推式。

**易错**：复利期与提取期不一致却直接套用年利率；把最大提取额算成本金的一个比例，而不是当期利息；把提取额和余额的时间点混在一起。2016 年 Q16 为当年最难题（平均 42.26%），本题型的子题覆盖了递推、年数和最大提取额三类。

**真题**：2016A-Q16(a)(i)、2016A-Q16(a)(iii)、2016A-Q16(b)(i)、2016A-Q16(b)(ii)、2016A-Q16(b)(iii)、2020A-Q9(a)、2021A-Q14(a)(i)、2021A-Q14(a)(ii)、2021A-Q14(a)(iii)、2022A-Q15(b)(i)、2023A-Q14(a)、2023A-Q14(b)、2024A-Q13(a)、2024A-Q13(b)、2024A-Q13(d)(ii)、2025A-Q12(a)(ii)、2025A-Q12(b)(i)、2025A-Q12(d)

## 题型 8：年金现值、期款与期限求解 ★

**识别**：题目涉及年金（annuity）或定期存款目标，要求求现值、每期付款、可领取的年数或所需利率；通常需要财务计算器或求解器。

**步骤**
1. 参数：N = 总付款次数（年数 × P/Y）；I = 名义年利率；PV = 现值；PMT = 每期付款；FV = 终值（到期余额为 0，或为目标金额）；P/Y 与 C/Y 分别为每年付款次数与计息次数，按题目填写（2018A-Q11(a) 中两者都为 12）。
2. 符号约定：存款一方的 PV 与 PMT 同号（都是付出），FV 为目标时与之异号；借款一方的 PV 为收到的本金，还款 PMT 与之异号，还清时 FV = 0。在答卷上写出每个参数的数值，便于阅卷核对。
3. 付款时点：每期末付款用期末（END）模式；若题目说明利息在付款前加入，则要按递推式处理（2022A-Q15(b)(i)）。
4. N 不是整数时取整：2018A-Q11(b)(i) 的 key 要求把 N 向下取整到 12 年；取整后的余数归入题型 6 的末期处理。
5. 求利率：N、PV、PMT、FV 已知，解 I（2018A-Q11(b)(ii)）。

**得分点（key 的典型写法）**：至少三到四个参数正确，全部参数正确后再计算结果（2017A-Q8(b)、2022A-Q8(b)(i)）；N 正确（2018A-Q11(a) 的 60 个月，2018A-Q11(b)(ii) 的 20 次付款）；P/Y 与 C/Y 都要写对（2018A-Q11(a)、2025A-Q8(d)）；求出缺额（2022A-Q8(b)(i)）。

**易错**：N 用年数而非付款次数；存款与取款的符号写成相同；忘记到期后的剩余余额；2016A-Q16(a)(ii) 要求先给出小数形式的年数，再写整数年。

**真题**：2016A-Q16(a)(ii)、2017A-Q8(b)、2018A-Q11(a)、2018A-Q11(b)(i)、2018A-Q11(b)(ii)、2018A-Q16(f)(i)、2018A-Q16(f)(ii)、2020A-Q9(c)、2021A-Q10(f)、2022A-Q8(b)(i)、2022A-Q8(b)(ii)、2022A-Q15(b)(ii)、2023A-Q14(a)、2024A-Q10(b)、2024A-Q10(c)、2024A-Q13(d)(i)、2025A-Q8(c)、2025A-Q8(d)、2025A-Q12(b)(ii)

## 题型 9：永续年金与无限期付款

**识别**：题目要求一笔钱能无限期地每期支付固定金额，或年金到期后转为永续年金（perpetuity）。

**步骤**
1. 每期利率按付款周期换算：若付款按季、计息按月，则把月利率换算成季利率，或在求解器中同时设置 P/Y 与 C/Y。
2. 求维持永续付款所需的现值：PV = PMT ÷ 每期利率。
3. 已知现值求每期付款：PMT = PV × 每期利率。
4. 年金转永续时，先求年金在转换时刻的余额（作为新的 PV），再求每期付款（2023A-Q14(b)、2025A-Q12(c)）。
5. 用求解器时，PV 与 FV 的符号应相反（2025A-Q12(c) 的 key 有此项）。

**得分点（key 的典型写法）**：每期利率正确（2017A-Q8(a)，待复核：key 的解法为 x = x(1 + 5.9%/12)¹² − 6000，即 x = 6000 ÷ i，其中有效年利率 i ≈ 6.06%，得 98 974；题干写年初付款，若按期初付款应为 104 974，key 与题干的时点不一致）；参数 P/Y、C/Y、PV、FV 都写对（2020A-Q9(d)、2021A-Q14(b)、2024A-Q13(e)）；转换时的余额正确（2023A-Q14(b)）；2025A-Q12(c) 要算出年金余额、列出方程，并得出结论；2025A-Q12(d) 要比较第 8 年与第 9 年的余额，确定最长年数。

**易错**：直接用年利率除以付款次数；付款与计息频率不同却不换算；把永续理解成有限期年金。2025A-Q12(d) 的 key 分别给出第 9 年与第 8 年的余额两项，所以要把两个比较值都写出来，再下结论。

**真题**：2017A-Q8(a)（待复核）、2020A-Q9(d)、2021A-Q14(b)、2022A-Q15(a)、2022A-Q15(c)、2023A-Q14(b)、2024A-Q13(e)、2025A-Q12(c)、2025A-Q12(d)

## 题型 10：名义年利率与每期利率换算

**识别**：题目给出余额的增长因子或每期利息，要求求每期利率或名义年利率。

**步骤**
1. 每期利率 r = 增长因子 − 1（或 每期利息 ÷ 期初余额）。
2. 名义年利率 = 每期利率 × 每年计息次数。这是简单相乘，不是有效年利率。
3. 需要有效年利率时，用 (1 + r)ᵐ − 1（见题型 2）。

**得分点（key 的典型写法）**：每期利率正确；名义年利率正确（2024A-Q6(b)、2025A-Q8(e)、2025A-Q12(a)(i)）；2024A-Q13(c) 是年金的年利率，计算方法相同。

**易错**：把名义年利率当作有效年利率；每年期数用错（月为 12，季为 4，半年为 2）。

**真题**：2024A-Q6(b)、2024A-Q13(c)、2025A-Q8(e)、2025A-Q12(a)(i)
